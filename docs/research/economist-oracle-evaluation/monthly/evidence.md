## 3. История решений (с hold'ами)

```sql
WITH m AS (SELECT event_date AS meeting, max(emergency) AS emergency
           FROM v_events_calendar
           WHERE category = 'cbr' AND title LIKE '%заседание по ключевой ставке%'
             AND event_date < toDate('2026-11-15') GROUP BY event_date),
     r AS (SELECT date, value FROM v_cbr_macro WHERE series = 'cbr_key_rate'),
     x AS (SELECT meeting, emergency,
                  argMaxIf(value, date, date <  meeting)     AS rate_before,
                  argMaxIf(value, date, date <= meeting + 4) AS rate_after
           FROM m CROSS JOIN r GROUP BY meeting, emergency)
SELECT meeting, emergency, rate_before, rate_after, round((rate_after - rate_before) * 100) AS step_bp
FROM x WHERE meeting >= toDate('2024-01-01') ORDER BY meeting;
```

2024: 16,0 hold ×4 → 18,0 (+200) → 19,0 (+100) → 21,0 (+200) → 21,0 hold.
2025: 21,0 hold ×3 → 20,0 (−100) → 18,0 (−200) → 17,0 (−100) → 16,5 (−50) → 16,0 (−50).
2026: 15,5 (−50) → 15,0 (−50) → 14,5 (−50) → 14,25 (−25) → 14,0 (−25) → **14,0 hold (11.09)** → **14,0 hold (23.10)**.
