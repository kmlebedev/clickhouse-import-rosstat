## Задача и решение

Следующий P0 после ОНДКП — резолвер прогнозов и свежесть данных. Снимок dev
показал 8 ожидающих прогнозов на заседание23.10.2026 при наличии факта14%
на26.10.2026. Для них требовался догон штатного резолвера, а не новый прогноз.
Весь журнал содержит15 строк:12 cbr_rate* (4 ранее resolved),1 nav,2 xau_q_avg.

Общий resolver обрабатывает обе семьи метрик. При повторной агрегации золота
среднее может отличаться от сохранённого на машинное округление; обработка
ставки не должна попутно переписывать золотой контур. Добавлен
`FORECAST_RESOLVE_SCOPE=cbr_rate`: gold-методы стора вообще не вызываются.
Пустое значение/`all` сохраняет прежнее поведение. Неизвестное значение — ошибка
до запросов/батча. Scope охватывает все наступившие `cbr_rate*`, включая
shadow/canary; это не фильтр одного заседания.

Алгоритм факта/ошибки, SQL, схема, витрины, гранты и DAG не менялись.
`FORECAST_RESOLVE_SCOPE` читается через os.Getenv в Import, разовый запуск:

```sh
FORECAST_RESOLVE_SCOPE=cbr_rate make import STAT=forecast_resolve
```

Параметр не записывался в постоянный env и расписание. Проверен локальный
write endpoint через make: `localhost:9000`; исходные таблицы агент не читает,
SQL снимков — только MCP к витринам. Изменения выполняет штатный Go-батч.

## Границы

Восемь строк относятся к одному исходу заседания и не являются восемью
независимыми наблюдениями для сравнения моделей. Это сверка уже записанных прогнозов с фактом. Она не создаёт декабрьский прогноз,
годовую траекторию ставки и причинные веса каналов. `divergence` по-прежнему
сопоставляет октябрьскую цель с ближайшим декабрьским заседанием и не должен
становиться сопоставимым только из-за заполнения actual.

Metadata всех12 rate-строк доступны через `v_ml_live_accuracy`, но probabilities
там нет: живьём их можно сверить у трёх последних production-строк dashboard;
для остальных перенос проверяется тестом и кодом батча. Полная независимая
live-сверка probabilities всех12 строк не заявляется.

Свежесть остальных макрорядов остаётся следующим P0; staging, новые модели,
перенос старых прогнозов в иной stage и промоушен модели не выполнялись.
