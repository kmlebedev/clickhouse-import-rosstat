## Контракт

`announcement_date` — дата официальной новости о документе, не автоматически
дата исторических байтов PDF. В частности, **2 ноября 2022 года** извлекается
из `.news-info-line_date` [новости14277](https://www.cbr.ru/press/event/?id=14277)
об ОНДКП на 2023–2025 годы. Старое `published_at` сохраняется.

Добавлены `announcement_date`, `announcement_url`, `announcement_evidence` в
реестр `cbr_ondkp`. Схема обновляется идемпотентным `ADD COLUMN IF NOT EXISTS`.
JSON v1 содержит UTC-время наблюдения, SHA256 сохранённого/текущего PDF,
SHA256 HTML новости и страницы выпуска, URL страницы выпуска. Текущий PDF
перед записью должен совпасть по SHA и размеру с реестром. Дата заголовка
новости связывается с годом через точную ссылку в тексте статьи; footer,
дата проекта в теле текста и ссылки навигации не используются.

Витрина `v_cbr_ondkp_forecast` раскрывает provenance и `artifact_sha256`.
`publication_status` различает `announcement_only`, `legacy_unverified`,
`unknown`; **ни один статус не означает PIT-ready**. `release_year` — год
политики, использовать его как дату as-of нельзя. Каталог рядов и MCP-комментарии
обновлены. Новый числовой ряд, таблица, грант или DAG не добавлялись.

При одинаковом URL известного выпуска заменяется полная копия строки реестра
с дополненными announcement-полями. Даты, URL, формат, SHA, размер и счётчик
прогнозов сохраняются; прогнозные строки на этом пути не вставляются.
При изменении URL известного выпуска прогон останавливается до **записи данных**:
DDL к этому моменту уже мог выполниться. Автоматически переносить дату и прогнозы
на другую версию нельзя. Новый неизвестный выпуск обрабатывается штатно.

## Ограничения

Это конкретизация безопасного варианта handoff #597: неизвестная дата выбранной
исторической версии не заполняется датой новости. Реализовано NULL→date для
`announcement_date`; все прежние `published_at` сохранены. Архив исторических
байтов, независимое доказательство доступности версии на дату, внутридневное
время публикации и полная PIT-проверка остаются невыполненными.

Четыре URL новостей — проверенный список, новые добавляются после проверки
источника; даты читаются из HTML. Новости 2021/2022/2025 не установлены.
Дата наблюдения provenance не обновляется на каждом no-op. Замена содержимого
под тем же URL после наблюдения не отслеживается этим гейтом; evidence относится
к сохранённому SHA и своему времени. Смена URL требует отдельной проверки версии.

Staging не менялся. Свежесть прочих рядов, forecast_resolve, собственная годовая
траектория и причинные веса — следующие пункты исходного плана, не результат #598.
