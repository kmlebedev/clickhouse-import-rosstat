## 3. Метод

- Недельное значение — индекс «% к предыдущей дате регистрации»; месячный m/m — `Π(value/100) − 1` по неделям, зарегистрированным в месяце.
- Полнота месяца: `n_weeks ≥ 3`, первая точка не позже 10-го числа, последняя — не раньше чем за 10 дней до конца месяца, максимальный разрыв ≤21 дня; праздничный сдвиг 15–17 дней допускается, иначе NaN.
- Месяц — по дате регистрации недели, а не по началу интервала; это не точный календарный месяц (ошибка измеряется сверкой).
- Веса — годовые 2016–2024 (2013–2015 → 2016, 2025–2026 → 2024); fixed-2024 — робастность.
- As-of: недельная точка `date + 2`, cutoff 8-е M+1; официальная метка M доступна не раньше конца M+1 и используется только для сверки.
- Проверка as-of: 0 нарушений; использовано 48641 недельных точек, исключено 2983 (45 уникальных дат) с доступностью после cutoff.

- Task 2 (отраслевые МП), Task 4 (модель v3) и Task 5 (сравнение с CB_COMP) в этот PR не входят.
