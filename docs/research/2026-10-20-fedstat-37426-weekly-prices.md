# ЕМИСС 37426 — недельные средние потребительские цены: spike источника (2026-10-20)

> **Задача:** Task 1 пункта `key-rate/phase-4-emiss-weekly-prices` (issue [#264](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/264), родитель [#263](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/263)).
> **Границы:** spike источника и протокола выгрузки; прод-код, DDL и запись в ClickHouse не выполнялись.
> **Итог:** источник пригоден; полный набор — **158 товаров, 56 133 уникальные точки**, 2008–2022 по коду РФ `1688487` и 2026 по коду `1849012`; 2023–2025 в источнике отсутствуют. Оценка issue «158 × 2008–2018 ≥ 88 000» не подтвердилась: за 2008–2018 в источнике только **77 товаров / 36 335 точек**.

## 2. Протокол выгрузки

1. `GET /indicator/37426` — получить `token` и cookie сессии (`JSESSIONID`, `session-cookie`).
2. `POST /indicator/downloadData.do?format=sdmx` с `Content-Type: application/x-www-form-urlencoded`, `Referer: https://www.fedstat.ru/indicator/37426`, `Origin: https://www.fedstat.ru`:
   - `id=37426`;
   - `lineObjectIds=57831`, `lineObjectIds=58273`;
   - `columnObjectIds=3`, `columnObjectIds=33560`;
   - `filterObjectIds=30611`;
   - `selectedFilterIds=0_37426`, `selectedFilterIds=57831_1688487`, `selectedFilterIds=57831_1849012`, `selectedFilterIds=3_<год>` (2008–2022, 2026), `selectedFilterIds=58273_<id товара>` (×158), `selectedFilterIds=30611_950351`;
   - `struts.token.name=token`, `token=<токен>`, `title=…`.

Проверено live 2026-10-20:

| Прогон | Ответ | Размер | Время |
|---|---|---|---|
| один товар, 2016 | 200 XML | 118 511 байт | 2,8 с |
| все 158 товаров, 2016 | 200 XML | 1 862 483 байта | 3,3 с |
| все 158 товаров, 2008–2022 | 200 XML | 27 521 579 байт | 28,8 с |
| все 158 товаров, 2008–2022 + 2026, оба кода РФ | 200 XML | 27 630 517 байт | 41,4 с |

**Rate limit.** Серия из 11 POST подряд (по одному на год) получила `503 Service Temporarily Unavailable` на 9 запросах; после паузы 30 с тот же запрос проходит. Один POST на весь диапазон — безопасный путь: 41 с, 27,6 МБ, без 503. Импортёр обязан делать **один POST на прогон** и иметь backoff на 503 (30/60/120 с, 3 попытки).

**Ответ без данных.** POST за 2023–2025 по коду `1688487` возвращает HTTP 200 с `text/html` (страница показателя, 541 590 байт), а не XML. Это не ошибка парсера и не пустой ряд: импортёр обязан проверять `Content-Type`/корень XML и падать с явным сообщением, а не писать «0 строк».

## 3. Структура SDMX и разбор

`GenericData` → `generic:Series` → `generic:SeriesKey` (`s_OKATO`, `s_grtov`), `generic:Attributes` (`EI`, `PERIOD`), `generic:Obs` (`generic:Time`, `generic:ObsValue value="311,8"`).

- `s_OKATO=643` — «Российская Федерация» (фильтр `1688487`), 2008–2022.
- `s_OKATO=643004.АГ` — «Российская Федерация без учета новых субъектов (с 01.01.2023)» (фильтр `1849012`), только 2026 недели 39–40.
- Десятичная запятая (`311,8`), пустых/нулевых значений в проверенной выборке нет.
- 68 серий — точные дубли (тот же товар/регион/дата/значение, например 2017-01-16); расхождений значений нет.

## 4. Правило даты

Метки `PERIOD` делятся на два вида; оба проверены на всех 769 метках (0 ошибок):

1. **Дата в метке:** `на 9 января 2008 года`, `23 неделя (на 13 июня 2016 года)`, `40 неделя 2009 года (на 12 октября)`, `37 неделя (на 17сентября 2018 года)` (пробел между днём и месяцем пропущен), `41 неделя (на 14 октября )` (лишние пробелы).
   - Регулярка: `на\s+(\d{1,2})\s*([а-яё]+)(?:\s+(\d{4})\s+года)?` после нормализации пробелов.
   - Год: из метки, если он там есть; иначе из `Time`. **Год метки сильнее `Time`:** 68 серий начала января имеют `Time` предыдущего года (например, `2 неделя (на 16 января 2017 года)` при `Time=2016`) — дата обязана быть 2017-01-16.
   - Месяц — родительный падеж (`января`…`декабря`), день — число; невалидная дата (например, 30 февраля) — ошибка.
2. **Только номер недели:** `1 неделя 2021`, `51 неделя 2022`, `39 неделя 2026`.
   - Правило: **неделя 1 — первый понедельник 8 января или позже**; неделя N = неделя 1 + (N−1)×7.
   - Проверка на совпадении с `rosstat_ipc_weeks` (ClickHouse, `frequency='W'`): 2021 — 2021-01-11 … 2021-12-27 (51 дата), 2022 — 2022-01-10 … 2022-12-26 (51), 2026 — 2026-01-12 … 2026-10-12 (40). Совпадение полное.
   - Пример: `39 неделя 2026` → 2026-09-28, `40 неделя 2026` → 2026-10-05.

Распределение по годам (2008–2022): 2 727 / 3 162 / 3 183 / 3 213 / 3 262 / 3 380 / 3 468 / 3 468 / 3 536 / 3 468 / 3 468 / 3 468 / 4 950 / 5 610 / 5 610; 2026 — 228. 2023–2025 — ноль, источник их не отдаёт.

Товарный состав: 143 товара есть в 2008–2022, 114 — в 2026, 15 — только в 2026, 44 — только в истории; объединение — 158. Полные флаги и точки по каждому товару — в CSV.

**Почему issue ошибся:** оценка «158 × 561 ≈ 88 600» предполагала, что все 158 товаров существуют все 11 лет. Фактически до 2019 года в источнике 68 товаров, в 2008-м — 59; 158 — это полный список фильтра, а не панель одного года. За 2008–2018 фактически 36 335 точек; 88 000 недостижимо без регионов (392 ОКАТО, ~50 млн точек) или без 2019–2022.

## 6. 2023–2025 и 2026

- `1688487` (РФ) за 2023–2025 — HTML-страница вместо XML: данных нет.
- `1849012` (РФ без новых субъектов) за 2023–2025 — сервер игнорирует невалидные годы и отдаёт только 2026 недели 39–40 (228 точек).
- `1688487` за 2026 — HTML-страница; 2026 данные есть только под `1849012`.
- Вывод: **2023–2025 — реальный разрыв источника**, а не ошибка импортёра. 2026 — частичный выпуск (2 недели) под новым определением РФ.

## 7. Terms/robots

- `https://www.fedstat.ru/robots.txt`: `User-agent: *`, запрещены только `/login.do` и `/changeLanguage.do`; `Sitemap: /sitemap.do`.
- `/terms.do`, `/userAgreement.do`, `/help.do` отдают общую страницу «О сервисе»; явных условий использования, ограничений объёма или запрета регулярного импорта в доступном HTML не найдено.
- Наблюдаемый rate limit — 503 при серии POST; рабочий режим — один POST в неделю (по расписанию) плюс backoff. Юридические terms формально не подтверждены — см. «Что не проверено».

## 9. Риски и ограничения

| Риск | Следствие / лечение |
|---|---|
| CSRF-токен привязан к cookie сессии | GET и POST — одним `util.HttpClient` с cookie jar; токен на один POST |
| 503 при частых POST | один POST на прогон; backoff 30/60/120 с, 3 попытки; ошибка с кодом и сниппетом тела |
| HTTP 200 + HTML вместо XML | проверять `Content-Type` и корень `GenericData`; ошибка «источник вернул HTML» |
| 2023–2025 отсутствуют | зафиксировано как ограничение источника; не «пустые» точки |
| 2026 — другой код РФ | отдельный `region` в таблице; не смешивать с 2008–2022 |
| Ревизии/винтажи | источник отдаёт текущее значение; PIT/архива нет |
| Регионы 392 ОКАТО | вне v1 (~50 млн точек) — отдельный пункт |
| Rate limit/нестабильность | retry DAG, один POST, логирование размера/времени |

## 10. Что не проверено

- Точный день/время публикации недельного выпуска: `Header/Prepared` — время экспорта, не публикации; расписание ставится еженедельно с запасом.
- Юридические условия использования: `/terms.do` и `/userAgreement.do` не содержат явного текста в доступном HTML; robots разрешает обход.
- Ревизии исторических значений: один срез, повторный POST через время не сравнивался.
- Поведение 2023–2025 при появлении данных: если источник откроет годы, гейт/диапазон придётся расширить отдельным пунктом.
- Региональный разрез и 2026+ (кроме недель 39–40) — вне v1.
