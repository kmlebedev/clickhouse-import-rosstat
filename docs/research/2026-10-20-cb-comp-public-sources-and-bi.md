# Публичные источники для CB_COMP и недельного ИПЦ: StfCpiR DB, ЕМИСС 31074 и BI Росстата (2026-10-20)

> **Объект:** локальный архив авторов `BusinessSurveyCBRCpiForecastingSourceCode/Models/CpiComponents/StfCpi_External_data` (панель `StfCpiR_db/output/data_panel_bi_sa.fst`), публичные источники Росстата/ЦБ и BI-система `bi.rosstat.gov.ru`.
> **Задача:** ответить на два вопроса: (1) есть ли недельный ИПЦ в архиве CB_COMP; (2) можно ли получить live-данные или аналог панели `StfCpiR` из публичных источников — ЕМИСС, сайта Росстата, BI-системы, ЦБ.
> **Метод:** `find`/`grep`/`openpyxl`/`Rscript` по архиву; HTTP-пробы и браузер (гостевой режим) по публичным источникам; MCP ClickHouse (`kimi_reader`) по витринам. Дата среза — 2026-10-20.
> **Границы:** полный SDMX-pull ЕМИСС и экспорт BI не выполнялись; terms/robots публичных источников не проверялись; per-code МП недоступен публично по определению.

## 2. Архив CB_COMP: что публично, а что нет

### 2.1. Публикация

- figshare DOI **10.6084/m9.figshare.27990260.v1**, файл `BusinessSurveyCBRCpiForecastingSourceCode.7z`, 438 628 189 байт, лицензия **GPL 3.0+**, опубликован 2024-12-09.
- `README.txt` авторов: «Текущая версия проекта урезена»; «Распространение всех исходных данных только по запросу. Для оценки модели доступны все данные только в форме SA».
- В архиве 3 375 файлов, из них 3 312 `*.RDS` (модели), 33 xlsx, 16 csv, 2 fst, 2 txt, 1 xls; остальное — служебные файлы (`.DS_Store` и пр.). Файлов с `nedel`/`week`/`недельн` нет; grep по R-коду находит только generic-опцию `time_res = c("month","week","day")` в `R/common/utils.R`, к ИПЦ не относящуюся.

### 2.2. Панель и её входы

`data_panel_bi_sa.fst` — производная панель: 183 654 строки × 9 колонок, 2009-01…2024-09, 189 месяцев (шаг ровно 31 день). Собирается кодом `R/databases_creators/base_indicies_calculate.R` и `base_indicies_calculate_sa.R`.

| Компонент панели | Вход в коде | Статус |
|---|---|---|
| 92 группы месячного ИПЦ | `raw_data_store/fedstat/31074_ru_only` | **Нет в архиве**; источник публичный (см. §3) |
| 87 кодов ОКВЭД2 × 3 индикатора МП | `raw_data_store/monitoring/monitoring_db` | **Только README** «по запросу»; в архиве нет |
| Кредит/ставки/USD | `cbr/curs_usd.xlsx`, `cbr/miacr.xlsx`, ручной файл задолженности | USD/MIACR — есть; задолженность — ручная |
| Региональный ИПЦ (ГУ7) | `raw_data_store/data_cpi_vvgu/data_out.csv` | **Нет в архиве**; публичный источник не подтверждён |
| Производство, ЖКУ, общепит, тарифы | fedstat 57783, 57806, 31065, 31076 | **Нет в архиве**; источники публичные (ЕМИСС) |
| Рынок | `market_data/*` (Brent, Urals, RVI, VIX, золото, медь, CRB) | Файлы есть; часть загрузчиков `broken` |

Проверка отсутствующих путей по коду: `fedstat/31074_ru_only`, `31065`, `31076`, `57783`, `57806`, `data_cpi_vvgu`, `loans/*` — отсутствуют; есть только производные `output/*`. То есть **опубликованный архив не самодостаточен**: воспроизвести сборку панели из него нельзя, можно только читать готовые `output/*`.

## 3. ЕМИСС 31074 — точный live-первоисточник ИПЦ-компонентов

Авторы качают месячный ИПЦ индикатором **31074** («Индексы потребительских цен на товары и услуги») через `fedstatAPIr`:

- страница `https://www.fedstat.ru/indicator/31074` — HTTP 200, 622 353 байта, заголовок «Индексы потребительских цен на товары и услуги»; период **2002–2026**;
- выгрузка — POST `https://www.fedstat.ru/indicator/downloadData.do?format=sdmx` (или `format=excel`), с CSRF-токеном; клиент — открытый пакет `DenchPokepon/fedstatAPIr` (GitHub), функции `fedstat_get_data_ids` → `fedstat_data_ids_filter` → `fedstat_post_data_ids_filtered` → `fedstat_parse_sdmx_to_table`;
- фильтры авторов: `Год` = год, `Виды товаров и услуг` = `*`, `ОКАТО` = «Российская Федерация», `Период` = месяц, `Виды показателя` = «К предыдущему месяцу»;
- результат — тот же `raw_data_store/fedstat/31074_ru_only`, из которого строится панель.

**Значение:** это не аналог, а **точный первоисточник** 92 групп месячного ИПЦ. В нашей витрине `v_rosstat_macro` месячный ИПЦ представлен только 4 официальными компонентами (все товары и услуги, продовольствие, непродовольственные, услуги; 1991-01…2026-09, 429 точек каждый). Импортёр ЕМИСС 31074 на 92 группы — прямой путь к live-панели компонентов.

Ограничение: ЕМИСС отдаёт данные только за запрошенный месяц/фильтр; полный pull 2002–2026 — это тысячи POST-запросов (авторы делали по одному на месяц). Нужен дизайн с батчем/кэшем и гейтом публикации.

## 4. Публичная МП ЦБ — что есть и чего нет

- Страница `https://www.cbr.ru/analytics/dkp/monitoring/0926/` (и `/1026/`) отдаёт 200 и публикует XLSX:
  - `mp_survey_data.xlsx` — 2 193 461 байт, **31 лист**: «Участники опроса», «Экономика всего», «Промышленность», «Добыча», «Обработка», «Сельское хозяйство», «Строительство», «Торговля», «Транспортировка и хранение», «Услуги» и др.;
  - `survey_data_group.xlsx`, `mp_survey_data_gu.xlsx`, `mp_survey_data_facts.xlsx`.
- Данные — **агрегаты по ВЭД/листам**, а не 87 кодов ОКВЭД2 × 3 индикатора, как в архиве авторов. Per-code значения публично не отдаются (в архиве — README «по запросу»).
- Наша витрина `v_cbr_mp_public_panel`: 77 517 строк, 87 кодов, 3 индикатора, но **33 различные серии** — то есть значения повторяются по листам; per-code паритета нет.

**Вывод:** публичная МП — это листовой аналог, а не замена per-code панели. Для полного паритета нужен data request к ЦБ.

## 5. BI Росстата — публичный live-источник недельного ИПЦ

### 5.1. Доступ

- `https://bi.rosstat.gov.ru/biportal/` → 200, `BI Portal`.
- Дашборд недельных цен: `https://bi.rosstat.gov.ru/biportal/contourbi.jsp?allsol=1&solution=Dashboard&project=%2FDashboard%2FPrices_week` — 200, в HTML `CC_UN = "guest"`; логин не требуется.
- Дашборд месячных цен: `...project=%2FDashboard%2FPrices` — 200, гостевой доступ.

### 5.2. Что внутри `Prices_week`

Проверено в браузере 2026-10-20:

- **«Consumer Price Index Estimation»** — недельная оценка ИПЦ РФ: на **12.10.2026 — 100,11**; таблица недель 12.10, 05.10, 28.09, 21.09.2026; фильтр `Year` — **2019, 2020, 2021, 2022, 2023, 2024, 2025, 2026**; список дат начинается **09.01.2019**; проверка фильтра «2018» даёт пустой список.
- **«Индексы потребительских цен на отдельные виды товаров и услуг, в % к предыдущей регистрации»** — товарные строки (маргарин, сметана, говядина, молоко и т.д.) × субъекты РФ; фильтры `Country` / `Federal District` / `The Subject of the Russian Federation` / `date of`; даты недельные, начиная с 2019.
- **Экспорт**: меню карточки — `Export` в форматах **CSV, Word, Excel, Excel (без форматирования), HTML, PDF**; есть `Click to copy link`.
- Примечание источника: данные без ДНР/ЛНР/Запорожской/Херсонской областей; Архангельская — без НАО; Тюменская — без ХМАО/ЯНАО.

### 5.3. Что внутри `Prices`

Месячный ИПЦ: сентябрь 2026 — все товары и услуги **100,35**, базовая **100,49**, продовольствие **100,00**, непродовольственные **100,55**, услуги **100,58**; разрезы по регионам, таблица, карта.

### 5.4. Ограничения BI

- История **с 2019-01-09**, не с 2009: дыры 2009–2018 BI не закрывает.
- Значения текущие (ревизии возможны), винтажей/PIT нет.
- Автоматизация экспорта не подтверждена: UI-экспорт есть, прямой URL/API не найден; это задача отдельного spike.
- Terms/robots BI не проверялись; условия использования данных нужно зафиксировать до импортёра.

### 5.5. Что BI даёт нашим моделям

| Потребность | Сейчас в витрине | BI | Действие |
|---|---|---|---|
| Недельный агрегат ИПЦ 2022+ | **Нет** (агрегат до 2021-12-27) | Есть, 2019–2026, live | spike экспорта → импортёр |
| Полный 2019 год | 42 недели (январь–начало ноября) | Есть весь год | добор 2019 |
| Недельные товары × регионы | **Нет** регионального разреза | Есть, 2019+ | новая витрина/фича |
| Месячный ИПЦ | 4 компонента с 1991-01 | Есть месячный дашборд | кросс-чек, не новый источник |
| 92 группы месячного ИПЦ | 4 компонента | Нет (BI — не ЕМИСС) | импортёр ЕМИСС 31074 |
| Per-code МП | 33 листовые серии | Нет | data request |

## 6. Рекомендация и критерий приёмки

**L1 — импортёр ЕМИСС 31074 (Go, отдельный пункт).** Забрать 92 группы месячного ИПЦ за 2002–2026, каталог `series_catalog`, витрина `v_rosstat_*`, грант `kimi_reader`, `make mcp-check`. Критерий: 92 группы × месяцы, сверка агрегата `1` с `rosstat_ipc_mes` (допуск — округление источника), повторный прогон — no-op по гейту дат.

**L2 — spike BI (research/Go).** Определить прямой export-URL/формат CSV или Excel, условия использования, устойчивость guest-доступа; собрать:
- недельный агрегат ИПЦ 2019–2026 — закрывает 2022+ и 2019;
- недельные товары × субъекты РФ 2019+ — новый региональный слой;
- сверить пересечение 2019–2021 с `rosstat_ipc_weeks_bulletins` и 2022+ с `Nedel_ipc.xlsx` (где пересекается) — допуск на округление.

Критерий: агрегат 2019–2026 без пропусков, товарные ряды 2022+ и 2019, региональный разрез, as-of-оговорка (значения текущие, не винтажные).

**L3 — data request к ЦБ** на per-code МП (87 кодов × 3 индикатора). Критерий: получены файлы/API, зафиксированы винтажи и условия; без этого полный паритет CB_COMP не заявляется.

**Что не делать:** не пытаться восстановить 2009–2018 из BI (их там нет) и не считать месячный дашборд BI новым источником — месячный ИПЦ у нас глубже (с 1991).

## 7. Что не проверено

- Прямой export-URL BI и возможность автоматизации (UI-экспорт подтверждён, API — нет).
- Terms/robots BI, ЕМИСС и ЦБ для регулярного импорта.
- Полный SDMX-pull ЕМИСС 31074 с CSRF (проверены страница, формат и клиент, но не полный цикл).
- Live-веса ИПЦ 2025/2026: в архиве только 2016–2024; публичный источник весов не подтверждён.
- Региональный ИПЦ ГУ7 (`data_cpi_vvgu`) — публичный источник не найден.
- Винтажи/PIT: ни BI, ни ЕМИСС не дают as-of-срез; ревизии не отслеживаются.
