|---|---:|

## 5. PIT/as-of

| Правило | Значение |
|---|---|
| Cutoff месяца M | 8-е число M+1 |
| Доступность недельной точки | date + 2 |
| Доступность месячной метки | конец M+1 |
| Проверено месяцев | 155 (2013-10-01 … 2026-08-01) |
| Недельных дат в панели | 746 |
| Исключено точек `date+2 > cutoff` | 36 (не более 1 на месяц) |
| Нарушений | 0 |
| Пропущенных месячных меток | 0 |

Проверка: для каждого месяца берутся только недели с `date + 2 ≤ cutoff`; месячная метка `M` доступна не раньше конца `M+1`, поэтому на cutoff 8-го `M+1` не участвует. Официальные значения используются только ex post для сверки, не как признаки. Винтажного архива `rosstat_ipc_mes`/weekly нет: PIT проверен на уровне правила, а не фактических дат публикации.

## 6. Решение

**Hybrid «4 официальных компонента + признаки».** Покрытие 39,3 % < гейта 50 %, услуги — 29,0 %. Полный 88-групповой bottom-up на публичных данных не заявляется; частичный bottom-up допустим только как robustness-проверка с явно названным покрытием.

Следствия для Task 2–3:

- Task 2 может использовать 16 отраслевых листов как признаки; весового покрытия они не добавляют.
- Task 3 должен строить месячный m/m только на 118 совпавших рядах (39,3 %) и называть это частичной реконструкцией; гейт ≥50 % не пройден.
- Task 4 — hybrid-модель на 4 компонентах; full bottom-up не публикуется.

## 7. Ограничения и что не проверено

- **Покрытие 39,3 %**: полный 88-групповой bottom-up не построен; услуги покрыты на 29,0 %, это худший компонент.
- **Веса только 2016–2024**: для 2025–2026 используется 2024; публичных весов 2025–2026 в архиве нет.
- **Недельная панель разрежена**: 122 из 148 товарных рядов имеют разрыв >14 дней, 21 — >365 дней, 19 — >1000 дней; 37 рядов заканчиваются раньше 2026-10-12. Агрегат заканчивается 2021-12-27, в диапазоне 7 пропущенных месяцев.
- **Нет винтажей**: PIT/as-of — правило cutoff, а не фактические даты публикации и ревизии.
- **30 рядов не сопоставлены**: дженерики/бренды лекарств, снятые/переименованные позиции, отдельные услуги; alias-словарь не выдумывался.
- **МП: 16 листов не в ClickHouse**: в БД только «Экономика всего» (13 рядов `cbr_survey`); аудит читает публичный xlsx. Публичного mapping «отрасль → код ИПЦ» без 87 кодов ОКВЭД2 нет.
- **Сырая `rosstat_ipc_mes` закрыта грантом**: аудит использует `v_rosstat_macro`; это те же 4 ряда.
- **CB_COMP напрямую не сравнивался**: Task 1 — аудит публичной панели, не паритет; сравнение — Task 5.
- **Фактические даты публикации и ревизии** не проверены; `first_seen`/винтажного слоя для этих рядов нет.
