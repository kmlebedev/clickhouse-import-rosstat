## 4. КУ и вес

- **Их КУ против нашего:** NSA м/м (`Россия не SA`, 175 месяцев «факт») — **идентично нашему `ipc31074/Коммунальные услуги`** (max \|diff\| = 0): данные КУ у нас и у авторов один источник.
- **Как авторы вычитают КУ.** Их КУ SA (`Россия`) вне тарифных месяцев равен константе 0,327374 % (41 из 175 месяцев в точности; это и есть «4 %/год» прокси #396) и сглаживает тарифные скачки (июль 2024: NSA 9,92, SA 6,04). Их таргет = SA «все» минус вклад **SA-КУ**, а не NSA-КУ; поэтому наш `T_SAX` (X-13 по ряду без реального вклада КУ) отличается от `TARGET_FULL` даже при том же `w`.
- **Подразумеваемый вес** `w_t = (π_t − x_t)/(u_t − x_t)` из их SA-рядов (`π` — код `1`, `x` — `1 - 9470`, `u` — их КУ SA) на месяцах с \|u − x\| ≥ 1 п.п. (n = 7: 2019-01, 2019-07, 2022-03/04/07/12, 2024-07): медиана **0,061**, q25 0,030, q75 0,066, диапазон −0,066…0,068 — близко к весу ЖКУ СПР 0,061–0,065 из паритета #190 и **заметно ниже 0,10**.
- **Калибровка `w` по сетке 0,05…0,15** (RMSE `T_SAX` против `TARGET_FULL[1]`): fit-окно 2010-03…2018-12 минимум при 0,08 (0,0749); eval-окно 2019-01…2024-07 растёт с `w`: 0,05 → 0,069, 0,06 → 0,075, 0,08 → 0,088, 0,10 → 0,117, 0,15 → 0,222. По протоколу принят **0,08** (калибровка по fit-окну, а не по eval); eval-минимум (0,05) и подразумеваемый вес (0,06) указывают ещё ниже — это наблюдение **не** применялось (пересмотр `w` до 0,06 возможен только отдельной поправкой спеки).
- Результаты W4 получены с `w = 0,10` и не пересматриваются (Stage 1 не прошёл gate; пересчёт с 0,08 в этой постановке не планируется).

## 5. Что это значит для W5b

- Истина сравнения — `TARGET_FULL`; наши модели обучаются на `T_SAX` (w = 0,08, `aligned`), модель на `TARGET_FULL` (target-aligned) не требуется.
- **Расхождение целей — часть ошибки сравнения:** RMSE `T_SAX` против `TARGET_FULL` 0,088 (h1), 0,167 (h3), 0,260 (h6) при RMSE CB_COMP 0,159/0,444/0,971. Чтобы это не списывалось на модель, в W5b приводятся оба набора: ошибка против `TARGET_FULL` и ошибка против нашего `T_SAX` для наших моделей (справочно).
- Регрессионная база для W5b воспроизведена (0 расхождений с пинами).

## 6. Что не проверено и уточнения

- **Core** — кода `3` нет в доступных файлах архива; сверка core с «Базовым ИПЦ» ЦБ не выполнена.
- **Групповой уровень** (88 компонент, 1105 товаров) — не выполнен (панель CB_COMP только SA).
- **Вес ЖКУ из `cpi_weights_tovar.xlsx`** (протокол п. 4в) — ряд ЖКУ-группы в весах не найден по названию (есть только отдельные позиции, напр. «Обращение с ТКО»): не выполнено.
- **Уточнение после результатов:** протокол п. 5 не уточнял, при каком `w` оценивается `aligned`; решение принято по ряду с primary `w` после п. 4 (0,08) — `aligned`; при `w = 0,10` — `misaligned` (RMSE 0,117). Обе версии приведены; код сначала считал только `w = 0,10` и был дополнен до выбранного `w` после просмотра результатов.
- Окончательные ряды наши — 2026-й редакции данных, у авторов — 2024-й; сравнение винтажа на 2024-08 показывает, что на h1 разница мала (RMSE 0,115 против 0,117).
- Достаточно ли `T_SAX` как обучающей цели для h3/h6 (RMSE цели 0,167/0,260) — вопрос W5b.
