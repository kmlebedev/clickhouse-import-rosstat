## 5. Причины пробелов на stage и runbook исправления (не выполнялся)

| Пробел | Причина | Что сделать |
|---|---|---|
| `comex_front` отсутствует | ingest-endpoint на stage не развёрнут; COMEX пишется только через `POST /v1/gold_prices` | развернуть ingest на stage и залить историю COMEX; либо переключить панель цены на `bold` (есть на stage) и добавить оговорку «bold — прокси, не COMEX» |
| `v_cb_gold_dynamics` NULL | XLSX WGC не лежат в `/root/dagu/wgc/data/` (каталога на stage нет) | `scp wgc/data/Changes_latest_as_of_Oct2026_IFS.xlsx wgc/data/World_official_gold_holdings_as_of_Oct2026_IFS.xlsx palmshell:/root/dagu/wgc/data/`; затем `CLICKHOUSE_IMPORT_STAT=wgc_cb_reserves` бинарником на stage; проверить `v_cb_gold_dynamics` |
| `v_gold_dashboard` NULL | ручные ряды пишутся только через ingest (`POST /v1/manual_series`), которого на stage нет; `distillate_stocks` должен приходить из EIA | развернуть ingest или применить seed ручных рядов; прогнать `eia`; проверить `stale` |
| `v_eia_petroleum` пуста | шаг `eia` не отработал / нет ключа | `CLICKHOUSE_IMPORT_STAT=eia` на stage; проверить `v_eia_petroleum` |
| `v_bls_macro` пуста | шаг `bls` не отработал / нет ключа | `CLICKHOUSE_IMPORT_STAT=bls` на stage; проверить `v_bls_macro` |
| `v_forecast_accuracy` пуста | в `v_forecast_accuracy` 0 строк; сырой `forecast_log` под `kimi_reader` закрыт — проверять `default`-пользователем; возможно, журнал пуст или строки не созданы ingest'ом | после появления записей журнала — `make import STAT=forecast_resolve`; проверить `is_resolved` |
| Дашборд цены на stage пуст | панель жёстко фильтрует `series='comex_front'` | либо бэкфилл COMEX, либо `coalesce(comex_front, bold)` в панели (код `grafana/gold_thesis.go`, `make grafana-build`) |

**Важно:** это операционные действия на общем staging-хосте; без отдельной просьбы владельца они не выполнялись. Аудит — read-only.
