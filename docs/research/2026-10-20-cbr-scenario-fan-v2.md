## 1. Что изменено относительно Task 1

Task 1 строил веер из абсолютных шагов `cbr_rule`; shock-слой улучшал CRPS, но coverage 80 % был 0.429, потому что центр наследовал смещение отвергнутого правила. Task 3 меняет ядро:

1. **Ядро** — `ordered_logit` (primary): `m_t = E[step]`, вероятности классов; walk-forward 84/68 фолдов. ML-челленджер — `ElasticNetCV` на признаках `CbrRow`; CatBoost на 108 решениях не используется.
2. **Сценарии КПМ** — центрированные дельты `δ_s = step_s − mean(step_s)`, `Σδ_s = 0`: `budget`, `inertial`, `rational`, `hard`, `no_market_loans` добавляют форму, не сдвигают центр.
3. **Остатки и дисперсия** — `e = факт − m_t` только по прошлым фолдам; квантили 0.05…0.95; три модели: `disp_global` (ablation), `disp_scale` (`log|e| ~ 1−w + p`, primary), `disp_conformal` (robustness).
4. Веер: `point = m_t + δ_s + q_α(t)`, 5×7 = 35 точек, веса 1/35.

## 2. Данные и выборка

- 108 решений `2014-02-14 … 2026-09-11`; пропусков нет.
- Ядро: expanding 84 фолда, rolling40 — 68.
- **Веер: 72/56** — первые 12 фолдов на окно уходят на residual warm-up (`MIN_RESIDUALS=12`), потому что нужны прошлые остатки ядра. `fan_fold` skip — 0; `residual warm-up` — 24 (12 × 2 окна); `scale_fallback` — 0.
- As-of: CPD — конец M+1; ВВП — конец квартала + 3 месяца; консенсус — волна + 6 дней; бюджет — конец M+1; веса/вероятность шока — walk-forward. PIT/винтажей нет.

### 3.3. Дисперсия: что сработало

`disp_scale` коэффициенты (среднее по 128 фолдам): **γ0=3.7677, γ1=0.1322, γ2=−2.7206**.

- **`disp_scale` не улучшил `disp_global`:** CRPS 60.761 vs 60.358, coverage 80 % 0.736 vs 0.764. Отрицательный γ2 означает, что рост `p_t` **сужает** интервал — экономически сомнительно; модель масштаба не подтверждена.
- **`disp_conformal` — лучший coverage:** 0.806 (expanding) и 0.821 (rolling40), CRPS 60.598/81.778; цена — шире интервал (203.57/508.48), особенно на rolling40.
- **`core_fan_ml` — лучший RMSE** (153.14), но CRPS 61.378 и coverage 0.736; ML-челленджер не лучше ordered logit по распределению.
- **`core_fan_scale` — primary по предзарегистрированному правилу** (coverage 0.736 в [0.70; 0.90], Wilson CI [0.624; 0.824] включает 0.8; Task 1 значимо лучше; CRPS/RMSE не хуже ordered). Но point estimate ниже 0.8, и `conformal`/`global` выглядят лучше — следующий шаг.

## 4. Вердикт и следующий шаг

**`promote`** по предзарегистрированному правилу: coverage 80 % 0.736 [0.624; 0.824], Task 1 ΔCRPS −51.86 (значимо), CRPS/RMSE не хуже `ordered_logit`. Это лучший результат трека: Task 1 102.97 → v2 60.76 CRPS, 204.49 → 155.01 RMSE; веер впервые конкурентоспособен с точечными бенчмарками по CRPS.

**Оговорки и следующий шаг:**

1. **Coverage ниже номинала:** point estimate 0.736; `conformal` 0.806 и `global` 0.764 лучше. Следующая итерация — primary `disp_conformal` (или `disp_global`) с проверкой на 2022–2023; `disp_scale` с отрицательным γ2 не promotion-кандидат.
2. **2022–2023 не закрыт:** coverage 0.600–0.650; нужен либо более сильный core (ML/структурные признаки), либо условная дисперсия по режиму, а не по `p_t`.
3. **ML-челленджер** даёт лучший RMSE (153.14), но не CRPS; в primary не входит.
4. **Task 2 (CPI, #285)** — следующий отдельный PR; #269 — robustness.

## 5. Что не проверено

- PIT/винтажи CPD, ВВП и Минфина; бюджетный лаг консервативный.
- Сценарные дельты `cbr_rule` — reduced-form прокси, не QPM; центрирование убирает уровень, не шум.
- `disp_scale` — 2 признака; отрицательный γ2 не объяснён; conformal нарушает exchangeability временного ряда.
- 2014/2015 — в train, не тесте.
- Множественные сравнения: primary один (`core_fan_scale`, expanding); остальные — robustness, p-value без поправки.
- Многозаседаний путь, CPI-веер, quantile regression/CQR — вне Task 3.
