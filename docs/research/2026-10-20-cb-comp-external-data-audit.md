# Данные авторов CB_COMP vs live-витрины: аудит (2026-10-20)

> **Объект:** `BusinessSurveyCBRCpiForecastingSourceCode/Models/CpiComponents/StfCpi_External_data` (локальная копия архива авторов, 538 МБ).
> **Задача:** инвентаризировать данные, которые использует production-пайплайн авторов, и сверить с тем, что есть в live-витринах ClickHouse; явно назвать отсутствующее.
> **Метод:** `find`/`pandas`/`openpyxl`/`xlrd` по архиву; MCP ClickHouse (`kimi_reader`) по витринам; дата среза — 2026-10-20.
> **Границы:** не все 42 листа «Краткосрочных экономических показателей» и продуктовые `Prom_*.xlsx` разобраны построчно; `fedstat` и `monitoring_db` в архиве отсутствуют (только README).

---

## 1. Короткий вывод

Авторы используют четыре класса данных:

1. **Сырые МП по 87 кодам** (`monitoring/monitoring_db`) — в архиве **только README**: «распространение оригинальных данных только по запросу». Это главный блокер live per-BSU.
2. **88 компонентных SA-рядов ИПЦ и SA-таргет** (`cpi_sa_target_history.xlsx`, `cpi_components_sa` из NMFI) — в live-витринах их нет; есть только 4 официальных компонента ИПЦ NSA.
3. **Сырой Росстат/Fedstat** (`fedstat`, `Prom_*.xlsx`, `sales_dynamics.xlsx`, «Краткосрочные экономические показатели», ручные `ИПСХ/Молоко/Яйца`) — в live-витринах покрыт частично: ИПЦ, зарплата, рабочая сила, ВВП; нет ИПП, розницы, сельхозпроизводства, инвестиций.
4. **Рынок/ставки/ФАО** — USD, RUONIA, ключевая ставка, кредиты, ОФЗ, золото, FRED есть; **Brent, Urals, VIX, RVI, медь, CRB, реальный FAO** — нет.

Поэтому live-пайплайн воспроизводит структуру, но не полный набор признаков и не 88-компонентную SA-модель.

## 4. Критические разрывы

**P0 — без этого полный CB_COMP/live per-BSU невозможен:**

1. **Per-code MP** (`monitoring_monitoring_db`): в архиве только README, данные — по запросу. Публичная книга даёт 33 листовые серии; любые per-BSU-признаки на live — это per-sheet.
2. **88-компонентный SA-ряд и SA-таргет** (`cpi_components_sa` NMFI, `cpi_sa_target_history.xlsx`): live нет; официальный ИПЦ — 4 компонента NSA.
3. **Сырой Fedstat** (ИПП, розница, сельхоз, инвестиции): в архиве только README, данные — по запросу.

**P1 — публичные live-источники, которые можно добавить импортёрами:**

4. **Росстат/ЕМИСС**: ИПП, розничные продажи, сельхозпроизводство, инвестиции, строительство; `Prom_*.xlsx`, `sales_dynamics.xlsx`, «Краткосрочные экономические показатели».
5. **Рынок**: Brent, Urals, VIX, RVI, медь, CRB. USD, золото, ОФЗ, FRED уже есть.
6. **FAO real**: в live-источнике ФАО есть deflated-серия; в витрине только nominal.

**P2 — инфраструктура и регионы:**

7. **Региональный CPI/веса для ДФО**: в live-витринах нет; есть только ипотечные кредиты по федеральным округам.
8. **Live-веса и словари 2025/2026**: ОКАТО, ОКЕИ, ОКВЭД↔ОКПД2, платные услуги, стандартизация; сейчас — архив 2024.
9. **ЖКУ-прогноз 2026**: архивный файл заканчивается 2025-05.
10. **88-групповые модели**: 2 208 RDS в архиве; live-пайплайн обучает 3 компонента.
