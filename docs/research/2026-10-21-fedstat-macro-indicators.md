# Fedstat (ЕМИСС): ИПП, розница, сельхоз, инвестиции и `31074_ru_only` — исследование (2026-10-21)

> **Объект:** публичные индикаторы ЕМИСС `fedstat.ru` для пяти блоков — индекс промышленного производства (ИПП), оборот розничной торговли, продукция сельского хозяйства, инвестиции в основной капитал и ИПЦ (индикатор 31074, фильтр «только РФ»).
> **Задача:** найти точные идентификаторы индикаторов, получить ряды/таблицы, зафиксировать покрытие, ограничения и пригодность для импорта.
> **Метод:** live-пробы страниц `fedstat.ru/indicator/<id>`, CSRF POST `downloadData.do?format=excel` (XLS) с cookie сессии; резервный формат — SDMX XML; сверка агрегата ИПЦ с витриной `v_rosstat_macro` через MCP ClickHouse (`kimi_reader`); разбор XLS — `xlrd` (изолированная установка в `/tmp`).
> **Границы:** только РФ (без регионов); полная выгрузка всех лет и всех разрезов не заявляется; terms/robots юридически не проверялись; винтажей/PIT нет.

## 4. Винтажи, ревизии, PIT

- Источник отдаёт **текущее значение**; архива версий и `published_at` нет.
- `31074` и остальные индикаторы могут ревизоваться Росстатом без отдельного винтажа; повторный прогон увидит новую версию, но старую не сохранит.
- Для честного PIT нужен собственный append-only snapshot с `loaded_at`/`observed_at`; в этом прогоне он не строится.
- Даты в отчёте — **начало периода** (`YYYY-MM-01`, квартал — первый месяц, год — `YYYY-01-01`), а не дата публикации. Для `31074` фактическая публикация — 6–10-й рабочий день после отчётного месяца; для ИПП — 16–20-й; для розницы — 19–23-й рабочий день через 3 месяца (годовая) и позже (месячная).

## 5. Риски и режимы отказа

| Риск | Следствие / лечение |
|---|---|
| 503 при серии POST | пауза 30 с, backoff 30/60/120 с; при длительной серии — временный обрыв GET (наблюдалось 2026-10-21), пауза ≈5 мин и повтор |
| HTTP 200 + HTML «Нет данных для выбранного сочетания признаков» | это не пустой ряд, а невалидная комбинация; переключить код РФ/год или зафиксировать пробел |
| Смена определения РФ в 2023 | два кода `1688487`/`1849012`; не смешивать в одну линию |
| ОКВЭД1 → ОКВЭД2 | `43046` (2000–2016) и `57806` (2015–2026) — разные классификаторы; overlap 2015–2016 (24 месяца) даёт **mean abs diff 1,05 п.п., max 3,8 п.п.** по общему ИПП (м/м) — ряды не идентичны; склейка только с явным разрывом/поправкой, не бесшовно |
| `43337` «окончательные данные» | пробы 2023/2024 не дали данных; фактическая выгрузка — 1990–2011, при этом паспорт заявляет 1990–2025; не выдавать фильтр за данные |
| `34128` | начинается с 2018; более ранняя история — только годовые `31062`/`59001` |
| `58089`/`58090` | начинаются с 2017; история до 2017 — другие индикаторы (`34129`/`34130`/`34475`/`40562`) с иной методологией. В `58090` 2024 г. | Ревизии | источник не даёт винтажей; PIT не заявляется |
| Terms/robots | юридическая проверка не выполнена; research-only, не production-импорт |
