## 6. Что это значит для #419

- **G11 пройден:** очищенный `agg_ex` + сезонность — первый недельный кандидат, который значимо лучше `combo3` на h1 в арене без шока 2022. `wk_mix_ex` — победитель (p = 0,00034), `wk_agg_ex` — второй (p = 0,0040).
- **Сезонность обязательна:** без месячных дамми эффект исчезает; это подтверждает диагноз ревью (NSA-агрегат против SA-цели).
- **`combo3_wk`** (групповые признаки) тоже значим на 2023+ (p = 0,0073); Task 4b не выбирает между ним и `wk_mix_ex` — для Task 5/7 можно рассматривать оба, но `wk_mix_ex` сильнее по MCS.
- **Не паритет с CB_COMP:** истина — `T_LIVE`; сравнение с CB_COMP по SA ЦБ не заявляется. `agg_ex` — прокси (83,1 % ЖКУ, нет сетевого газа/ТКО), не официальный ряд.
- **Промоушен:** решение владельца; production/shadow, `forecast_log`, h2/h3/h6 не заявляются.
