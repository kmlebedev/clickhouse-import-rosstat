# Инфляционные ожидания: история с 2017 — источник и разбор (2026-11-14)

> **Объект.** Бюллетени ЦБ «Инфляционные ожидания и потребительские настроения населения» (инФОМ), волны 2017–2022.
> **Задача.** Найти архив волн и оценить, каким разбором из них достаются ряды `cbr_infl_exp` (research-поток R3 [плана роя](../superpowers/plans/2026-11-14-key-rate-coverage-swarm.md), issue [#575](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/575)).
> **Метод.** Пробы `cbr.ru/analytics/dkp/inflationary_expectations/` 2026-11-14, разбор страницы наволн, скачивание четырёх волн разных эпох, `pdftotext -layout` и `pdftotext -bbox`.
> **Границы.** Проверены 4 волны из 154; значения с независимым источником не сверялись.

## 1. Короткий вывод

1. **Архив волн на странице полный: 154 волны, 13-09 … 26-10.** 58 из них (22-01 и позже) — страницы `.../Infl_exp_ГГ-ММ/`, остальные — прямые PDF `/Collection/Collection/File/<id>/Infl_exp_ГГ-ММ.pdf`. Волна 2017-01 доступна: `/Collection/Collection/File/26997/Infl_exp_17-01.pdf` (HTTP 200, 4 312 151 байт).
2. **Графики старых бюллетеней — картинки**, координатного слоя нет: у PDF 17-01, 21-12, 19-06, 22-12 `pdftotext -bbox` первой страницы даёт 11–19 слов. Поэтому текущий парсер `cbr/Infl_exp_pdf.go` (разбор подписей у точек графика в «Оперативной справке») **к старым волнам неприменим**.
3. **Числа есть в тексте, но в двух разных формах:** таблица (19-06, 21-12 — «Табл. 1. Динамика индикаторов инфляционных ожиданий» с рядами `Инфляция, наблюдаемая населением, %` и `Инфляционные ожидания населения, %`) и проза (17-01: «…медианное значение … составила 11,5%»; 22-12: «медианная оценка составила 16,3%»).
4. **Текущая книга XLSX историю не содержит, но БД уже глубже книги.** Глубина книги (`Данные для графиков`) — с 2023-01; на момент первой редакции документа (до T3) в `cbr_infl_exp` было 46 точек на ряд, 2023-01-14 … 2026-10-14. Снимок БД **2026-11-14** (SQL в §7): **88 точек на ряд, 2019-01-14 … 2026-10-14** — после документа догнал импортёр истории T3 (#587), который забрал 2019–2022 из архива волн; это не ошибка источника и не новая глубина книги. Волны **2017–2018** по-прежнему доступны только в архиве, поэтому цель `min(date)=2017-01-14` остаётся невыполненной.

## 4. Рекомендация и критерий приёмки (T3)

**Go, двухступенчатый разбор:**

1. **Таблица (приоритет).** Искать в тексте блок `Динамика индикаторов инфляционных ожиданий` / `Табл. 1` и строки `Инфляционные ожидания населения` и `Инфляция, наблюдаемая населением`; значения — по колонкам месяцев.
2. **Проза (фолбэк).** Регулярка по предложению с «медианн… оценк… составила X%» — только ожидания (наблюдаемая в прозе часто не названа).
3. **Fail-fast на волну:** не найдено ни таблицы, ни предложения — ошибка с именем волны, а не «0 строк». Волны без числа (скан, смена вёрстки) перечисляются в логе прогона.

**Критерий:** `min(date) = 2017-01-14` (14-е число месяца волны — конвенция `cbr_infl_exp`), оба ряда одной длины, повтор — no-op. На снимке 2026-11-14 достигнуто `2019-01-14` (T3 закрыл 2019–2022); 2017–2018 ещё нет.

**Оценка:** 1,5–2 p-d: два парсера, фикстуры на эпоху, ручная сверка ≥10 волн.

## 5. Риски

- **Разные месяцы в таблице и в прозе.** Таблица даёт ряд по месяцам, проза — только текущую волну; смешивать нельзя: приоритет таблицы, проза только для волн без таблицы.
- **Методика инФОМ менялась** (формулировки вопроса, медиана vs среднее) — до 2020 числа могут быть несопоставимы; это ограничение ряда, а не разбора, и должно попасть в `series_catalog.description`.
- **Скан-волны.** Часть PDF может быть без текстового слоя (так выглядит `inFOM_25-10.pdf`) — такие волны пропускаются с явным сообщением.

## 6. Что не проверено

- Наличие таблицы во всех 154 волнах (проверены 4).
- Сверка 11,5 % (17-01) и 16,3 % (22-12) с независимым источником (пресс-релиз, дашборд ЦБ).
- Поведение страниц волн 22-01+ (проверена только 22-12; PDF у неё — `/Collection/Collection/File/43585/Infl_exp_22-12.pdf`).
- Совместимость рядов 2017–2019 с 2023+ по методике.

## 7. Команды

```bash
UA='Mozilla/5.0'
curl -s -A "$UA" 'https://www.cbr.ru/analytics/dkp/inflationary_expectations/' -o infexp.html
grep -oE 'Infl_exp_[0-9]{2}-[0-9]{2}' infexp.html | sort -u | head

pdftotext -bbox -f 1 -l 1 ie_17-01.pdf - | grep -c '<word '
```

Снимок БД (2026-11-14, `kimi_reader`, только SELECT):

```sql
SELECT series, count() AS n, min(date) AS min_date, max(date) AS max_date
FROM default.v_cbr_macro
WHERE series IN ('наблюдаемая инфляция', 'ожидаемая инфляция')
GROUP BY series
ORDER BY series;
```

Результат на 2026-11-14: оба ряда — **88 строк, 2019-01-14 … 2026-10-14**. `v_cbr_macro` — витрина над `cbr_infl_exp`; 46 → 88 — догон T3 (#587) из архива волн, а не изменение книги или ошибка источника.
