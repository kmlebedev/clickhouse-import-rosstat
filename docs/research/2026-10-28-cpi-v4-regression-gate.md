## Обновление: эталон переустановлен, гейт пройден

По решению владельца (спека [§7.1](../superpowers/specs/2026-10-28-cpi-v4-weekly-aggregate-core-design.md), отдельный коммит `bceae21`) эталоном гейта Task 4 стали **текущие RMSE v2/v3 и `feature_sha256` на данных 2026-10-28**; числа Stage 1 — историческая справка (таблица ниже сохранена как есть).

- Повторный полный прогон `make cpi-v4-leaderboard ARGS="--gate"`: **гейт пройден** — все 8 моделей в допуске 1e-6 (Δ < 1e-9), 17 признаков v3 совпали с эталонными отпечатками.
- Детерминизм: три полных прогона подряд дали одинаковые RMSE всех моделей; sha256 предсказаний второго и третьего прогонов совпал (`cbe63ba9c21a6d22…`).
- **Оговорка:** эталон получен *после* наблюдения результата. Он проверяет воспроизводимость и неизменность входов, но не подтверждает правильность прежних чисел Stage 1 и не объясняет их расхождение (причина дрейфа — не установлена; ведущая гипотеза — ревизии `*_sa` МП/FAO/USD). При следующем расхождении гейта эталон не переустанавливается молча: сначала диагностика по `feature_sha256`, затем отдельная поправка спеки.
- Tasks 5–7 разблокированы; их сравнения идут на общих фолдах с `v2_bottomup`/`v3_bottomup` текущих данных, без сопоставления со Stage 1 по времени.

Ниже — исходный отчёт о провале гейта против Stage 1 (состояние до переустановки эталона).

5. **Ведущая гипотеза (не доказана):** ревизии исторических значений входов. Кандидаты — `*_sa` ряды МП `cbr_survey` (сезонная корректировка пересчитывается с каждой новой точкой), FAO (ИПЦФ ревизуется), `usd_mm`/`key_rate` (дубли `cbr_currency_usd` в аудите 2026-10-16). Разошлись фолды с самого начала окна (2024-01), значит менялась история, а не только хвост.

## Что сделано для диагностики

- Гейт теперь сохраняет `feature_sha256` — sha256 значений каждого признака по месяцам (`cpi_v4_gate.json`): при следующем расхождении оно называет признак, а не только «выборка изменилась». Для текущего состояния данных отпечатки записаны (`build/cpi-v4/cpi_v4_gate.json`, sha256 предсказаний `cbe63ba9c21a6d22…`).
- `--models B1,B3` — частичный гейт для быстрой диагностики; помечается `partial` и не заменяет полный.
