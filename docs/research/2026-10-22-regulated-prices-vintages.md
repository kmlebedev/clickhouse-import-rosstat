# Регулируемые цены и тарифы, влияющие на ИПЦ: источники и винтажи (2026-10-22)

> **Объект:** плановые и утверждённые решения по регулируемым ценам/тарифам и ценовым ограничениям, которые влияют на ИПЦ: ЖКУ (газ, электроэнергия, тепло, вода/водоотведение, ТКО, совокупный платёж), плата за содержание жилья (УК), а также прочие административные цены (ж/д, связь, ЖНВЛП, минимальные цены алкоголя/табака, ОСАГО, региональные надбавки).
> **Задача:** найти источники с винтажами, проверить доступность и машиночитаемость, сравнить выпуски, оценить покрытие фактами в БД и дать go/no-go с handoff.
> **Метод:** live-пробы 2026-10-22 (curl с `Referer`, `pdftotext -layout`, `sha256`, SQL через MCP `clickhouse` только по витринам `v_*`); сравнение трёх винтажей прогноза Минэка; сверка с фактическими рядами ЕМИСС.
> **Границы:** не проверялись полные региональные реестры тарифов, платные базы («КонсультантПлюс» целиком), юридические terms/лицензии источников, старые винтажи глубже 2025–2027; УК — только федеральное право и выборочные примеры, не полный реестр муниципальных актов.

---

## 1. Короткий вывод

1. **Главный источник плановых тарифов — годовой прогноз СЭР Минэкономразвития.** В PDF на 2027–2029 (сентябрь 2026) есть готовая таблица «Прогнозируемые изменения цен (тарифов) на продукцию (услуги) компаний инфраструктурного сектора» (PDF-с. 29–30) с газом, электроэнергией (передача, сетевые компании, население), теплом, водой, водоотведением, совокупным платежом граждан и датами индексации. В открытом доступе лежат три винтажа: сентябрь-2025, апрель–май-2026 (сценарные условия) и сентябрь-2026. Это делает **go** для P0-слоя «плановые тарифы» реальным без Wayback.
2. **Винтажи различаются принципиально.** Совокупный платёж на 2027: 8,7 % в сентябре-2025 → **11,0 %** в сентябре-2026; электроэнергия для населения: 8,6 % → **14,4 %**; газ: 9,1 % → **10,4 %**; тепло: 9,3 % → **10,2 %**. Без винтажного ключа «план на 2027» неотличим от прошлогоднего плана.
3. **Утверждённые индексы 2026 — распоряжение № 3413-р от 25.11.2025:** с 01.01.2026 — 1,7 % во всех субъектах, с 01.10.2026 — средние по субъектам **8,9–19,8 %**, отклонения по муниципалитетам — до **21,9 %**. На 2027 год распоряжения на 2026-10-22 в открытых источниках **не найдено**: 11 % с 01.07.2027 — только прогноз; документ ожидается в ноябре–декабре 2026.
4. **ФАС:** приказ № 789/25 от 10.10.2025 (2026, территории вне ценовых зон) и приказ № 783/26 от 12.10.2026 (2027, население по субъектам РФ, PDF). По 68 разобранным строкам таблицы 783/26 медианный шаг с 01.07.2027 — **14,3 %**, средний — 15,0 %, что близко к прогнозным 14,4 %.
5. **ЦБ:** ОНДКП-2027 (проект от 30.09.2026, 227 с.) даёт нарратив, а не таблицу по секторам. «15,0 %» в тексте — не национальный совокупный индекс 9,9 %; это другая величина (среднее по региональным повышениям), её методика в ОНДКП не раскрыта — разводить.
6. **УК:** федерального предельного индекса на плату за **содержание жилого помещения** нет. По ст. 156 ЖК РФ её устанавливают собственники на общем собрании; предельные индексы по ст. 157.1 — только про **коммунальные услуги**. Законопроект № 1272398-8 ограничивает периодичность индексации платы за коммунальные услуги, а не тариф УК. Вывод: **no-go для федерального импортёра УК**; P1 — трекинг законопроектов, P2 — региональные/муниципальные акты; прокси Росстата — только «содержание и ремонт» в гос./мун. фонде.
7. **Факты уже в БД, но с дефектами:** `v_fedstat_ipc` (31074) даёт ЖКУ, жилищные и коммунальные услуги, воду, электроэнергию и содержание жилья; `v_fedstat_weekly_prices` (37426) — отопление, воду, электроэнергию, сжиженный газ и плату за жильё в рублях. Отдельных рядов по **теплу** и **сетевому газу** нет; агрегат «Жилищно-коммунальные услуги» обрывается на 2021-12.
8. **PIT для фактов не заявляется:** у ЕМИСС/Росстата нет винтажей, ревизии не отслеживаются. Для планов PIT возможен по `release_date`/`published_at`; для фактов — только append-only с даты первого импорта.

**Рекомендация:** P0 — **go** (`minec_forecast`, `government_decree`, `fas_order`, mapping фактов); P1 — **go только для ж/д** (та же таблица Минэка), остальное — **no-go/defer**; УК — **no-go на федеральный источник**. Импортёр — отдельным Go-пунктом после этого research.

### 4.3. PIT и ревизии

- **Планы:** `release_date` + `published_at` (дата публикации страницы, если известна) + `vintage`. Один и тот же `(indicator, year, effective_from)` лежит в таблице столько раз, сколько выпусков его напечатало — это и есть винтажность.
- **Факты:** у 31074/37426 винтажей нет; ревизии не отслеживаются. `loaded_at` можно писать только с даты первого импорта; заявлять PIT за 2002–2021 нельзя.
- **Сверка «план vs факт»:** допустима только по `effective_from` и с оговоркой, что CPI — не административный индекс. Сравнение «план 9,9 % vs CPI 9,9 %» без этой оговорки — ложная точность.
- **Даты вступления** — отдельное измерение: в 2025–2026 индексация сдвигалась (июль → октябрь), в 2027 — снова 1 июля. Без `effective_from` ряд «год → процент» теряет смысл.

### 6.2. Handoff для Go-пункта

**Таблица (черновик DDL):**

```sql
CREATE TABLE IF NOT EXISTS tariff_plan (
    source         LowCardinality(String),  -- minec_forecast | government_decree | fas_order
    indicator      LowCardinality(String),  -- gas_wholesale_all | gas_population | gas_transport
                                            -- | electricity_enes | electricity_grid_population
                                            -- | electricity_grid_other | electricity_population
                                            -- | heat | water | sewage | combined_payment
                                            -- | housing_maintenance | rail_freight | rail_passenger
    region         LowCardinality(String) DEFAULT '',  -- '' — РФ; иначе субъект/муниципалитет
    year           UInt16,                  -- тарифный/прогнозный год
    effective_from Date,                    -- 01.01 / 01.07 / 01.10 / 01.12
    value          Float64,                 -- процент или коп./кВт·ч; единица — в unit
    unit           LowCardinality(String),  -- percent | rub_per_kwh | rub_per_gcal
    release_date   Date,                    -- дата выпуска/публикации
    published_at   DateTime,                -- as-of; 0/NULL — неизвестно
    url            String,
    vintage        String                   -- человекочитаемый ID выпуска
) ENGINE = ReplacingMergeTree
ORDER BY (source, indicator, region, year, effective_from, release_date);
```

**Витрины:** `v_tariff_plan` (long, с комментариями таблицы и колонок), `v_tariff_plan_latest` (`argMax(value, release_date)` по ключу без `release_date`); `GRANT SELECT` — `sql/mcp_kimi_reader.sql`.

**Парсеры:**
- `minec_forecast`: `pdftotext -layout`; колонки — по годам из шапки, строки — по подписям; даты — из ячеек «с 1 июля / с 1 октября»; fail-fast на пропавшую строку/год.
- `government_decree`: HTML-таблица legalacts; строки — субъекты, два значения (январь/октябрь); fail-fast на нечисловое значение.
- `fas_order`: PDF-таблица; 4 числовых столбца (январь min/max, июль min/max), единица — коп./кВт·ч; fail-fast на пропавший субъект.

**Расписание:** месячная проверка + событийный запуск после публикации (сентябрь — прогноз, октябрь — ФАС, ноябрь–декабрь — распоряжение). Dagu-шаг с retry; no-op по `release_date` + `url`/`sha256`.

**Тесты:** фикстуры — урезанные PDF трёх винтажей и FAS (только таблица), HTML 3413-р; ожидаемые числа из §4.2; идемпотентность по `release_date`; fail-fast на пропавшую строку; без сети.

**Критерий приёмки Go-пункта:** три источника дают строки; повтор — no-op; `v_tariff_plan` отдаёт P0-набор; `make all`, `make mcp-check`, `make docs-check` зелёные; протокол — комментарием в PR. Оценка — 2–3 pd.

## 7. Что не проверено

- Полные региональные реестры тарифов (89 субъектов) и муниципальные ставки УК — вне объёма; проверены только федеральные акты и 2–3 примера.
- Точная дата утверждения сценарных условий (апрель–май 2026) — по PDF-метаданным 07.05.2026, по странице не подтверждена.
- Наличие/отсутствие проекта распоряжения на 2027 на `regulation.gov.ru` — не проверено; проверено только отсутствие финального акта в legalacts/FAS.
- Юридические terms/лицензии `economy.gov.ru`, `fas.gov.ru`, `legalacts.ru` — не проверены; в документе нет утверждения о праве на перепубликацию.
- Старые винтажи (2024 и раньше) — не проверялись; Wayback не использовался.
- P1-источники (ЖНВЛП, минимальные цены, ОСАГО, связь, региональные надбавки) — инвентарь по правовой природе, live-пробы не делались.
- Факт октября 2026 — ещё не опубликован; недельные 37426 начинаются 2026-10-05, дошаговой точки нет.
- `cb-comp-proxy` (2026-10-18) утверждает «нет ЖКУ за 2019–2021»; после импорта 31074 ряд есть до 2021-12 — утверждение устарело. Это **дефект существующего research**, а не данных; нужен отдельный bug/roadmap item, в этом документе код и старые отчёты не правятся.
