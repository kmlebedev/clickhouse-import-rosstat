## Вывод

**Не паритет.** На прокси-таргете RMSE нашего месячного nowcast systematically выше опубликованных RMSE CB_COMP:

- без МП: **0.233 / 0.471 / 0.714 / 1.316** против 0.20 / 0.39 / 0.59 / 1.05 (h = 1/2/3/6), отношение **×1.16 / ×1.21 / ×1.21 / ×1.25**;

Все точки вне margin δ = 10 % (issue #190), то есть по зафиксированному критерию это «не близко». **DM/TOST не считались**: опубликованы только агрегатные RMSE, помесячных ошибок CB_COMP у нас нет; сравнение отношений — описательное, а не тест эквивалентности.

Дополнительный — и главный — ограничитель: на прокси наш nowcast **не даёт выигрыша над наивной инерцией** на h = 1–3. На h = 1 он практически равен B1 last value (0.233 против 0.234) и чуть хуже AR(1) (0.230); на h = 2–3 хуже обоих (0.471/0.714 против 0.464/0.714 у B1 и 0.458/0.699 у AR(1)). Выигрыш появляется только на h = 6 (1.316 против 1.591 у B1). Это согласуется с тем, что прокси — сглаженный агрегат, а наш nowcast обучен на несглаженном общем ИПЦ: перенос сигнала на SA-таргет почти не добавляет информации сверх инерции.

## Прокси-таргет

Тождество: если `π` — SA ИПЦ с КУ, `u` — SA ЖКУ, `w_u` — доля ЖКУ в ИПЦ, то

```
π_ex = (π − w_u·u) / (1 − w_u).
```

Компоненты food/nonfood/services после подстановки сокращаются: `π = w_f·π_f + w_n·π_n + w_s·π_s`, `w_s = w_s_ex + w_u`, поэтому исключение ЖКУ не требует отдельного ряда услуг. Компоненты используются для **контроля**:

- NNLS-веса на train 2009-01…2018-12: `cpi_food` 0.3796, `cpi_nonfood` 0.3659, `cpi_services` 0.2545, сумма 1; RMSE восстановления агрегата 0.0079 п.п.;
- альтернативные веса из SAAR-компонент: 0.3785 / 0.3528 / 0.2687, RMSE 0.0075 п.п. — согласованы;
- SA ИПЦ ЦБ против `saar_all_goods`→м/м: RMSE 0.0245 п.п., max 0.1443, n = 152;
- проверка тождества «SAAR-агрегат vs взвешенные компоненты»: RMSE 0.0119 п.п., max 0.0790, n = 153.

**Допущения:**

- `w_u = 0.10` (ЖКУ ≈ 9–10 п.п. ИПЦ; услуги ≈ 27.7 % в структуре 2023 г., из них ЖКУ — примерно треть). Чувствительность: 0.05–0.15.
- `u` — постоянный рост 4 %/год (`0.3274 %/мес`). Публичного месячного ряда ЖКУ за 2019–2021 в БД нет: недельные средние цены (`rosstat_ipc_weeks`) начинаются 2022-01-10 и окно статьи не покрывают. Постоянный `u` после калибровки **неидентифицируем** — он входит в таргет константой и поглощается свободным членом; чувствительность к 0/4/8 %/год нулевая (см. ниже).
- Следствие: прокси — **масштабированный SA-агрегат** `π/(1−w_u)` минус константа (масштаб 1.111). Он не воспроизводит ЖКУ-шоки (январская/июльская индексация тарифов), X-13, веса СПР и 88 групп статьи. Это **не** строгий таргет CB_COMP.

## Метод

Для каждого h на train 2009-01…2018-12 (120 месяцев; прокси доступен с 2002, прогнозы — с 2006) оценивается прямой перенос:

```
cum_h(t) = a_h + b_h·nowcast_t + c_h·π_ex_{t−1} + ε_t,
cum_h(t) = Σ_{j=0}^{h−1} π_ex_{t+j}.
```

Кумулятивная цель train-строки не выходит за train (для h = 6 — 115 строк, не 120), иначе test затекал бы в обучение. Гиперпараметров нет. Это прямой метод (как у статьи), а не рекурсивная экстраполяция: `nowcast_t` — сигнал о текущем месяце, `π_ex_{t−1}` — инерция SA-таргета.

Test-origin 2019-01…2024-07; кумулятивное окно целиком внутри test. Исключения статьи: 2014-12…2015-03 (в тест не попадает), **2020-04**, **весь 2022**; наблюдение выпадает, если исключён любой месяц окна. n = 54 / 51 / 48 / 39 для h = 1/2/3/6. RMSE/MAE — в п.п.; 95 % CI нашего RMSE — блочный бутстрап (блок 3, n = 2000, seed = 20261018). Горизонты h = 4/5 функция `cumulative` поддерживает, но статья их не публикует, поэтому в сравнение они не входят.

## Чувствительность

- **Вес ЖКУ** `w_u` 0.05 → 0.15: RMSE h = 1 0.221 → 0.247, h = 6 1.247 → 1.394; вывод не меняется. Это единственное допущение, меняющее масштаб таргета.
- **Рост тарифа** 0/4/8 %/год: RMSE не меняется (0.233 / 0.471 / 0.714 / 1.316) — постоянный сдвиг поглощается калибровкой.
- **Короткий train** 2014-01…2018-12 (60 мес., из-за глубины DIP-компонент): h = 1 0.245 (без МП) / 0.263 (с МП), h = 6 1.317 / 1.502. Вывод «не паритет» сохраняется; с МП короткий train заметно хуже.

## Где прокси расходится с CB_COMP

1. **Нет ЖКУ-ряда.** Публичного месячного индекса ЖКУ за 2019–2021 в БД нет; постоянные вес и рост тарифа не воспроизводят административные шоки. После калибровки прокси — масштабированный SA-агрегат, а не SA ИПЦ без КУ.
2. **Нет X-13 SA, весов СПР с лагом год и 88 отраслевых групп ЦБ.** У статьи гранулярность — внутренние выгрузки ЦБ; у нас 4 агрегатных ряда.
3. **Другой nowcast.** Наш nowcast обучен на NSA общем ИПЦ, а не на SA ИПЦ без КУ; перенос — линейная калибровка на train, а не обучение на таргете. Это не «та же модель на том же таргете».
4. **Винтажи.** `cbr_dip_bulletin` читается последней редакцией месяца, а не выпуском на дату; PIT-слоя нет.
5. **DM/TOST невозможны.** Опубликованы только агрегатные RMSE; помесячных ошибок CB_COMP нет. Отношение RMSE и абсолютная разница — описательные; паритет без DM/TOST не заявляется.
