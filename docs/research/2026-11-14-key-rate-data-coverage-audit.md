# Полнота, свежесть и винтажи данных контура ключевой ставки на dev (2026-11-14)

> **Объект:** dev-ClickHouse `default` — 96 витрин `v_*`, 11 каналов решения ЦБ, 23 резюме обсуждения, корпус «Основных направлений единой государственной денежно-кредитной политики» (ОНДКП) 2000–2027.
> **Задача:** ответить фактом, что уже собирается, что протухло, и каких рядов не хватает из того, на что ЦБ опирается в резюме и релизах, **за всё время** — до решения о новых импортёрах.
> **Метод:** SQL через MCP `clickhouse` (`kimi_reader`, только витрины `v_*`); живые пробы `cbr.ru`; инвентарь артефактов с HTTP-кодами и числом страниц. Дата прогона — 2026-11-14.
> **Границы:** не проверялись staging, винтажный архив файлов источников и полнота корпуса «Доклада о ДКП» по годам (только факт его наличия на сайте).

## 1. Короткий вывод

1. **Контур собран, но dev остановлен на 2026-11-06/07.** Дневные ряды (`cbr_key_rate`, ОФЗ, KEYRATE, Brent) заканчиваются 6–7 ноября, RUONIA — 5 ноября; `v_key_rate_dashboard` помечает `stale=1` у **19 индикаторов из 24**. Источник при этом живой: страница RUONIA на `cbr.ru` отдаёт ставку за **13.11.2026** (проба 2026-11-14). То есть это лаг импорта, а не отсутствие данных.
2. **Числовая база закрывает 9 из 11 каналов.** Полностью читаются inflation, expectations, labor, lending, output gap (прокси), budget, money supply, external, savings. Два канала дефектны: **автономные факторы** (АЦН-индикаторы стоят на 2024-10-01, кредитные гэпы — на 2024-07-01) и **бюджетный импульс** (раздел «Национальная оборона» закрыт источником с 2022-01, кумулятивного ряда нет).
3. **Ряды внутри диапазона полны.** Месячные ряды совпадают с календарём: ИПЦ 429 точек 1991-01 … 2026-09 (429 месяцев), рабочая сила 116 точек 2017-01 … 2026-08 (116 месяцев), средства клиентов банков 3 177 точек / 21 ряд 2012-02 … 2026-10, ВВП 62 квартала 2011-04 … 2026-07. У ключевой ставки 3 295 точек с 2013-09-17; 143 пропущенных рабочих дня за 13 лет — нерабочие дни, не дефект.
4. **Главный пробел «за всё время» — не числа, а история рядов.** RUONIA рассчитывается с **11.01.2010**, в БД — с 2019-01-09 (потеряно 9 лет). Инфляционные ожидания в публикациях ЦБ есть с 2017 г., в БД — с 2023-01-14. Ставки по вкладам — с 2021-10-30. Всё это укорачивает выборку ровно там, где лежит единственный цикл ужесточения 2014–2015.
5. **Текстовый слой 2013–2023 отсутствует полностью.** Пресс-релизы по ставке и резюме обсуждения начинаются 2024-02-16 (23 документа, 1 355 блоков); «Доклад о денежно-кредитной политике» (квартальный, до февраля 2024) на сайте есть, в БД нет. Модель не может проверить текстовый канал до 2024 г. ни на одном заседании.
6. **ОНДКП — 28 винтажей 2000–2027, все доступны и машиночитаемы**, в БД отсутствуют. 2000–2010 — ZIP с `.doc` в cp1251 (текст извлекается после перекодировки), 2011–2027 — PDF с текстовым слоем (35–251 страница). Из документа 2027 г. числа берутся строкой таблицы: «Ключевая ставка, в среднем за год» → 17,5 / 19,2 / 14,6 / 12,5–13,5 / 9,0–10,0 / 7,5–8,5.
7. **Журнал прогнозов не резолвится:** строки `cbr_rate:*` остались на `target_date=2026-10-23`, `error_bp` пуст — после заседания 23.10 факт не подставлен.

## 2. Метод и определение «свежего»

Свежесть считается от 2026-11-14 против естественного цикла ряда: дневные — 7 дней, недельные — 14, месячные — 45, квартальные — 120. Отдельно различаются три причины отставания: **dev не обновлялся** (источник свежее БД), **источник не отдаёт** (Росстат после восстановления 13.11 отдаёт только сентябрьскую волну) и **публикация ещё не вышла** (октябрьский ИПЦ).

Пробы первоисточников — `curl` с браузерным UA, 2026-11-14; для ОНДКП каждая ссылка проверена отдельно (HTTP-код, content-type, размер), для PDF — `pdfinfo` + `pdftotext -layout`.

### 7.1. Что извлекается числами

Проверено на документе 2027 г. (`pdftotext -layout`): таблица прогноза содержит строку с устойчивой подписью

```
Ключевая ставка, в среднем за год, % годовых   17,5   19,2   14,6¹   12,5 – 13,5   9,0 – 10,0   7,5 – 8,5
```

то есть по каждому винтажу извлекаются: **цель по инфляции**, **диапазон среднегодовой ключевой ставки** на каждый год трёхлетки, прогноз инфляции и ВВП, сценарные развилки. Дополнительно — историческая линия цели: ОНДКП-2013 — «5–6 % в 2013, 4–5 % в 2014 и 2015», ОНДКП-2014 — «4,5 % в 2015 и 4,0 % в 2016», ОНДКП-2015 — «4 %». Это то, чего нет в `cbr_mt_forecast` (там только «Комментарий к среднесрочному прогнозу» с 2024-02): получается непрерывная линия собственных прогнозов ЦБ **с 2000 по 2029 год**.

### 7.2. Ограничения корпуса

- 2000–2010 — не PDF, а ZIP с одним `.doc` на весь выпуск «Вестника»: нужен `unzip` + конвертация (текст в cp1251, после перекодировки читается; проверено на выпуске 2000 г.).
- 2022 — на странице только **проект** документа; итоговый текст, если он публиковался отдельно, надо искать дополнительно.
- Формат страниц 2021–2027 менялся: 2026–2027 отдают брошюру и PDF с якорями (`#page=25`); парсер должен брать первую ссылку на `on_YYYY(...).pdf`.
- Нумерация страниц и вёрстка таблиц меняются между выпусками — извлечение чисел обязано проверяться фикстурами по эпохам (2000-е `.doc`, 2011–2020 PDF, 2021+ PDF с брошюрой).

## 8. Рекомендация и критерий приёмки

**Go** на P0-пункты 2–4 (ОНДКП, RUONIA, ожидания) и P1-пункт 7 (АЦН): у всех есть стабильный машиночитаемый источник, глубина подтверждена, объём — 1–4 p-d на пункт. **Go с оговоркой** на пункт 1 (текст 2013–2023): источник есть, но «Доклад о ДКП» — PDF-корпус, и нужен отдельный research по извлекаемости таблиц. **No-go** на r\* и разрыв выпуска числом — источника нет.

Критерий приёмки любого из пунктов (по стандарту импортёра): живой прогон на dev, повтор — no-op, число точек и границы совпадают с источником, каталог `series_catalog` заполнен, витрина `v_*` и `GRANT SELECT` добавлены, `make mcp-check` зелёный.
