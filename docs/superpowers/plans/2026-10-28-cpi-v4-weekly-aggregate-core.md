# План: CPI v4 — единый лидерборд, недельный агрегат 2009+, core с обученными весами

**Пункт:** `key-rate/phase-4-cpi-v4-weekly-aggregate-core`, issue [#396](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/396), `role:ml`.
**Спека:** [2026-10-28-cpi-v4-weekly-aggregate-core-design.md](../specs/2026-10-28-cpi-v4-weekly-aggregate-core-design.md) — предрегистрация; этот план её **не меняет**. Расхождение с планом = правка спеки отдельным коммитом до прогона.
**Ветка:** `exp/cpi-v4-weekly-aggregate-core`, worktree `.worktrees/cpi-v4-weekly-aggregate-core`.
**Правила:** TDD, офлайн-тесты без ClickHouse и сети; ClickHouse только читается через `lib.clickhouse.ch_query`; команды — только через `make`; `ML_LOG=1`, MLflow по умолчанию; в БД, `forecast_log`, Go/DDL/витрины/гранты ничего не пишется.

## Порядок и зависимости

```text
Task 1 аудит агрегата ─┬─> Task 2 признаки wkagg_* ─┐
                       └─> Task 3 core-группы ──────┤
Task 4 каркас лидерборда + регрессия v2/v3 ─────────┼─> Task 5 эксперимент 1 (сетка)
                                                    ├─> Task 6 эксперимент 2 (H2)
                                                    └─> Task 7 эксперимент 3 (H3)
Task 8 отчёт, make, docs, роадмап
```

Tasks 2 и 3 зависят от Task 1; Task 4 независим от Tasks 1–3 и идёт параллельно. Стоп-условие спеки §8: если регрессионный гейт Task 4 не воспроизводит v2/v3 на `S_W22`, Tasks 5–7 не запускаются.

## Task 2: признаки `wkagg_*` (H2)

**Файлы:** `scripts/models/cpi/cpi_weekly_aggregate.py`, `cpi_weekly_aggregate_test.py`.
**Контракт (спека §3):** `wkagg_mtd`, `wkagg_cov`, `wkagg_mtd_scaled` (при `cov ≥ 0,5`, иначе NaN), `wkagg_last`, `wkagg_4w`, `tariff_week`.

**Шаги (тест → реализация):**
- [ ] Тесты признаков на синтетической сетке: полное покрытие месяца (`cov = 1`, `mtd` = произведение недель), дыра в середине (`cov < 1`, `mtd_scaled` NaN при `cov < 0,5`), неделя через границу месяцев (доли по дням).
- [ ] **Тест на утечку:** признак месяца `O` не использует точки с `date + 2 > cutoff`; пара «cutoff − 1 день / + 1 день» меняет признак только при появлении новой доступной недели.
- [ ] Тест `NaN ≠ 0`: месяц без доступных недель → все `wkagg_*` NaN.
- [ ] `tariff_week` — по календарю из спеки (июль 2022–2025, октябрь 2026, Jan-1 неделя); тест на известных датах скачков (2022-07-01, 2023-07-03, 2024-07-01, 2025-07-07).
- [ ] Функция `wkagg_features(panel, month, cutoff)` совместима по сигнатуре с `weekly_features` v3; **без интерполяции** на 7-дневную сетку.
- [ ] Сборка строк `Row` для `S_L09`/`S_L13`/`S_W22` через расширение `build_sample_v3` (композиция, `cpi_monthly_v3.py` не модифицируется; выборка `S_L09` — набор признаков без `usd_mm`/`key_rate`, фиксируется константой и тестом).

**Done:** тесты зелёные (`make cpi-weekly-aggregate-test`), утечка отсутствует.
