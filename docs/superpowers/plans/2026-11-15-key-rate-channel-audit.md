## 4. Воспроизводимые проверки R0 и R5

Все SQL ниже исполняются через ClickHouse MCP, не shell-клиентом.

```sql
SELECT currentDatabase(), currentUser(), hostName(), version();
SELECT count(), min(meeting_date), max(meeting_date) FROM v_cbr_mp_summary;
SELECT count() AS compared,
       countIf(s.decision_rate != p.decision_rate
               OR s.decision_action != p.decision_action) AS mismatch
FROM v_cbr_mp_summary s
INNER JOIN v_cbr_key_rate_press p USING (meeting_date);
SELECT method, model, prompt_version, uniqExact(meeting_date), count()
FROM v_cbr_mp_summary_channels GROUP BY method, model, prompt_version;
SELECT count(), countIf(stale = 1) FROM v_key_rate_dashboard;
SELECT count(), countIf(published_at IS NULL) FROM v_cbr_ondkp_forecast;
SELECT meeting_date, release_date, indicator, year, lo, hi, url
FROM v_cbr_mt_forecast
WHERE indicator IN ('key_rate_avg', 'cpi_dec', 'cpi_avg')
  AND release_date = (SELECT max(release_date) FROM v_cbr_mt_forecast)
ORDER BY indicator, year;
```

До дополнительных SELECT прочитать схемы/комментарии, не угадывать поля.
Проверка последнего винтажа выше — текущий срез; для historical cutoff запрос
обязательно ограничивает release_date до выбора max. Отдельно проверить точность
времени публикации для предрешенческого прогнозирования.

Контроль арифметики (синтетические фикстуры, не экономический прогноз):

- Постоянные 10% весь 2027 год → 10%.
- 10% до 01.07.2027, 8% с 01.07 → `(10*181+8*184)/365`.
- Тот же переход в 2028 → `(10*182+8*184)/366`.
- Заседание 10.03, вступление 13.03: 10–12 марта остаются на старой ставке.
- Пропуск стартовой ставки года или непокрытый будущий интервал → исключение,
  а не молчаливое заполнение нулями/последним значением.

Для финансового счёта сверить три квартала по методологии источника, включая
резервы и ошибки/пропуски; допуск обосновать опубликованным округлением. В текущем прогоне 0,02 млн USD
выбран после получения округлённых данных; это диагностическая проверка, не предрегистрация. Для тарифов выделить прямой арифметический вклад и неизвестный
вторичный эффект. Для миграции проверить определения на двух странах назначения.

## 6. Решения при отказах

MCP недоступен → не подтверждать локальный baseline, продолжить источниковую часть.
Закрыта детализация расходов → принять ограниченную прокси с coverage-gap.
Нет dated-vintage → исключить историческое сравнение, оставить текущую сверку.
Нет собственной годовой траектории → контракт/фикстуры готовы, количественное
сравнение модели не принято. Нет независимого ревью → R6 не закрывать.
Эти ограничения должны остаться в итоговом отчёте, а не исчезнуть при агрегации.
