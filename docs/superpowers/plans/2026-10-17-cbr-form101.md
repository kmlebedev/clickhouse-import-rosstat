# План реализации: cbr_form101 (первый срез — Сбер)

**Спека:** [2026-10-17-cbr-form101-design.md](../specs/2026-10-17-cbr-form101-design.md).
**Пункт роадмапа:** [ROADMAP_KEY_RATE.md](../../ROADMAP_KEY_RATE.md) §4.2 №21.
**Issue:** [#95](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/95).

## T1. Парсеры и фикстуры

**Файлы:**
- `cbr/form101_parse.go` — `parseForm101DBF([]byte) ([]form101Row, error)`, `latestForm101Link([]byte) (time.Time, string, error)`, `form101EntryName`/`extractB1` (RAR);
- `cbr/form101_parse_test.go` — тесты на фикстурах;
- `cbr/testdata/form101_page.html` — срез страницы ЦБ с несколькими `101-*.rar`;
- `cbr/testdata/form101_sber.dbf` — маленькая DBF-фикстура (заголовок + 2–3 записи, включая Сбера и удалённую).

**Шаги:**
1. DBF-парсер: заголовок (record count, header length, record length), дескрипторы до `0x0D`, записи; CP866 через `x/text/encoding/charmap`; числовые поля — `strconv.ParseFloat` с проверкой; `*` — удалённая запись.
2. `form101Row`: `Regnum uint32`, `Account`, `Plan`, `ActivePassive string`, `BalanceTotal float64`.
3. Поиск ссылки: goquery `a[href*="/vfs/credit/forms/101-"]`, regexp `101-(\d{8})\.rar`, максимум даты; 0 ссылок — ошибка.
4. RAR: `rardecode/v2`, entry с суффиксом `B1.dbf` (регистронезависимо); тест на живом RAR в `/tmp` не коммитить; в тестах — только DBF/HTML.
5. `go get github.com/nwaples/rardecode/v2@v2.4.5` (уже добавлен в рабочем дереве), `go mod tidy`.

## T2. Импортёр и витрина

**Файлы:**
- `cbr/form101.go` — `cbrForm101Importer` (`Name() = "cbr_form101"`), DDL, `Import()`, витрина;
- `cbr/importers.go` — запись реестра;
- `dagu/cbr.yaml` — шаг в хвост цепочки;
- `sql/mcp_kimi_reader.sql` — грант;
- `scripts/mcp_check.py` — проверка;
- `cbr/importers_test.go` — обновить ожидаемый состав, если тест пинит число записей.

**Шаги:**
1. DDL `cbr_form101` по §3 спеки; `report_date`, `regnum`, `account`, `plan`, `active_passive`, `balance_total`, `loaded_at`; `ReplacingMergeTree(loaded_at)`, `ORDER BY (report_date, regnum, account, active_passive)`.
2. `Import()`: DDL → `util.CreateView` (витрина) → `util.GetPage` → `latestForm101Link` → гейт `max(report_date)` → `util.GetFile` RAR → извлечь `B1.dbf` → `parseForm101DBF` → фильтр `REGN=1481` → батч → `Send` → лог.
3. Витрина `v_cbr_form101` с комментариями (таблица и 7 колонок), `Tables: []string{"cbr_form101"}`.
4. Регистрация: `{cbrForm101Importer, "cbr_form101", "SELECT count() FROM cbr_form101 FINAL"}`; шаг `cbr_form101` в `dagu/cbr.yaml` — последним.
5. MCP: `SELECT count() AS n FROM v_cbr_form101` > 0; `SELECT count() AS n FROM v_cbr_form101 WHERE regnum=1481 AND report_date='2026-09-01'` > 0; сырая `cbr_form101` — `ACCESS_DENIED`.
6. Тесты: `parseForm101DBF`, `latestForm101Link`, `reportDateKnown` (гейт без ClickHouse).
