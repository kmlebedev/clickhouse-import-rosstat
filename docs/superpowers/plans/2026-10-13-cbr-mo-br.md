# cbr_mo_br (макроопрос ЦБ) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Импортёр `cbr_mo_br` — консенсус-бенчмарк макроэкономического опроса ЦБ (17 показателей × 6 статистик × волны с 2021-05) в `macro_series` + витрина `v_cbr_mo_br`, с общим механизмом точек контроля публикаций `source_publications` и лёгким HEAD-префлайтом.

**Architecture:** Пакет `cbr/` (конвенция фазы 3), паттерн `cbr_mp_survey`: `getPage → findLink → HeadFingerprint → source_publications`; полный upsert истории файла — только при новой версии; иначе no-op с количественным чеком. Общий `util/publications.go` (первый потребитель — mo_br; миграция остальных — вне объёма). Каталог генерируется из разбора.

**Tech Stack:** Go, `util.ClickHouseImport`/`GetXlsx`/`GetFile`/`findLink`/`getPage` (пакет `cbr`), `excelize/v2`, logrus; ClickHouse ReplacingMergeTree; dagu.

**Spec:** `docs/superpowers/specs/2026-10-13-cbr-mo-br-design.md` (коммит `52c50d3`, ветка `feat/cbr-mo-br`). Читать вместе с планом: спека — связывающая власть, план — её аргумент.

## Global Constraints

- Ветка `feat/cbr-mo-br`; незакоммиченная правка владельца `deploy/staging/dagu.service` — не трогать и не коммитить; перед коммитом `git status`, в индекс только свои файлы.
- Новых зависимостей не добавлять.
- Вставки в ClickHouse — только батчами `PrepareBatch → Append(err!) → Send`; HTTP — только через `util.*`; логирование — logrus; сетевых вызовов в `init()` нет.
- `source='cbr_mo_br'`; имена рядов — `<base>_<year>_<stat>` (листы 16–17 — `<base>_<stat>`), статистики `median|p10|p90|min|max|answers`, 17 базовых имён — из спеки §3.3, дословно.
- `date` ряда = дата волны из файла (1-е число месяца); 6 статистик; пустые ячейки («-») — пропуск.
- DDL `macro_series`-импортёра — в `%s`-форме; DDL `source_publications` — литерал в `util` (канонический в ARCHITECTURE §6.2).
- `source_publications` — внутренняя таблица: гранта `kimi_reader` нет, в `v_series_catalog`-обвязку не входит.
- Фикстуры — реальные артефакты (zip-хирургия `full.xlsx` до листов «1», «3», «16»); тесты офлайн, без сети.
- Каждый Task заканчивается gofmt-чистым кодом, зелёными `go build ./...` и `go test ./util/ ./cbr/`, коммитом кратко по-английски.
- Ручные команды с ClickHouse/env — только через `make` (Makefile подключает env). Секреты не читать/не печатать.

## Review Focus

1. **Пустая ячейка («-») в любом месте файла** — пропуск точки, соседние не страдают, нулём не подменяется. Тест: T3.
2. **Разметка источника поплыла** (шапка волн, блоки статистик, годы) — импорт обязан падать ошибкой до `Send`, а не писать «0 rows». Тесты: T3 (fail-fast).
3. **Новый год/волна у ЦБ подхватывается, новый лист — нет**: год из колонки D и новая волна в шапке принимаются без правок кода; неизвестный лист-показатель — ошибка. Тесты: T3.
4. **HEAD-отпечаток**: стабилен между запросами; меняется при смене ETag/Last-Modified/Content-Length/имени; пропажа ETag не ломает; не-200/сеть → ошибка. Тесты: T2.
5. **No-op повтор**: вторая полная версия файла не пишется; количественный чек сравнивает точки и лечит расхождение. Тесты: T6 (приёмка) + код T4.
