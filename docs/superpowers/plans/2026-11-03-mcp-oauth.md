# План: MCP OAuth (Google + allowlist), cutover `:8443`

1. **Провайдер.** `deploy/staging/rosstat_mcp_auth.py`: `RosstatGoogleProvider(GoogleProvider)`,
   env-адаптер `FASTMCP_SERVER_AUTH_GOOGLE_*`, allowlist `ROSSTAT_MCP_ALLOWED_GOOGLE_EMAILS`,
   проверка `email_verified`. `deploy/staging/rosstat_mcp_auth_test.py` — 8 офлайн-тестов.
2. **Юнит и env.** `mcp-clickhouse.service`: `PYTHONPATH`, `UnsetEnvironment=CLICKHOUSE_MCP_AUTH_TOKEN`.
   `clickhouse-import-rosstat.env.example`: OAuth-блок, `CLICKHOUSE_MCP_ALLOWED_ORIGINS`, allowlist;
   static bearer удалён.
3. **Makefile.** `mcp-auth-test`; `deploy-staging-mcp` копирует провайдер и проверяет OAuth-env;
   `deploy-staging-preflight` — непустые OAuth-переменные и отсутствие legacy token;
   `deploy-staging-smoke` — `/health`, 401 + `WWW-Authenticate`, `/.well-known/oauth-*`;
   полный Google-вход — вручную.
4. **Документация.** `deploy/staging/README.md` (Google Cloud OAuth client, callback
   `https://mcp.selfinvesting.ru:8443/auth/callback`, allowlist, откат), `ARCHITECTURE.md` §6.5,
   `README.md`.
5. **Плагин `rosstat-mcp` 0.5.0.** `kimi.plugin.json` — `auth: "oauth"`; остальные манифесты —
   URL без `headers`/`bearer_token_env_var`/`variables`; README/wiki — вход через Google;
   тесты — без `ROSSTAT_MCP_TOKEN`.
6. **Проверка.** `make mcp-auth-test`; `make all`; тесты плагина; локальный smoke OAuth-метаданных;
   после деплоя — вход allowed-аккаунтом и `run_query`, отказ чужому аккаунту, регрессия legacy
   на откате.
