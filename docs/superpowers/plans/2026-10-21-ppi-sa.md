**Пункт:** `key-rate/phase-4-rosstat-ppi-sa` T4, issue [#279](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/279), parent [#266](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/266).

## 1. Решения

| Вопрос | Решение |
|---|---|
| Пакет / имя | `ppi/`, импортёр и таблица `ppi_sa`; `Name()` = `CLICKHOUSE_IMPORT_STAT` = `ppi_sa`. |
| Транспорт | Go читает CH, строит уровни, вызывает встроенный R-скрипт X-13 через `Rscript`, пишет `ppi_sa`. Python — только read-only паритет и экспорт весов. |
| Таксономия | `okpd2-kipc-2026-v2` (PR #307); `taxonomy_version` читается из mapping, сверяется с ожидаемым. |
| Веса | Фиксированные веса **2026** для всех месяцев (как research/T3); полная панель по всем группам mapping v2 встраивается для provenance и будущей sensitivity (годовые веса / `2022-04`), но primary их не использует — иначе разрыв состава КИПЦ на 2023-01. |
| Spec | `x13arima-seats`, `ppi-sa-2026-v1`, SEATS/log/auto-outliers/calendar td; `saar3` — среднее трёх SAAR. |
| Схема | `ppi_sa`, ключ `(date, series, method, spec_version, taxonomy_version)`, `ReplacingMergeTree(loaded_at)`. |
| Идемпотентность | SHA-256 входов + версии → `source_publications`; повтор — no-op без R; count mismatch — self-heal. |
| Каталог | 5 рядов `source='ppi_sa'` в T4; витрина/грант — T5. |
| Расписание | `dagu/ppi.yaml`, четверг 14:17, один шаг; окно/свежесть — T6. |

## 2. Данные и контракты

### 2.1. Полная панель весов

- Источник: `Vesa-tov-KIPC_2012-2026.xlsx` (публичный XLSX, `build/ppi-sa-research/raw/`, в git не входит).
- Группы: все `kipc_group` из v2 mapping (45 групп mapped-листьев), включая `01.2.1`…`01.2.6`, `09.3.2`, `04.3.1.1.*`, плюс scope/subtract-группы.
- Периоды: 2012–2022, `2022-04`, 2023–2026 — экспортируются все (provenance/sensitivity); primary-агрегация читает период `2026`.
- Артефакт: `docs/research/2026-10-21-ppi-sa-weights-panel.csv` (`period,code,name,weight`); ожидаемо ≥469 строк / 66 кодов.
- Проверка: у каждой mapped-группы есть вес 2026; экспорт детерминирован (повтор побайтово тот же).

### 2.2. Ряды и базы

| Ряд | Вход | Начало | База |
|---|---|---|---|
| `total` | `rosstat_ppi_ved`, `index_type='m/m'`, `code='1323500.029.31'` | 2013-01 | 100 = 2013-01 |
| `food` | KIPC-агрегат food | 2021-01 | 100 = 2021-01 |
| `nonfood` | KIPC-агрегат non-food | 2021-01 | 100 = 2021-01 |
| `all` | food + alcohol + tobacco + nonfood + fuel | 2021-01 | 100 = 2021-01 |
| `core` | food + nonfood | 2021-01 | 100 = 2021-01 |

Ожидаемо 164 + 4×68 = **436 строк**.

### 2.3. `ppi_sa`

```sql
CREATE TABLE IF NOT EXISTS ppi_sa (
    date Date,
    series LowCardinality(String),
    method LowCardinality(String),
    spec_version LowCardinality(String),
    taxonomy_version LowCardinality(String),
    sa Float64,
    mm_sa Nullable(Float64),
    saar Nullable(Float64),
    saar3 Nullable(Float64),
    published_at Nullable(Date),
    loaded_at DateTime DEFAULT now()
) ENGINE = ReplacingMergeTree(loaded_at)
ORDER BY (date, series, method, spec_version, taxonomy_version);
```
