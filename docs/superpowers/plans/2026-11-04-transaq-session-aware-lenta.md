## Задача 1. Экспортёр: лог роста каталога (первым, отдельным PR)

1. После первичной подписки — периодическая сводка `catalog: N; subscribed by board: …` при

   до основной переделки.

## Задача 2. Экспортёр: инкрементальная подписка

1. Тест на фейковом клиенте: каталог растёт после первичной подписки → один `subscribe` только
   с новыми `secid`; без роста — ни одного; новая сессия соединения сбрасывает подписанный набор.
2. Вынести из `updateSecurities` чистую функцию отбора `secid` вселенной по каталогу (доски,
   коды, облигации для `get_securities_info`) — её используют и первичная, и инкрементальная подписка.
3. Цикл в `processTransaq`: тикер `catalogQuiet`, дельта к подписанному набору, `subscribe` и
   `get_securities_info` для новых облигаций; `allTradesCoverage` и порог из #15 не возвращать.
4. `go vet`, `go test -race`, PR.

3. Импортёр по стандарту пакета (§14), `util.ClickHouseImport`, батч; витрина с комментариями,
