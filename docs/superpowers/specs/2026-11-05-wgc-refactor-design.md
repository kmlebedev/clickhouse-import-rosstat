# Рефакторинг пакета `wgc/` по стандарту импортёров

**Дата:** 2026-11-05. **Роль:** Go-инженер. **Нормы:** [IMPORTER_PACKAGE_STANDARD.md](../../IMPORTER_PACKAGE_STANDARD.md) §15 (рефакторинг), §8 (реестр).

## 1. Инвентарь (§15.1)

| Признак | Состояние |
|---|---|
| `colly` / `fmt.Print*` / `panic` / `_, _ = Parse*` | нет |
| Транспорт | `util.GetJSON` (ETF API); XLSX — локальные файлы (goldhub отдаёт 403 боту) |
| Разбор | отделён от сети, значения читаются сырыми (`parse.go`), фикстуры — реальные (`testdata/`) |
| Каталог / витрины / гранты | `series_meta.go`; витрины `v_gold_etf_flows`, `v_cb_gold_dynamics` — в `views/` |
| `conn.Exec` | два вызова — только DDL `macro_series`, вне цикла (§5.3) |
| **Реестр (§8.1)** | **нет:** два персональных `init()` в `cb.go` и `etf.go` |
| **Тест-энфорсер (§8.3)** | **нет** |

Единственное расхождение — §8. Остальное соответствует.

## 2. Решения

1. `wgc/importers.go` — единственный `init()`, записи `{ImportStat, table}` с литералом `macro_series`; персональные `init()` и импорт `chimport` из `cb.go`/`etf.go` удаляются.
2. `Name() != TableName` у обоих импортёров — общая `macro_series` (§7.2); allowlist владельцев литеральный.
3. Точка контроля публикации **не объявляется** (§9.3): `wgc_etf_flows` ходит в JSON API на каждом прогоне и ловит публикацию в день выхода; `wgc_cb_reserves` читает вручную скачанные выгрузки — HEAD-отпечатку источника нет. Энфорсер проверяет отсутствие объявления (д).
4. Винтажный архив (§9.6) не применим: без точки контроля архив версий не включается; отступление не вводится.
5. `wgc_etf_flows` и `wgc_cb_reserves` оставляют собственный `Import()`: шаблон `util.ClickHouseImport` не покрывает два транспорта с фолбэком и режим `WGC_REQUIRE_DATA`; перевод — отдельный пункт, не рефакторинг (§15.2: поведение не меняется).
6. Тест `TestWgcImportersPrefixedAndRegistered`: (а) префикс `wgc_`, (б) таблица/владельцы, (в) уникальность и регистрация, (г) покрытие `dagu/wgc.yaml` в обе стороны, (д) нет объявления публикации, (¬) число в `chimport.Stats` = `len(реестр)`.

## 3. Данные не меняются (§15.2)

Набор рядов, таблицы, `Name()`, расписание и значения точек не меняются; приёмка — `go test` (офлайн), повторный живой прогон на dev-ClickHouse — по просьбе владельца (`make ch-up` ассистент не делает).
