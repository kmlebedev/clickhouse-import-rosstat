**Статус:** спека утверждена владельцем 2026-10-14 (план-ревью); реализуется в ветке `feat/rosstat-refactor`.
**Пункты:** (1) новый нормативный документ [IMPORTER_PACKAGE_STANDARD.md](../IMPORTER_PACKAGE_STANDARD.md) — целевой вид пакета импортёров, вынесенный из практики `cbr/`; (2) [ROADMAP_KEY_RATE.md](../ROADMAP_KEY_RATE.md) §6, фаза 2 — первый по приоритету шаг «починка пустых рядов» (`salaries_mes`, `vvp_kvartal`) в части Росстата; (3) технический долг пакета `rosstat/` (аналог фазы 3 для `cbr/`), закрываемый по стандарту.

## 1. Цель и объём

### 1.1. Цель

1. Зафиксировать **целевой вид пакета импортёров** отдельным нормативным документом, пригодным и для нового пакета, и для рефакторинга существующих, — а не растворять его в задаче про Росстат.
2. **Починить два пустых ряда** контура ключевой ставки: `salaries_mes` (рынок труда: средняя номинальная зарплата) и `vvp_kvartal` (ВВП и дефлятор, квартально) — §4.1 роадмапа называет их пустыми и требует «разобраться с падениями, подтвердить покрытие живым снимком и только затем опираться на эти ряды».
3. Привести пакет `rosstat/` к стандарту: единый реестр и тест-энфорсер, транспорт только через `util`, шаблон `util.ClickHouseImport` для всех четырёх импортёров, фикстуры реальных артефактов, тесты каталога, fail-fast разбора.

### 1.2. Объём

Пакет `rosstat/` (4 импортёра), новый документ `docs/IMPORTER_PACKAGE_STANDARD.md`, ссылки на него из `AGENTS.md`/`ARCHITECTURE.md`/`README.md`, минимальная правка `util/` (вынос HTML-хелперов) и `cbr/` (переключение на вынесенные хелперы), сопряжённые правки `views/model_inputs.go`, `sql/key_rate_coverage.sql`, `dagu/rosstat.yaml`, `scripts/mcp_check.py` и документации.

### 1.3. Вне объёма (названо явно)

- **Рефакторинг остальных пакетов по стандарту** — отдельный пункт роадмапа; инвентарь даёт таблица применения (стандарт §18), ни один пакет, кроме `rosstat/`, не трогается, кроме `cbr/` (перенос хелперов).
- `sber_consumper_spending_index`, `sber_izmenenie_trat` (`bank/`) — тот же класс дефекта (пустые таблицы), другой пакет; отдельный пункт фазы 2.
- Безработица и рабочая сила Росстата (пробел № 4 карты §4.2) — следующий приоритет фазы 2.
- Точка контроля публикации у `rosstat_ipc_weeks` — осознанно не объявляется (темп файла равен шагу, стандарт §9.3).
- Легаси-дашборд `dashboard/rosstat.json` — не мигрируется (панелей Росстата в `grafana/` нет).

## 2. Диагнозы (проверены на живых файлах источника)

### 2.1. `salaries_mes` — формат чисел, а не разметка

Разметка разобрана верно (заголовок A1, шапка месяцев в `row[6:]`, якорь `1991`, год — сдвиг строки). Блокирует **формат**: у всех числовых ячеек `number_format = '#,##0'`, `excelize.GetRows` без `Options` отдаёт форматированный текст `1,074` → `strconv.ParseFloat` падает → разбор возвращает ошибку → 0 строк (живая ошибка из приёмки шага 1.7: `parsing "1,017": invalid syntax`).

Следствия, обязательные к закрытию: (а) `#,##0` округляет до целых рублей — нужны сырые значения (`RawCellValue: true`), иначе теряются копейки; (б) в строке 1991 шесть нулевых ячеек (январь–июнь) — в источнике это «данных не имеется» (квартальные колонки той же строки содержат `…`).

### 2.2. `vvp_kvartal` — четыре расхождения разметки

| Факт источника | Что делал парсер |
|---|---|
| Заголовок в **A2** (объединённая A2:D2); B2 пуста | читал `rows[1][1]` → `panic: index out of range` (`vvp_kvartal.go:88`) |
| Годы в строке 3 в колонках **A, E, I, …**, у поздних групп с суффиксом сноски (`20262)`) | читал `rows[2][i+1]` при обходе `rows[4][1:]` → сдвиг на колонку; первая группа (2011) оставалась без года |
| Подписи `I квартал`…`IV квартал` в строке 4, с колонки A | читал `rows[3][i+1]` (тот же сдвиг); `getQuarterDate` на незнакомой подписи — `panic("Invalid quarter")` |
| Данные в строке 5, с колонки **A** | обходил `rows[4][1:]` → терял 2011-I |
| Значения — полные float (`13024.799539024814`) | форматированный текст `13,024.8` и `ReplaceAll(",","")` → потеря точности |

### 2.3. Имена рядов `ipc_mes` нестабильны

Имя ряда берётся из A1 листа, а A1 содержит годы (`…в 1991-2026*)гг.`). Обновление файла в январе меняет имя → новый ряд, старый обрывается. Для контура ключевой ставки ИПЦ — ключевой вход; решение владельца — чинить в этом пункте.

## 5. Риски и митигации

| Риск | Митигация |
|---|---|
| Переименование ломает вход контура золота (`v_model_inputs` читает `ipc_mes`/`ipc_weeks` и грантован агенту) | порядок стандарта §15.3: новые таблицы наполняются рядом, витрина переключается шагом `gold_views` после сверки с базовой линией, старые таблицы удаляются последними |
| `RawCellValue` меняет значения в младших разрядах | сверка с базовой линией по числу рядов/строк и spot-значениям; расхождение называется в отчёте |
| Урезанная фикстура `ipc_weeks` не содержит всех 128 товаров | контракт каталога односторонний (Р7), обратное направление не заявляется |
| Живой источник недоступен на прогоне (HTTP 426 у `rosstat.gov.ru` — известное ограничение) | приёмочный прогон выполняется при доступном источнике; при недоступности фиксируется факт и прогон повторяется |
| Переименование осиротит версии в `source_publications` | первый прогон после переименования — полный импорт (не no-op); строки по старым ключам удаляются на шаге приёмки |

## 6. Приёмка

1. `make all` — зелёный (gofmt, golangci-lint, `go vet ./...`, `go test -race ./...`, обе сборки); по затронутым пакетам свежим прогоном `go test -race -count=1 ./rosstat/ ./cbr/ ./util/`.
2. Grep-чистота пакета: ноль `gocolly/colly` и ноль `fmt.Print` в `rosstat/`.
3. Живой прогон четырёх импортёров на dev-ClickHouse: `rosstat_ipc_mes` (4 ряда, 1716 строк), `rosstat_ipc_weeks` (128 рядов, 25691 строка), `rosstat_salaries_mes` и `rosstat_vvp_kvartal` — **непусты** (число точек и крайние даты).
4. Spot-сверка с публикацией Росстата: зарплата за июнь 2026, ВВП 2026-I/II в текущих ценах, ИФО ВВП.
5. Повторный прогон: три импортёра с точкой контроля — no-op без скачивания; `rosstat_ipc_weeks` — идемпотентный повтор.
6. `make import STAT=gold_views` — `v_model_inputs` пересоздана на новых таблицах, `ipc_mes_last`/`ipc_week_ytd` не NULL.
7. Старые таблицы удалены; `sql`- и `views`-ссылок на них не осталось.
8. `make mcp-check` — ПРОВЕРКА ПРОЙДЕНА; `dagu validate dagu/rosstat.yaml` — exit 0.
9. Документация и статусы в `docs/ROADMAP_KEY_RATE.md` (§4.1, §6 фаза 2, §8) обновлены тем же PR с командой и результатом.
