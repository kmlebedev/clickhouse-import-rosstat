# wgc_cb_reserves: раскладка листа Monthly выгрузки Changes

**Дата:** 2026-11-05. **Роль:** Go-инженер. **Пункт:** `gold-thesis/phase-3-followup-1a`, issue #530.

## 1. Проблема

`Changes_latest_as_of_Nov2026_IFS.xlsx` (IFS за ноябрь, данные по сентябрь 2026) изменил раскладку листа `Monthly`:

| | Oct2026 | Nov2026 |
|---|---|---|
| Служебные строки и колонка-ключ A | строки 1–7, колонка A | убраны |
| Заголовок с датами (serial) | строка 8 | строка 1 |
| Страна (короткое имя) | колонка B | колонка A |
| Комментарий | колонка C | колонка B |
| Первый месяц (2002-01) | колонка D | колонка C |
| Первая строка данных | 9 | 2 |

Парсер зашит на раскладку Oct2026 и падает: `заголовок-дата CO8 = "-7.478E-4": invalid date value` (строка 8 в новой выгрузке — Australia). Файл holdings (лист `PDF`) не менялся.

## 2. Решение

1. Раскладка определяется по тексту, а не по номерам: первая ячейка с точным значением `Country` в колонках A–B строк 1–20 задаёт строку заголовка и колонку имени; ячейка справа обязана быть `Comments`; месяцы — со второй колонки справа от имени; данные — со строки ниже заголовка. Обе раскладки (Oct и Nov) читаются одним кодом.
2. Не нашлась пара `Country`/`Comments` — ошибка «раскладка выгрузки изменилась» (fail-fast, без тихого фолбэка на старые координаты).
3. Остальные проверки без изменений: строгий словарь стран (`Turkey` ≠ `Turkey*`), дата заголовка — только число, колонка без даты со значением — ошибка.

## 3. Данные

Схема, набор рядов (14), `Name()`, расписание — без изменений. Новая фикстура `testdata/Changes_latest_as_of_Nov2026_IFS.xlsx` рядом с Oct. Приёмка: `go test ./wgc`, `make import STAT=wgc_cb_reserves` на Nov-выгрузках (ряды до 2026-09-30), повтор no-op.
