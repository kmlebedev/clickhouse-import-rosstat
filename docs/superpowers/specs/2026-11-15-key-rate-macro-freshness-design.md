## Ограничения и отказ

G-curve — только текущий снимок, пропущенную историю догон не восстанавливает.
KEYRATE может частично записать данные до ошибки — после ошибки проверять MCP.
Ключевая ставка/USD перечитывают историю; Brent переписывает окно 400 дней;
Минфин перечитывает файл. Повтор не обязан писать 0 строк: критерий — равенство
логических данных витрин; HEAD-no-op может вернуть известное число точек.
Месячная дата наблюдения не равна публикации; зарплаты/ВВП датируются началом
следующего месяца/квартала. Нельзя объявлять отсутствие публикации по одному max(date).
Недоступность/старый файл фиксируются как ограничения с HTTP/логом/URL;
дефекты парсеров — отдельные пункты, без попутного ремонта.
