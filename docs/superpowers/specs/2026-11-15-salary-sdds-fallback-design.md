# Salary SDDS fallback — #607

Пункт `key-rate/phase-4-salary-sdds-fallback`, role:go. Depends on #604, принят PR #609.

## Контракт

Основной источник остаётся найденным на странице Росстата `tab1-zpl`. Только ошибка обнаружения/чтения источника или открытия XLSX допускает резервный официальный `https://rosstat.gov.ru/storage/mediabank/SDDS_labor_market.xlsx`. Ошибки БД, семантического разбора, батча, каталога и регистрации версии не маскируются fallback. В archive restore автоматического переключения нет; dynamic importer без явно заданного primary DataUrl отклоняется до сети.

Резервный парсер принимает лист «Рынок труда», заголовок ССРД, единственную строку номинальной начисленной зарплаты работников организаций и единицу «рубли». Месяцы — последовательные первые числа с января 2015; конечные положительные значения должны помещаться в Float32. Пустые конечные месяцы пропускаются; внутренние разрывы, неверные даты/подписи/единицы и HTML вместо XLSX отвергаются до Append. Соседние трудовые показатели не импортируются.

Таблица, имя ряда, Float32 и ключ сохраняются. Дата хранения — первое число следующего месяца. SDDS добавляет только отсутствующие даты, не пересматривает имеющуюся точную историю, включая периоды до 2015. Новая версия источника имеет отдельный ключ `rosstat_salaries_mes_sdds`, URL и архив; count-check ограничен поддерживаемыми датами. Каждый fallback читает файл и сверяет множество дат; PublicationAlwaysRead отключает только ранний count-only no-op, сохраняя регистрацию версии и архив при настроенном backend. Повтор без новых дат пишет 0 строк. На no-op каталог и витрина остаются доступными. Предполагается один писатель: сверка известных дат не является транзакционной блокировкой. Поддержка восстановления именно SDDS отдельным CLI-переключателем не входит в пункт.

Минимальное расширение util: типизированная ошибка чтения исходного файла, только для GET и открытия XLSX до батча. Остальные импортёры сохраняют поведение; errors.Unwrap сохраняет причину.

## Приёмка

Тесты парсера, выбора источника и сохранения истории; `make all`, `make docs-check`; независимое ревью. Dev: baseline, ограниченный импорт и повтор, MCP-сопоставление зарплаты/трудовых рядов, отдельная версия SDDS. Текущий SDDS заканчивается августом 2026 (103014 рублей), сентябрь пуст: улучшения свежести не обещаем. Исследование #604 доказало 140/140 совпадений. Staging и ML не затрагиваются.
