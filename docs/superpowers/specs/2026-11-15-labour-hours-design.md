# rosstat/1.14 — фактические часы и трудозатраты

Issue #613, role:go, Depends #612 (принят PR #614). Контракт источников:
[research](../../research/2026-11-15-demography-labour-contract.md).

## Объём

Один импортёр `fedstat_labour_hours` в существующем пакете fedstat, одна таблица
и `v_fedstat_labour_hours`. Три series = ID ЕМИСС: 59749 — распределение занятых
по фактическим недельным часам основной работы, тыс. человек; 59751 — средние
недельные часы основной работы на всех занятых группы, включая временно
отсутствующих; 60463 — годовые фактические трудозатраты всех работ,
тыс. человеко-часов. Все имеют годовую частоту, дата = 1 января года.
Не вычислять совместную месячную панель, причинные веса или PIT.

## Схема

`series, region, age, sex, hours_band, activity, employment_status, unit` —
LowCardinality(String); `date Date`, `value Float64`. ReplacingMergeTree,
ключ `(series, region, age, sex, hours_band, activity, employment_status, date)`.
region и измерения сохраняют код и подпись источника, trim whitespace.
Неприменимые измерения — пустая строка, а не «Всего». unit проверяется по ID,
не входит в ключ. FINAL-витрина выдаёт source='fedstat_labour_hours', все
измерения, частоту Y и комментарии; каталог описывает три ряда и ограничения.
Полная географическая строка различает 643/643004.АГ; автоматической склейки нет.

## Транспорт и парсер

GET indicator/ID, CSRF и cookie jar, POST indicator/ID/download с id/format=excel,
на том же клиенте util.NewDefaultTLSClient (существующий fedstat transport),
дедлайн и ограничение тела; токены/куки не логировать. Повтор transient ошибок
по существующему fedstat backoff. BIFF-магия и лист Данные обязательны.
Парсер фиксирует заголовки измерений, годовые колонки, единицу и годовой период;
пустые значения пропускает, нули сохраняет, незнакомые числовые строки/нечисловой
мусор/нефинитные или отрицательные значения отвергает. Конфликт дубля — ошибка.
Коды и подписи измерений проверяются по `fedstat/labour_hours_dimensions.json`,
зафиксированному по числовым выгрузкам research; расширение классификатора
требует явного обновления контракта и фикстур. Контроль 59749: девять категорий в каждой age/sex/region/year, сумма восьми
бин = Всего ±0.45 тыс. человек. Контроль 60463: Всего = по найму + не по найму
±0.15 тыс. человеко-часов по каждой activity/region/year. Не суммировать отрасли.

## Версия и идемпотентность

Явное отступление стандарта §9.6: многоартефактный POST не поддержан GET-шаблоном.
Свой Import с util.ClickHouseImport для имени/DDL, общий archive.Store/Registry
для тех же разобранных байтов; не отдельная система архива. Не вводить HEAD по
HTML-странице. Каждый прогон читает все три выгрузки; SHA256 тела — отпечаток
каждой версии, source_publications после данных/каталога/витрины/архива.
Сравнивать по полному ключу и значению с FINAL: новые/изменённые точки — один
батч, остальные no-op; повтор обязан вернуть 0. Удаление существующих ключей
из ответа — fail closed до записи (отдельный контракт ревизий удаления нужен).
При ошибке любого источника ничего не писать. При сбое архива версия не
отмечается принятой; повтор восстанавливает архив даже при нулевой дельте.
Архив при отключённом backend не создаётся; dev-приёмка с local backend.
Restore для кастомного Import явно не поддержан, без молчаливого сетевого вызова.
FirstSeen — время наблюдения, не опубликованная дата и не исторический PIT.
