## 1. Гипотеза и решение

КПМ ЦБ используется для сценариев, а официальный прогноз публикуется диапазоном. Наши модели дают точку/3 класса на одно заседание. Гипотеза Task 1:

> Сценарный веер по 5 калибровкам ЦБ, расширенный shock-aware слоем (причинные веса + emergency-ветка), даёт лучшие вероятностные прогнозы шага ставки (CRPS и coverage 80 %) и не худший точечный прогноз (медиана веера), чем веер без шокового слоя (`fan_raw`) и точечные B1 hold, B2 repeat, B3 AR(1), `ordered_logit`, `cbr_rule`.

Гипотеза может быть **отвергнута** — это допустимый результат. Пункт измеряет ценность веера и шокового слоя, а не доказывает превосходство. Решение по итогу: `promote` / `iterate` / `reject` (§7).

**Почему shock-aware слой — часть веера, а не `cbr_rule`.** PR [#283](https://github.com/kmlebedev/clickhouse-import-rosstat/pull/283) закрыл `cbr_rule` с вердиктом `reject`: RMSE 304.34 против 145.05 у `ordered_logit`. Post-hoc §6.1 показал, что веса и emergency-ветка снижают RMSE до 203.82 (−33 %), но правило всё равно хуже бенчмарков (×1.41) и значимо хуже по бутстрапу (p=0.0400). Шоковый слой помогает **распределению**, а не реабилитирует точечное правило; поэтому он развивается в веере.

**Что не делается:** `forecast_log`, ingest, Go/DDL/витрины/гранты, путь ставки на несколько заседаний, воспроизведение официального прогноза ЦБ. Task 2 (CPI-веер) — отдельный PR.

## 2. Что именно прогнозируется

- Единица — **заседание Совета директоров ЦБ**; цель — шаг ставки в базисных пунктах на заседании `t`.
- Веер — **распределение шага** на одно заседание, а не траектория на несколько заседаний. Многоквартальный путь — вне объёма Task 1.
- `rate_before` — фактическая ставка накануне заседания (известна на дату прогноза), поэтому сценарии применяются как одношаговые правила от фактической ставки.
- Официальный среднесрочный прогноз ЦБ не воспроизводится: опубликованный код КПМ — IRF-only, без данных и оценки; официальная траектория — консенсус Совета директоров с суждением (research §5).

## 3. Данные и as-of

### 3.1 Выборка

- 108 решений `2014-02-14 … 2026-09-11`; пропусков нет (наследуется от `key_rate_model` v0).
- Walk-forward: расширяющееся окно `min_train=24` — **84 фолда** (primary); `rolling40` — **68 фолдов** (robustness).
- Строка выборки — `CbrRow` из `key_rate_cbr_rule.build_cbr_rows`: решение, `pi_saar`, ИБК-gap, `e3_core`, `e3_headline_adaptive`, `e3_headline_consensus`, `gdp_gap`, `ibk_gap`, `r_star_trend`, `e3_*_m3`.
- Новый признак — фискальный импульс (§3.2). Шоковые веса/вероятности — из `shock_classifier` (§5).

### 3.2 Фискальный импульс

Источник — `minfin_fed_bud_mes` (строки `name`, `date`, `value`):

- `Доходы` — доходы федерального бюджета за месяц;
- `Дефицит (-)/Профицит (+)` — сальдо за месяц.

Для заседания `d`:

```
available_from_budget(M) = end_of_month(M + 1)          # консервативно, как CPD
last_month = max{ M : available_from_budget(M) <= d }
income_12m = Σ value(Доходы, M)   за 12 месяцев до last_month
deficit_12m = Σ value(Дефицит, M) за 12 месяцев до last_month
fiscal_impulse = -deficit_12m / income_12m * 100          # > 0 — экспансия
```

- Пропуск любого из двух рядов или `income_12m <= 0` → `fiscal_impulse = None`, счётчик `budget_fallback`.
- `z = (fiscal_impulse - median_train) / IQR_train`; `IQR=0` → стандартное отклонение, затем 1; клип `[-2; 2]`; `None` → `z=0` + счётчик.
- **Ограничение:** лаг `end M+1` консервативен и не является PIT; ревизии и точные даты публикации Минфина не учтены. Это называется в отчёте.

### 3.3 As-of шокового слоя

- `events_calendar.emergency` — явная метка внеочередного заседания (6 событий: 2014-03-03, 2014-12-15, 2022-02-28, 2022-04-08, 2022-05-26, 2023-08-15).
- `shock_classifier.build_panel` — панель заседаний с каналами as-of; `walk_forward_weights` — причинные веса; `walk_forward_classifier` — вероятность явного шока.
- Даты `CbrRow` и шоковой панели обязаны совпадать 1:1. Расхождение — ошибка прогона, а не молчаливый пропуск.

### 3.4 Наследуемые as-of правила

| Признак | Правило доступности |
|---|---|
| `rate_before` | ставка на `d − 1` |
| `e3_core`, `e3_headline_adaptive` | точка месяца M доступна в конце M+1 |
| `e3_headline_consensus` | волна макроопроса + 6 дней |
| `gdp_gap` | конец квартала + 3 месяца |
| `ibk_gap` | конец месяца M+1 |
| фискальный импульс | конец M+1 (§3.2) |
| веса/вероятность шока | walk-forward, только прошлые заседания |

PIT/винтажей по CPD и ВВП нет — ограничение наследуется от v0 и называется в отчёте. Точка, опубликованная после `d`, не участвует; это проверяется тестом.

## 4. Сценарии

Пять сценариев — **reduced-form прокси** калибровок КПМ, не реализация QPM. Равные веса: калибровки ЦБ — альтернативы, а не вероятности; веса не оцениваются по тесту.

| Сценарий | Реализация | Параметр / формула |
|---|---|---|
| `inertial` | базовое правило `cbr_rule` | γ2=1.5, адаптивный E3 12m y/y, GDP gap, r*=3.0 |
| `rational` | `RuleSpec(e3_source="consensus")` | консенсус CPI; при отсутствии — fallback на адаптивный E3, счётчик `rational_fallback` |
| `hard` | `RuleSpec(gamma2=1.9)` | жёсткая ДКП |
| `budget` | база + фискальный импульс | `gap + 0.30·z(fiscal_impulse)`, `z` из §3.2; 0.30 = 0.40 − 0.10 (калибровки `a7_ru` budget vs base) |
| `no_market_loans` | база с подавленным gap | `gap × (0.05/0.15)` — прокси `a3_ru` 0.05 vs 0.15 |

Правило для сценария:

```
i_t = γ1·i_{t−1} + (1−γ1)·(r* + E3π_MP + γ2·(E3π_MP − 4) + 0.5·gap_scenario)
E3π_MP = 0.75·E3(core) + 0.25·E3(headline)
```

- Для `budget`/`no_market_loans` меняется только `gap_scenario`; остальные компоненты — из базового правила.
- Если базовый признак отсутствует (`E3`, `gap`, `r*`), фолд пропускается со счётчиком — как в `cbr_rule`.
- `rational` при отсутствии консенсуса использует адаптивный E3 и считается `rational_fallback`; это делается **до** расчёта, а не заполняется нулём.

**Чувствительность (robustness, не primary):** `budget` с коэффициентом 0.10 вместо 0.30 (эффект только бюджетной калибровки); `no_market_loans` с фактором 0.10/0.15 вместо 0.05/0.15. Результаты публикуются рядом, не выбираются по тесту.

## 5. Шоковый слой

### 5.1 Веса наблюдений

`w_t` — `shock_classifier.walk_forward_weights(panel, min_train=24)`: расстояние Махаланобиса с Ledoit–Wolf, `w = 1/(1 + max(0, r−1)²)`, клип `[0.05; 1]`, первые 24 заседания — 1.0. Веса **не исключают** наблюдения.

### 5.2 Вероятность шока

`p_t` — `shock_classifier.walk_forward_classifier(panel, min_train=24)`; `None` → 0; клип `[0; 0.25]`. Классификатор описательный (6 положительных меток), поэтому его вероятность не получает большой вес; клип фиксирован до прогона.

### 5.3 Emergency-ветка

- Шаги внеочередных заседаний **только из обучающего окна** (строго прошлые): `emergency_steps = [step_bp of rows in train if emergency]`.
- Если ветка пуста, `p_t` обнуляется, `fan_shock == fan_raw` на этом фолде; счётчик `shock_branch_missing`.
- Ветка не использует текущий или будущий шаг; это проверяется тестом.

### 5.4 Веера

| Веер | Состав | Роль |
|---|---|---|
| `fan_raw` | 5 сценариев, равные веса | ablation |
| `fan_shock` | `(1−p_t)` на 5 сценариев + `p_t` на emergency-ветку | **primary** (expanding) |
| `fan_shock_weighted` | как `fan_shock`, но шаг каждой ветки смешан с последним фактическим шагом: `w_t·step + (1−w_t)·last_step` | вторичная гипотеза/robustness |
| `fan_emergency_ex_post` | на внеочередном заседании `p_t=1` и только emergency-ветка; иначе `fan_raw` | диагностика, не прогноз |

- `last_step` — фактический шаг предыдущего заседания; для первого фолда `w=1`, поэтому смешивание не требуется.
- `fan_shock_weighted` повторяет post-hoc `w_repeat` из #283 §6.1; на той же выборке это **не независимое подтверждение**, а вторичная гипотеза.
- Квантили — взвешенная эмпирическая функция распределения. При 5–6 точках интервалы 50/80/90 % coarse; это называется в отчёте.

## 6. Метрики

### 6.1 Coverage

Для каждого фолда и уровня `α ∈ {0.50, 0.80, 0.90}`:

```
[low, high] = weighted_quantiles(steps, weights, [(1−α)/2, 1−(1−α)/2])
covered = low <= actual_step <= high
coverage(α) = mean(covered)
```

- Доверительный интервал coverage — Wilson; номинал 80 % — primary.
- Ширина интервала — `high − low`; средняя по фолдам.

### 6.2 CRPS

Для взвешенного эмпирического распределения `{(x_i, w_i)}`, `Σw_i=1`:

```
CRPS = Σ_i w_i·|x_i − y| − 0.5·Σ_i Σ_j w_i·w_j·|x_i − x_j|
```

- Точечная масса даёт `|x−y|` — проверяется тестом.
- Разница CRPS между веерами — блочный бутстрап (блок 4 фолда, 2000 повторов, фиксированный seed), 95 % CI.

### 6.3 Точка и вероятности классов

- Точечный прогноз веера — взвешенная медиана; RMSE/MAE; DM-HLN против B1–B3 и `ordered_logit` на общих датах.
- Вероятности `{cut, hold, hike}` — масса веера по границам ±12.5 б.п.; Brier/log loss.
- Бенчмарки B1–B3 и `ordered_logit` считаются на тех же фолдах; вырожденное окно бенчмарка исключает пару из DM, но не из coverage/CRPS веера.

### 6.4 Эпизоды

Отдельно: 2014-12…2015, 2022–2023, 2024–2026; emergency vs non-emergency. Для каждого — coverage 80 %, CRPS, ширина, число фолдов.

### 6.5 Множественность

- Primary — **один** вариант: `fan_shock`, expanding, CRPS + coverage 80 %.
- `fan_raw`, `fan_shock_weighted`, `fan_emergency_ex_post`, rolling40 и чувствительности — robustness; p-value публикуются без поправки с пометкой; для семейства 5 сценариев — Bonferroni.
- Выбор лучшего варианта по тесту запрещён.

## 7. Правило решения

- **`promote`:** CRPS `fan_shock` значимо ниже `fan_raw` **и** ниже B1/B3/`ordered_logit` (95 % CI разницы ниже 0); coverage 80 % в `[0.70; 0.90]` и Wilson CI включает 0.8; медианный RMSE не значимо хуже `ordered_logit`.
- **`iterate`:** выполнена часть условий (например, coverage лучше, CRPS не значим; или CRPS лучше, coverage вне диапазона).
- **`reject`:** веер хуже или улучшения нет.
- Все варианты публикуются; причина решения — в отчёте и паспорте run.

## 8. Тесты

Офлайн (`scripts/key_rate_scenario_fan_test.py`, unittest, без ClickHouse/сети):

1. **Сценарии:** 5 штук; `hard` меняет γ2; `rational` fallback считает пропуски; `budget`/`no_market_loans` меняют gap в ожидаемую сторону; NaN не появляется.
2. **As-of:** точка после заседания не участвует; бюджетный лаг; `p_t`/`w_t` выровнены по датам.
3. **Веера:** `p=0` → `fan_shock == fan_raw`; `p=1` → масса на emergency; веса нормированы; квантили монотонны.
4. **CRPS:** точечная масса = `|x−y|`; coverage монотонен по уровню; ширина ≥ 0.
5. **Шоковый слой:** первые 24 веса = 1.0; emergency-ветка использует только прошлые шаги; пустая ветка не падает.
6. **Детерминизм:** повторный прогон даёт те же числа и sha256 артефактов; `ML_LOG` payload содержит метрики/предсказания.
7. **Выравнивание:** даты `CbrRow` и шоковой панели совпадают 1:1; расхождение — ошибка.
8. **Смешивание:** `fan_shock_weighted` при `w=1` совпадает с `fan_shock`.

## 10. Границы и риски

- **Не независимое подтверждение.** §6.1 #283 — post-hoc на той же выборке. Primary `fan_shock` выбран до прогона; `fan_shock_weighted` — вторичная гипотеза, а не доказательство.
- **6 шоковых меток.** `p_t` описательный; клип 0.25 и оговорка в отчёте.
- **Сценарные прокси.** `budget`/`no_market_loans` — reduced-form, не QPM; знак и масштаб фиксированы в §4, чувствительность — robustness.
- **As-of приближение**, не PIT: CPD/ВВП без винтажей; бюджетный лаг консервативный.
- **Множественные сравнения.** Bonferroni/пометка; никакого выбора лучшего варианта по тесту.
- **Coarse fan.** 5–6 точек на фолд; интервалы 50/80/90 % не являются гладким распределением.
- **Вне объёма:** `forecast_log`, ingest, Go/DDL/витрины/гранты, путь на несколько заседаний, CPI (Task 2), Phillips (#269).
