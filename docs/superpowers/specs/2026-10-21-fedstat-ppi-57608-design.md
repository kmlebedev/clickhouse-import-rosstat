> **Статус:** **Gate 0 (2026-10-21) — стоп; no-go по research [#341](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/341), пункт закрыт.** Маппинг имён работает, но значения 2021 расходятся с XLSX; причина — источник/винтаж, не маппинг ([Gate 0](../../research/2026-10-21-fedstat-ppi-57608-gate0.md), [методология](../../research/2026-10-21-fedstat-ppi-57608-methodology.md)). ## 1. Задача

В витрине `v_rosstat_ppi` товарные ИЦП (`series LIKE 'okpd2:%'`) есть только с 2021-01: источник — месячный XLSX Росстата `Proizvoditeli_Ind_tov_*.xlsx`, в котором история начинается с 2021 г. ЕМИСС 57608 «Индексы цен производителей по товарам и товарным группам с 2017 г.» отдаёт тот же показатель месячно с 2017 г.

Нужно догрузить 2017–2020 в отдельную таблицу `fedstat_ppi_product` и показать её в `v_rosstat_ppi` как `source='fedstat'` с теми же именами рядов `okpd2:<код>:<тип>`, чтобы один `WHERE series = ...` покрывал 2017–2026.

## 2. Источник и проверенные данные (live-пробы 2026-10-21)

- `https://www.fedstat.ru/indicator/57608`; периодичность месячная + годовая; период действия с 01.01.2017; ряд 2017–2026; последнее обновление 21.09.2026.
- 1 672 позиции ОКПД2, 4 вида показателя, 3 канала реализации, 100 значений ОКАТО, 12 месяцев, годы 2017–2026.
- Раскладка фильтров:
  - `lineObjectIds`: `57831` (ОКАТО), `57939` (ОКПД2), `58601` (каналы), `57937` (виды показателя);
  - `columnObjectIds`: `3` (год), `33560` (месяц);
  - `filterObjectIds`: `30611` (единица);
  - РФ до 2023 — `57831_1688487`; единица — `30611_950473` (процент);
  - канал «Всего» — `58601_1744137` (SDMX `s_kanalreal=1`);
  - виды: `57937_1707674` = ytd, `57937_1704142` = m/m, `57937_1704140` = period, `57937_1704141` = y/y;
  - SDMX: `s_OKPD2` = код ОКПД2, `s_POK`: 4 = ytd, 44 = m/m, 9 = period, 3 = y/y; `s_OKATO=643`.
- `format=excel` — компактная матрица (3 товара × 4 типа × 12 месяцев = 14,8 КБ), лист «Данные»: `регион | товар | канал | вид показателя | 12 месяцев`. **Кода ОКПД2 в Excel нет — только название товара.**
- `format=csv`/`format=xlsx` не поддержаны (HTML страницы); рабочие форматы — `excel` (BIFF `.xls`) и `sdmx`.
- На выборке из 3 товаров сверка с `rosstat_ppi_product` на 2021 г. сошлась до сотых (код `06.20.10.110`, газ): m/m март 100,18; ytd янв/фев 103,52/103,55; y/y 91,90/91,86; period март 91,93. **Полная сверка Gate 0 (1 156 товаров) дала расхождения:** медиана |diff| 0,0, но у 86 товаров накопленное m/m > 5 %, у 47 — > 10 %; коды двух выбросов («Алмазы», «Сера») подтверждены SDMX — это не маппинг, а ревизии/определения. См. [Gate 0](../../research/2026-10-21-fedstat-ppi-57608-gate0.md).
- В источнике есть дыры (например, пустые февральские ytd/m/m за 2019 г. у газа и говядины). Значения не восстанавливаем и не интерполируем.
- Rate limit: серия POST без паузы → 503. Режим — пауза 30 с, backoff 30/60/120 с, таймаут 180 с.

## 4. Модель данных

```sql
CREATE TABLE IF NOT EXISTS fedstat_ppi_product (
    date       Date,                    -- последний день отчётного месяца
    okpd2      LowCardinality(String),  -- код ОКПД2
    name       LowCardinality(String),  -- название товара из Excel (trim)
    index_type LowCardinality(String),  -- 'm/m' | 'ytd' | 'y/y' | 'period'
    value      Float64                  -- индекс, % (100 = без изменения)
) ENGINE = ReplacingMergeTree
ORDER BY (date, okpd2, index_type);
```

Дата — конец месяца, как в `rosstat_ppi_product`. Тип — из подписи Excel:
«К декабрю предыдущего года» → `ytd`; «К предыдущему месяцу» → `m/m`;
«К соответствующему периоду предыдущего года» → `period`;
«Отчетный месяц к соответствующему месяцу предыдущего года» → `y/y`.

DDL добавляется в `ARCHITECTURE.md` §6.2 тем же PR.

## 5. Импортёр `fedstat/ppi.go`

### 5.1. Конфиг источника

`fedstatSourceSpec` из #310:

- `indicator="57608"`, `title="fedstat_ppi_product"`, `layout=matrix`, `labelCount=4`;
- `left=[57831,57939,58601,57937]`, `top=[3,33560]`, `filter=[30611]`;
- `unitDim=30611`, `unitCode=950473`, `regionDim=57831`;
- `fixed=[58601_1744137, 57937_1707674, 57937_1704142, 57937_1704140, 57937_1704141]`;
- `allDims=[57939]`, `years=2017..2020`, `pause=30s`, `regionSwitch=false`.

Перед POST — guard: `len(config["57939"]) >= 1000`, иначе ошибка (структура страницы изменилась).

### 5.2. Цикл

1. DDL → гейт по форме таблицы (см. §5.4).
2. `fedstatFetchYears` по годам 2017–2020: GET страницы, токен, конфиг ОКПД2, POST `format=excel`, `fedstatParseExcel`.
3. `mapRecord`: `labels[0]` — регион, `labels[1]` — название, `labels[2]` — канал, `labels[3]` — вид; канал проверяется на «Всего»; `date` переводится с первого дня месяца (`fedstatPeriod`) на последний; тип — из подписи; значение — `record.value`.
4. Маппинг названия на ОКПД2 (см. §5.3), `fedstatDedupPoints`, `fedstatInsert` одним батчем.
5. `AfterImport`: `util.UpsertSeriesCatalog` (`source='fedstat'`). Витрину пересоздаёт `ppi_sa` в той же chain; `CreateView` идемпотентен.

### 5.3. Маппинг названия на код

Excel не содержит кода ОКПД2. Перед разбором:

```sql
SELECT okpd2, argMax(name, date) AS name
FROM rosstat_ppi_product FINAL
GROUP BY okpd2
```

- Нормализация: `strings.Join(strings.Fields(name), " ")`.
- Дубли имён — ошибка со списком.
- Неизвестное имя — `log.Warnf` + счётчик, строка пропускается; если неизвестных > 2 % товаров или > 50 позиций — импорт падает.
- В отчёт приёмки: сопоставлено / неизвестно / неоднозначно.

### 5.4. Гейт и покрытие

Гейт: `SELECT uniqExact(okpd2), uniqExact(toYear(date)), uniqExact(index_type), count() FROM fedstat_ppi_product FINAL` — все четыре величины совпадают с пинами Gate 0 (точное равенство, исторический срез).

Покрытие после разбора:

- годы ровно `{2017, 2018, 2019, 2020}`, `max(date)=2020-12-31`;
- каждый год и тип имеет хотя бы одну точку;
- `uniqExact(okpd2)` не ниже порога Gate 0 (ожидаемо ~1 300);
- дубли `(date, okpd2, index_type)` с разными значениями — ошибка;
- gaps логируются по годам/типам и не заполняются.
