# Источник пресс-релизов ЦБ по ключевой ставке (квартальные блоки) — спека

**Дата:** 23 октября 2026 г.
**Пункт:** `key-rate/phase-4-cbr-key-rate-press`, issue [#368](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/368).
**Роль:** Go.
**Зависимости:** нет; research-пункт #366 (квартальный блок в уставе публикаций) смержен.

## 1. Контекст и цель

Пресс-релиз ЦБ о ключевой ставке содержит квартальное сравнение темпов цен — главный аргумент решения: «В 3к26 текущий рост цен с поправкой на сезонность в среднем составил 8,0% в пересчете на год после 4,8% в 2к26. Аналогичный показатель базовой инфляции увеличился до 6,2% после 4,5%…» (§4.7 [KEY_RATE_PUBLICATIONS.md](../../KEY_RATE_PUBLICATIONS.md), пункт #366). Сегодня эти числа переносятся в публикацию руками.

Цель — источник по образцу `cbr_mp_summary`: шапка релиза, дословные абзацы и отдельный слой квартальных блоков с разобранными числами. Импортёр `cbr_key_rate_press`, история — с первого релиза с квартальным блоком (16.02.2024).

## 2. Источник (проверено на живом сайте 2026-10-23)

**Календарь заседаний** `https://www.cbr.ru/dkp/cal_mp/` — 64 заседания 2020-02 … 2027-12, разбитые по годам-табам. Каждое заседание — `div.main-events_day`:

```html
<div class="main-events_day">
  <div class="date col-md-5">16 февраля 2024 года</div>
  <div class="main-events ...">
    <div class="main-event">
      <div class="title"><span>Заседание Совета директоров Банка России по ключевой ставке</span>…
      <div class="info col-md-15"><a href="/press/pr/?file=16022024_133000key.htm">Пресс-релиз</a> …
```

Дата и ссылка на релиз берутся из одного блока; URL не конструируется (у выпусков 2014–2020 разные имена файлов, у 2024+ — `…_133000key.htm`).

**Страница релиза** `https://www.cbr.ru/press/pr/?file=…` — текст в `div.landing-text`, 16–20 абзацев `<p>`; первый абзац — решение, далее абзацы без заголовков; в конце — «следующее заседание» и «При использовании материала…».

Проверено: 23 заседания 2024-02-16 … 2026-10-23; квартальный абзац есть во всех, в 22 — с числами, в 2024-03-22 — без («Текущий рост цен с поправкой на сезонность в феврале оставался на уровне января…», годовая инфляция 7,7 % на 18 марта).

Формы квартального блока:
- квартал: «В 3к26», «В II квартале 2024 года», «В IV квартале 2024 года»;
- месяц/месяцы к среднему за квартал: «В июле», «В октябре — ноябре», «В среднем за декабрь — январь»;
- один или два базиса: «после 8,7% в 1к26 и 4,3% в 4к25», «по сравнению с 11,5% в осенние месяцы», «после в среднем 8,2% в 1к25».

## 3. Схема

Канонический DDL — [ARCHITECTURE.md](../../../ARCHITECTURE.md) §6.2; копии в `cbr/key_rate_press.go` сверяются тестом-пином.

```sql
CREATE TABLE IF NOT EXISTS cbr_key_rate_press (
    meeting_date Date,
    published Date,                          -- дата публикации (у релиза = дата заседания)
    url String,
    decision_action LowCardinality(String),  -- 'hold'|'cut'|'hike'
    decision_rate Float64,                   -- % годовых
    decision_delta_bp Nullable(Int16),       -- шаг к предыдущему решению своего ряда; у первого NULL
    effective_from Nullable(Date),           -- «с …» для cut/hike; NULL для hold
    next_meeting_date Nullable(Date),
    signal String                            -- дословные предложения про сигнал
) ENGINE = ReplacingMergeTree ORDER BY meeting_date;

CREATE TABLE IF NOT EXISTS cbr_key_rate_press_block (
    meeting_date Date,
    block LowCardinality(String),  -- decision|guidance|inflation_quarter|expectations|activity|labor|monetary|credit|risks|budget|forecast|publications|next_meeting|other
    seq UInt16,                    -- порядок абзаца в релизе (истина; block — эвристика)
    text String
) ENGINE = ReplacingMergeTree ORDER BY (meeting_date, seq);

CREATE TABLE IF NOT EXISTS cbr_key_rate_press_quarter (
    meeting_date Date,
    seq UInt16,                    -- seq того же абзаца в block-таблице
    published Date,
    url String,
    period LowCardinality(String), -- '3к26' | 'июль' | 'октябрь — ноябрь' | 'II квартал 2024'
    form LowCardinality(String),   -- 'quarter' | 'month' | 'none'
    headline Nullable(Float64),            -- текущий рост цен, % SAAR
    headline_prev Nullable(Float64),
    headline_prev2 Nullable(Float64),      -- второй базис («… и 4,3% в 4к25»)
    core Nullable(Float64),                -- базовая инфляция, % SAAR
    core_prev Nullable(Float64),
    core_prev2 Nullable(Float64),
    annual_inflation Nullable(Float64),    -- годовая инфляция, оценка ЦБ
    annual_asof Nullable(Date),            -- «по оценке на 19 октября»
    parsed UInt8,                          -- 1 — числа разобраны; 0 — только текст
    text String                            -- дословный абзац
) ENGINE = ReplacingMergeTree ORDER BY (meeting_date, seq);
```

Ключ `ReplacingMergeTree` — `meeting_date` (шапка) и `(meeting_date, seq)` (текст и квартал): повторный прогон идемпотентен, порядок абзацев — часть ключа.

## 4. Разбор

Тело: `div.landing-text p`; пустые абзацы (`&nbsp;`) пропускаются; нет контейнера или < 1 абзаца — ошибка (вёрстка изменилась).

**Решение** (первый абзац): `Совет директоров Банка России <D> <месяц> <YYYY> года принял решение (сохранить|снизить|повысить) ключевую ставку (на N б.п., )?(до|на уровне) X% годовых`; действие — `hold|cut|hike`; `effective_from` — «с <D> <месяц> <YYYY> года» только для cut/hike; `next_meeting_date` — «Следующее заседание … запланировано на <D> <месяц> <YYYY> года» (из любого абзаца).

**Сигнал** — абзацы с «Банк России будет принимать дальнейшие решения…», «Банк России допускает…», «Банк России будет поддерживать…»: дословно, через пробел.

**Блоки** — все непустые абзацы с `seq` (с 1). `block` — эвристический слаг по ключевым словам (словарь в коде): `decision`, `guidance`, `inflation_quarter`, `expectations`, `activity`, `labor`, `monetary`, `credit`, `risks`, `budget`, `forecast`, `publications`, `next_meeting`, `other`. `seq` — истина, `block` — удобство агента; в витрине это названо.

**Квартальный блок** — абзац, содержащий «текущий рост цен» (без учёта регистра). Для каждого:
- `period` — текст перед «текущий рост цен» без хвоста «В среднем за»/«В»: «3к26», «июль», «октябрь — ноябрь», «II квартал 2024»; пусто, если фразы нет;
- `form` — `quarter`, если period содержит `\dк\d\d` или римский квартал (`I`–`IV` + «квартал»); `month`, если содержит название месяца; `none`, если чисел нет;
- `headline` — первое `X%` после «текущий рост цен» и до «базовой инфляции»; числа — десятичная запятая;
- `headline_prev` — число после «после» (допускается «в среднем») или «по сравнению с» в том же предложении; `headline_prev2` — число после «и …%» в том же хвосте (два базиса);
- `core`, `core_prev`, `core_prev2` — то же в предложении с «базовой инфляции»;
- `annual_inflation` — число в предложении с «Годовая инфляция» / «Показатель годовой инфляции» и «составил…»; диапазон «по итогам года сложится в диапазоне 7,1–7,6%» не число факта и не парсится;
- `annual_asof` — дата из «по оценке на <D> <месяц>» (год заседания; месяц больше месяца заседания → год−1);
- если стандартная пара «текущий/базовая» не найдена — `parsed=0`, числа NULL, warn; строка сохраняется (текст — источник истины). Пример — 2024-03-22.

**Дельта**: `decision_delta_bp = round((rate − previous_rate) × 100)` по прошлым решениям своего ряда (ORDER BY meeting_date); у самого раннего — NULL.

## 5. Импорт и идемпотентность

Порядок (свой `Import()`, шаблон не используется — три таблицы):

1. DDL трёх таблиц.
2. Витрины и каталог — до сети и до гейта (самолечение на no-op).
3. `util.GetPage(pressCalendarUrl)` → даты и ссылки заседаний.
4. Отбор: `meeting_date >= 2024-02-16` и `<= сегодня` (МСК = фиксированный UTC+3, без DST).
5. Гейт: `SELECT DISTINCT meeting_date FROM cbr_key_rate_press FINAL`. Неполные документы перекачиваются: шапка без блоков; блок `inflation_quarter` без строки квартала с тем же `(meeting_date, seq)`.
6. По каждому выпуску: `util.GetPage(url)` → разбор → три батча (шапка, блоки, квартал), `Append` с проверкой, `Abort` на ошибке.
7. Релиз сегодняшнего дня до 13:30 МСК: страница без абзаца решения → warn «ещё не опубликован», пропуск (иначе ежедневный dagu в 09:17 краснел бы в день заседания). Для прошлых дат то же состояние — ошибка.

Регистрация — `cbr/importers.go`, таблица литералом, `countPoints=""`: префлайта нет, известность — по `meeting_date` (прецедент `cbr_mp_summary`; артефакт — набор выпусков, а не один файл).

## 6. Производные

Витрины (комментарии таблиц и колонок обязательны):

- `v_cbr_key_rate_press` — шапки;
- `v_cbr_key_rate_press_blocks` — абзацы;
- `v_cbr_key_rate_press_quarters` — квартальные блоки с числами (колонки `headline*`, `core*`, `annual_*`, `parsed`, `text`).

Каталог `series_catalog` (source `cbr_key_rate_press`, frequency `irregular`): `decision_rate`, `decision_delta_bp`, `headline_saar`, `core_saar`, `annual_inflation` — с unit/origin/description. Гранты — `sql/mcp_kimi_reader.sql`, проверка — `scripts/mcp_check.py` (три витрины непусты, три сырые таблицы закрыты).

## 8. Расписание и приёмка

Шаг `cbr_key_rate_press` — в хвосте `dagu/cbr.yaml` (ежедневно 09:17): падение нового шага не лишает данных уже проверенные. В день заседания после 13:30 релиз импортируется ручным `make import STAT=cbr_key_rate_press` (публикационный контур), на следующее утро — штатным шагом.

Приёмка: `make import STAT=cbr_key_rate_press ARCHIVE_BACKEND=local ARCHIVE_LOCAL_DIR=build/archive-dev` → 23 шапки, блоки всех абзацев, 23 квартальные строки; спот-сверка; повтор — `Imported 0 rows`; `make all`, `make docs-check`, `dagu validate dagu/cbr.yaml`, `make mcp-check` — зелёные; протокол — комментарием в PR.

## 9. Ограничения

- Квартальные числа разбираются из прозы; при новой формулировке строка сохраняется с `parsed=0`, числа не выдумываются.
- `block` — эвристика; истина — `seq` и текст.
- Правка релиза под той же датой гейтом не отслеживается (как у `cbr_mp_summary` и `cbr_mt_forecast`): лечение — удалить строки выпуска и повторить прогон.
- До 2024-02 квартального блока в релизах нет — история сознательно начинается с него.
