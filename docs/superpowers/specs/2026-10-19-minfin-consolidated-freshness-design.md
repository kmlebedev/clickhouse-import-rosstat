## 1. Симптом и корень

В новом XLSX строка называется **`Акцизы ****`** (звёздочки — сноска источника). Парсер `fedbudMesyatsImport` сравнивает `row[1]` с точным `"Акцизы"` через `slices.Contains` и молча пропускает ряд: остальные четыре ряда обновляются, акцизы остаются старыми. Это не «источник перестал публиковать» — данные в файле есть.

Дополнительные дефекты того же файла:

- селектор — длинный CSS-путь, не константа, нет офлайн-теста.

## 3. Решение

### 3.1. Нормализация подписи

```go
label := strings.TrimSpace(row[1])
label = strings.TrimRight(label, "* ")
if slices.Contains(fedbudMesyatsFields, label) { … }
```

Снимаются хвостовые `*` и пробелы; `Акцизы ****` → `Акцизы`. Это соответствует §6.6 стандарта: ожидаемое изменение подписи источника не должно молча терять ряд. Если подпись изменится содержательно (не только сноска), ряд не найдётся — это ошибка/пробел, а не «0 строк»; тест на фикстуре фиксирует текущую подпись.

### 3.2. Транспорт

Вместо `colly`:

```go
const fedbudMesyatsLinkSelector = `a[href*="_mesyats.xlsx"]`

func getFedbudMesyatDataUrl() (string, error) {
    page, err := util.GetPage(minfinUrl + conbudExecutePath)
    if err != nil { return "", err }
    href, err := util.FindLink(page, fedbudMesyatsLinkSelector)
    if err != nil { return "", err }
    return minfinUrl + href, nil
}
```

`Import()` возвращает ошибку, если страница/ссылка недоступна; шаблон/оператор видит причину, а не пустой URL. Селектор — константа, проверяется на HTML-фикстуре.

### 3.3. Логирование

Убрать `fmt.Printf` и закомментированный debug. Оставить `log` только если нужно; шаблон уже логирует `Imported %d rows`.

### 3.5. Freshness-проверка MCP

В `scripts/mcp_check.py` рядом с контуром Минфина:

1. **Лаг консолидированного от федерального:**
   `dateDiff('month', max(minfin_mesyats), max(minfin)) <= 2`.
   До фикса: 2026-09 − 2026-06 = 3 → FAIL; после: 2026-09 − 2026-08 = 1 → OK.
2. **Лаг `Акцизы` от общего max консолидированного:**
   `dateDiff('month', max(Акцизы), max(minfin_mesyats)) <= 1`.
   До фикса: 2026-08 − 2026-06 = 2 → FAIL; после: 0 → OK.

Порог 1–2 месяца выбран потому, что консолидированный выпуск может отставать от федерального на месяц, а `Акцизы` — на месяц от других рядов; трёхмесячный разрыв уже означает пропущенный ряд/шаг.

## 5. Риски

- Подпись может получить другую сноску (`*`, `**`, буквы) — `TrimRight("* ")` покрывает звёздочки/пробелы; содержательное переименование даст пропуск, который ловит freshness-проверка `Акцизы`.
- `GetRows` переведён на `RawCellValue: true` (§6.2): без него excelize округлял значения до одного знака (1115,9 вместо 1115,85). Даты шапки в raw-режиме приходят сериалами Excel; `fedbudMesyatsDate` принимает и сериал, и форматированную строку `Jan-11`/`янв.23 ***`. Это меняет точность уже импортированных значений (округлённые → точные) — названное исправление, а не «данные не менялись».
- DAG может не запускаться/падать по внешней причине; freshness-проверка в `mcp-check` ловит результат, а не причину. Причина вне кода — сообщается владельцу.
