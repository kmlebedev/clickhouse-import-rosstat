# Спека: Минфин — федеральный дефицит и нефтегазовые доходы

**Дата:** 19 октября 2026 г.
**Пункт роадмапа:** `key-rate/phase-2-minfin-scrape` ([ROADMAP_KEY_RATE.md](../../ROADMAP_KEY_RATE.md) §4.2 №15, §4.3 №15, фаза 2).
**Issue:** [#116](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/116).
**Нормативы:** [IMPORTER_PACKAGE_STANDARD.md](../../IMPORTER_PACKAGE_STANDARD.md) §4–§12, [ARCHITECTURE.md](../../../ARCHITECTURE.md) §3, §6.2, §6.3, §8 п. 13.

## 1. Цель и объём

Закрыть пробел §4.2 №15 контура ключевой ставки — бюджетный импульс:

1. федеральный дефицит **отдельной строкой** (сейчас дефицит есть только у консолидированного бюджета);
2. НДПИ;
3. нефтегазовые доходы федерального бюджета.

Источник — Минфин:

- `Prilozhenie_3_dannye_109-111_—_mes.xlsx` — уже используется импортёром `minfin_fed_bud_mes`; в файле есть строка `Дефицит (-)/Профицит (+)`;
- `Svedeniya_<YYYYMMDD>.xlsx` — новый артефакт: нефтегазовые доходы и НДПИ.

Вне объёма: компоненты НДПИ (нефть, газ, газовый конденсат), экспортная пошлина, НДД, базовый/дополнительный нефтегазовый объём, длинная история нефтегазовых доходов из `Prilozhenie_3` (2011+), полный рефакторинг пакета `minfin/` (замена `colly` на `util`, удаление `fmt.Printf`).

## 2. Разведка источника (2026-10-19)

### 2.1. Страница и ссылка

- Каталог федерального бюджета: `https://minfin.gov.ru/ru/statistics/fedbud/`.
- Без браузерного User-Agent источник отдаёт 503; `util.GetPage`/`util.GetXlsx` используют `randomUA`, поэтому транспорт соответствует правилу 4 AGENTS.md.
- На странице ровно одна ссылка `Svedeniya_<YYYYMMDD>.xlsx`:
  `/common/upload/library/2026/10/main/Svedeniya_20261005.xlsx`.
- URL **не строится по дате**: имя файла содержит дату публикации, а каталог `library/<год>/<месяц>/main/` меняется от выпуска к выпуску; угадывание даты даёт 404. Ссылка берётся со страницы тем же кодом, что и в тесте: `util.GetPage` + `util.FindLink`.
- Селектор — константа пакета: `a.file_item[href*="Svedeniya_"]` (на живой странице одно совпадение).

### 2.2. Структура `Svedeniya_<YYYYMMDD>.xlsx`

- Один лист: `Информационное сообщение`.
- Шапка — строка 4: `A4 = «Показатели»`, далее колонки:
  - месячные — raw-сериалы Excel (`43101` = 2018-01-01, …);
  - годовые — целые числа `2018` … `2025`.
- Нужные строки верхнего уровня:
  - `Нефтегазовые доходы, всего`;
  - `Налог на добычу полезных ископаемых`.
- Значения — **помесячные потоки** в млрд руб. (не накопленные), 105 месяцев на ряд: 2018-01 … 2026-09 в выпуске 05.10.2026.
- Последняя месячная колонка шапки (2026-10) может быть пустой: пустая ячейка — не точка (§6.7 стандарта).
- В файле есть одноимённые подстроки (`Нефть`, `Газ` в НДПИ и в экспортной пошлине), поэтому ряды берутся только по точным подписям верхнего уровня из карты кода.

Spot-значения выпуска 05.10.2026:

| Ряд | 2018-01 | 2026-09 |
|---|---|---|
| `Нефтегазовые доходы, всего` | 661.3 | 452.4 |
| `НДПИ` | 442.9 | 807.0 |

### 2.3. Федеральный дефицит

`Prilozhenie_3_dannye_109-111_—_mes.xlsx` содержит строку `Дефицит (-)/Профицит (+)` с накоплением с начала года. Существующий `fedBudImport` уже переводит накопленные значения в месячные разности; отдельный парсер не нужен.

## 3. Решения

1. **Федеральный дефицит** — добавить `"Дефицит (-)/Профицит (+)"` в `fedbudMesFields` импортёра `minfin_fed_bud_mes`; ряд пишется в существующую таблицу `minfin_fed_bud_mes` (source `minfin`), месячные разности, млрд руб.
2. **Новый импортёр `minfin_oil_gas_mes`** — таблица `minfin_oil_gas_mes`, значения `Float64` (правило 5 AGENTS.md).
3. **Два ряда нового импортёра**, имена объявлены кодом:
   - `Нефтегазовые доходы, всего`;
   - `НДПИ`.
4. **Годовые колонки не импортируются**; значения — месячные потоки, без разностей. Это фиксируется в `description`.
5. **Точка контроля публикации** объявляется: файл обновляется раз в месяц, шаг — раз в месяц; HEAD-префлайт и версия в `source_publications` дают no-op на повторе.
6. **Реестр пакета** — `minfin/importers.go` с единственным `init()`; регистрация двух legacy-импортёров переносится механически, без изменения их разбора и транспорта. Пакетный рефакторинг `colly`/`fmt.Printf` — отдельный пункт.
7. **Витрина** — расширяется существующая `v_minfin_budget` третьим источником `minfin_oil_gas`; отдельная витрина не заводится: это тот же бюджетный контур, агент читает одну long-форму.
8. **Процесс трекера** — взятие пункта в работу сразу переводит issue в Project V2 `Status = In Progress` (до первого коммита, не ожидая PR). Норма фиксируется в `AGENTS.md` и скиле `github-tracker`.

## 4. Модель данных

### 4.1. Таблица

```sql
CREATE TABLE IF NOT EXISTS minfin_oil_gas_mes (
    name LowCardinality(String),
    date Date,
    value Float64
) ENGINE = ReplacingMergeTree ORDER BY (name, date);
```

- `name` — стабильное имя ряда из карты кода (`Нефтегазовые доходы, всего`, `НДПИ`);
- `date` — 1-е число отчётного месяца;
- `value` — млрд руб. за месяц; отрицательных значений у этих двух рядов нет.
- Ключ `(name, date)`: повторный импорт того же выпуска перезаписывает значения (ревизии источника), пропавшая из файла точка не удаляется.

### 4.2. Витрина `v_minfin_budget`

`Tables`: `minfin_fed_bud_mes`, `minfin_fed_bud_mesyats`, `minfin_oil_gas_mes`.

```sql
SELECT 'minfin' AS source, name AS series, date, toFloat64(value) AS value FROM minfin_fed_bud_mes FINAL
UNION ALL SELECT 'minfin_mesyats', name, date, toFloat64(value) FROM minfin_fed_bud_mesyats FINAL
UNION ALL SELECT 'minfin_oil_gas', name, date, toFloat64(value) FROM minfin_oil_gas_mes FINAL
```

Комментарии таблицы и колонок обновляются: `minfin_oil_gas` — нефтегазовые доходы и НДПИ из `Svedeniya_<дата>.xlsx`; отрицательное значение дефицита — только у ряда `Дефицит (-)/Профицит (+)`.

### 4.3. Каталог `series_catalog`

| source | series | unit | frequency | origin |
|---|---|---|---|---|
| `minfin` | `Дефицит (-)/Профицит (+)` | млрд руб. | M | `Prilozhenie_3_…_mes.xlsx`, лист «месяц», строка «Дефицит (-)/Профицит (+)» |
| `minfin_oil_gas` | `Нефтегазовые доходы, всего` | млрд руб. | M | `Svedeniya_<YYYYMMDD>.xlsx`, лист «Информационное сообщение», строка «Нефтегазовые доходы, всего» |
| `minfin_oil_gas` | `НДПИ` | млрд руб. | M | тот же файл, строка «Налог на добычу полезных ископаемых» |

В `description` явно: месячные потоки, не накопленные; годовые колонки не импортируются; НДПИ — одна из составляющих нефтегазовых доходов, сумма двух импортированных рядов не равна нефтегазовым доходам; данные с 2018-01.

## 5. Импортёр

### 5.1. Транспорт и ссылка

1. `util.GetPage(oilGasPageUrl)` — страница каталога.
2. `util.FindLink(page, oilGasLinkSelector)` — href; пусто — ошибка с доменом и ожидаемым именем файла.
3. `s.DataUrl = minfinUrl + href`.
4. `s.ClickHouseImport.Import(ctx, conn)` — полный шаблонный цикл: DDL → префлайт → точки → архив → `AfterImport` → версия.

### 5.2. Разбор

- `xlsx.GetRows("Информационное сообщение", excelize.Options{RawCellValue: true})` — сырые значения (§6.2 стандарта).
- Строка шапки ищется по якорю `Показатели` в первом столбце; индексы колонок выводятся из шапки, а не пишутся числом.
- Классификация колонок:
  - числовой сериал ≥ 20000 → месяц, `excelize.ExcelDateToTime(serial, false)`, дата нормализуется к 1-му числу месяца;
  - целое 1900…2100 → годовая колонка, пропуск;
  - первая колонка и нечисловые ячейки — пропуск.
- Строки: карта `label → series`; точное совпадение после `TrimSpace` и нормализации внутренних пробелов. Подстроки НДПИ не импортируются.
- Значения: пустая ячейка или `-` — пропуск; иначе `strconv.ParseFloat` с удалением пробелов (включая неразрывные); запятая не удаляется — в локали она может быть десятичной; ошибка — с контекстом «таблица, лист, строка, колонка».
- Fail-fast: нет листа, нет шапки, нет хотя бы одной ожидаемой строки, ноль точек — ошибка, а не «0 rows».

### 5.3. Производные

- `AfterImport: publishFedbud(ctx, conn, oilGasSeriesMeta)` — upsert каталога и `CREATE OR REPLACE VIEW v_minfin_budget`; шаблон вызывает это после точек и до строки версии.
- `PublicationCountPoints: "SELECT count() FROM minfin_oil_gas_mes FINAL"`.

### 5.4. Реестр и расписание

- `minfin/importers.go`: `minfinImporter{chimport.ImportStat; table, countPoints string}`, три литеральные записи, единственный `init()`.
- `dagu/minfin.yaml`: шаг `minfin_oil_gas_mes` третьим, `retry_policy` как у соседей; расписание `41 10 10 * *` не меняется.

## 8. Критерий приёмки

1. `minfin_fed_bud_mes` содержит отдельный ряд `Дефицит (-)/Профицит (+)` (source `minfin`), месячные разности YTD-накопления, 2011-01 … последний месяц файла.
2. `minfin_oil_gas_mes` импортирует `Svedeniya_<YYYYMMDD>.xlsx`, найденный со страницы каталога: `Нефтегазовые доходы, всего` и `НДПИ`, помесячно 2018-01 … последний месяц файла, млрд руб., Float64.
3. Повторный прогон — no-op с версией в `source_publications` и объектом в винтажном архиве.
4. `v_minfin_budget` содержит `source='minfin_oil_gas'`; `v_series_catalog` описывает оба ряда; сырая `minfin_oil_gas_mes` агенту закрыта.
5. `make all`, `make mcp-check`, `dagu validate dagu/minfin.yaml`, `make docs-check` — зелёные.
6. Роадмап и Project V2 отражают статус; issue закрывается `Closes #116`.

## 9. Отступления и риски

- Отступлений от стандарта у нового импортёра нет. Пакет `minfin/` в целом остаётся частично соответствующим: legacy-импортёры используют `colly` и `fmt.Printf` — это отдельный пункт рефакторинга, в объём не входит.
- Смена подписей строк нового источника — ошибка с именем таблицы, листа и подписи; «0 rows» не допускается. Legacy-парсер `fedBudImport` в объём не входит и не менялся: пропавшую строку федерального дефицита ловит MCP-проверка данных витрины (`v_minfin_budget`), а не каталога.
- Годовые колонки — классификация по raw-сериалу и целому году, тест фиксирует 105 месячных дат на ряд.
- Пустая последняя месячная колонка — не точка.
- ClickHouse недоступен — работа не блокируется: сообщить пользователю и попросить поднять `make ch-up`; `ch-up`/`ch-down` самостоятельно не запускать.
