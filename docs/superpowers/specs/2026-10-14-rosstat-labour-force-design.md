## 1. Цель и объём

### 1.1. Цель

Закрыть **четвёртый по счёту канал контура ключевой ставки**: рынок труда РФ. ЦБ называет его в каждом резюме обсуждения ставки — в [KEY_RATE_CHANNELS.md](../KEY_RATE_CHANNELS.md) канал `labor_market` занимает 286 regex-строк на 22 документах; в БД сегодня есть только безработица США (`bls`), российской нет. Шесть рядов одним файлом — рабочая сила, занятые, безработные (уровни, тыс. чел.) и уровни участия, занятости, безработицы (%).

### 1.2. Объём

Новый импортёр `rosstat_labour_force_mes` в пакете `rosstat/`: таблица, каталог 6 рядов, расширение витрины `v_rosstat_macro`, запись в реестр, шаг в `dagu/rosstat.yaml`, фикстуры и тесты, проверки `scripts/mcp_check.py`, сопряжённые правки документации и §4.2/§6 роадмапа.

### 1.3. Вне объёма (названо явно)

- **Глубина до 2017 г.** Росстат публикует ряд в возрасте «15 лет и старше» только с 2017-01; в книге нет ни одного ряда старше (проверены «Содержание» и все 7 листов), на странице — тоже. Длинная история (1992–2016) потребовала бы другого источника: ЕМИСС без ключа недоступен (JS-шелл + reCAPTCHA), единственные `.xls` с длинной историей — BIFF8, который `excelize/v2` не читает, и заморожены на 2016 г. Отдельный пункт, если понадобится.
- **Сезонно сглаженный ряд безработицы** — Росстат его не публикует: на `/labour_force` строка «сезон» не встречается ни разу (проверено по странице и по всем книгам карточки). Дезезонализация — задача модели ([KEY_RATE_MODEL.md](../KEY_RATE_MODEL.md) §4), не импортёра.
- Вариант «15–72 лет» (`trud_1_15-72.xlsx`), потенциальная рабочая сила (`prs_2025.xlsx`, `s_prs_2025.xlsx`), региональные листы 1–4 и листы 6–7 книги (образование рабочей силы) — не берутся (YAGNI).
- Региональный разрез: только РФ.
- Правка битых URL и фиксация проверенных источников остальных пробелов §4.2 — отдельный docs-коммит этой же ветки (`ROADMAP_KEY_RATE.md`), кода не касается.
- Ряд `rosstat_ipc_weeks` и другие импортёры пакета не трогаются.

## 2. Источник (проверено живыми запросами 2026-10-14)

| Что | Значение |
|---|---|
| Landing | `https://rosstat.gov.ru/labour_force` — HTTP 200, серверный HTML, анти-бот барьера нет; GET и HEAD отдают файл без обхода challenge |
| Селектор ссылки | `a[href$="trud-1_15-s.xlsx"]` → `/storage/mediabank/trud-1_15-s.xlsx` («Численность и состав рабочей силы в возрасте 15 лет и старше») |
| Ловушка имени | у этого файла **дефис** (`trud-1_15-s`), у соседних — подчёркивание (`trud_1_15-72`), поэтому селектор не должен быть по общей маске `trud` |
| Файл | ~343 КБ; имя **стабильное**, обновляется на месте (~раз в месяц); HEAD отдаёт `Last-Modified` и `ETag` — точка контроля публикации применима |
| Лист | «5» — «Численность и состав рабочей силы в возрасте 15 лет и старше по Российской Федерации» |
| Разметка | A1 «К содержанию», A2 заголовок, A3 «(по данным выборочных обследований рабочей силы, тыс. чел.)»; **шапка в строках 5–6**, данные с 7-й; диапазон `A1:G135` |
| Шапка | B5 «Рабочая сила»; C5 «в том числе», C6 «занятые», D6 «безработные»; E5 «Уровень участия в составе рабочей силы, в %»; F5 «Уровень занятости, `\n` в %» (**с переводом строки**); G5 «Уровень безработицы, в %» |
| Годы | отдельными строками-секциями: A = «2017» … «2026» (текст), данные — строки месяцев ниже |
| Месяцы | подписи со сносками источника: `январь1)`, `февраль1)`, …, с **октября 2022 — две сноски**: `октябрь1)2)` |
| Конец данных | строка 131 (`июль2)`); строки 132–133 — текст сносок, 134–135 пусты |
| Глубина | помесячно **2017-01 … 2026-07** = 115 месяцев, **690 точек** |
| Значения | сырые (`RawCellValue: true`): рабочая сила 2017-01 = `76489.193`, уровень безработицы 2017-01 = `5.6`; последний месяц 2026-07: рабочая сила `76389.482`, занятые `74660.473`, безработные `1729.009`, участие `62.9`, занятость `61.5`, безработица `2.3` |

**Сноски источника и методологический разрыв.** `1)` — «Данные пересчитаны с учетом итогов ВПН-2020.»; `2)` — «Без учета статистической информации по Донецкой Народной Республике (ДНР), Луганской Народной Республике (ЛНР), Запорожской и Херсонской областям.» С **октября 2022 г.** обе сноски стоят на каждом месяце, то есть ряд с этого месяца идёт **без четырёх регионов** — это разрыв покрытия, а не другой показатель. Дословная сверка «как в источнике»: значения месяцев со сносками записываются точками (как в `rosstat_salaries_mes`, где сноска тоже оговорка о покрытии), а разрыв назван в `description` ряда, чтобы агент MCP не прочитал сдвиг уровня как изменение экономики.

## 3. Решения

1. **Транспорт — существующий контур, без правок `util/`.** Ссылка вычисляется: `util.GetPage(labourForceUrl)` → `util.FindLink(page, labourForceLinkSelector)` → `rosstatUrl + href` → `util.GetXlsx` (стандарт §4.1, §5.4). Селектор и адрес страницы — константы пакета рядом с импортёром (§4.5); нет ссылки — ошибка с именем ожидаемого файла, а не `GetXlsx("")` (§4.4). Страница — HTML-фикстура в тестах, тот же селектор.
2. **Таблица `rosstat_labour_force_mes`** — зеркало `rosstat_salaries_mes`, значения **Float64** (новые таблицы, ARCHITECTURE §4):

   ```sql
   CREATE TABLE IF NOT EXISTS %s (
         name LowCardinality(String)
       , date Date
       , value Float64
   ) ENGINE = ReplacingMergeTree ORDER BY (name, date);
   ```

3. **Шесть рядов, имена закреплены кодом** (§6.8) — заголовки источника меняются от редакции к редакции, ряд из заголовка оборвался бы:

   | Series (пин) | Якорь в шапке | Unit | Freq |
   |---|---|---|---|
   | `Рабочая сила` | B5 | тыс. чел. | M |
   | `Занятые` | C6 | тыс. чел. | M |
   | `Безработные` | D6 | тыс. чел. | M |
   | `Уровень участия в составе рабочей силы` | E5 | % | M |
   | `Уровень занятости` | F5 | % | M |
   | `Уровень безработицы` | G5 | % | M |

4. **Дата точки — последний день отчётного месяца** (UTC), как у `rosstat_ipc_mes` — ближайшего помесячного ряда пакета, стоящего в той же витрине: значение относится к отчётному месяцу и лежит внутри него. Альтернатива («1-е число следующего месяца», как у `rosstat_salaries_mes`/`rosstat_vvp_kvartal`) отклонена: она сдвигала бы помесячный ряд относительно соседнего помесячного ряда той же витрины. Привязка названа в `description` каждого ряда и проверяется spot-тестом.
5. **Разбор — по признаку, без магических индексов** (§6.3): лист «5» ищется по имени (нет — ошибка, §6.4); строка шапки — по ячейке «Рабочая сила»; каждая из шести колонок — по нормализованной подписи (пробелы и переводы строк сжимаются, иначе `Уровень занятости, \nв %` не найдётся), ровно одно совпадение на ряд; год переносится вперёд из строки-секции; подпись месяца очищается от хвостовых сносок (`январь1)` → `январь`, `октябрь1)2)` → `октябрь`) до обращения к `util.MonthsToNum` — **существующий хелпер сноски не понимает** (`util/xls.go:25`), это новое требование разбора.
6. **Fail-fast (§6.4):** нет листа «5»; не найдена шапка; у любого из шести рядов колонка не найдена или найдена дважды; строка месяца до появления года; месяц вне возрастания внутри года; нечисловое значение; пустой разбор — ошибка с именем таблицы, листа и строки. Ошибка — возврат, не `panic` (§6.5). Пустая ячейка — не точка (§6.7): у последних месяцев нового года данных ещё нет.
7. **Точка контроля публикации объявляется** (§9.1): файл перезаписывается на месте под стабильным именем, обновляется ~раз в месяц, шаг dagu — недельный. `PublicationCountPoints = "SELECT count() FROM rosstat_labour_force_mes FINAL"`; `PublicationSource` не нужен — `Name() == TableName` (§9.4). Повторный прогон по тому же файлу — `no-op` без скачивания.
8. **Витрина не заводится новая**: ряды идут в общую `v_rosstat_macro` тем же хелпером `afterRosstatMacro` (§10.2), строка `toFloat64(value)`. Новых грантов не требуется — витрина уже выдана `kimi_reader`, а гранты переживают `CREATE OR REPLACE VIEW`; сырая таблица агенту не выдаётся (§10.4).
9. **Шаг dagu — последним в цепочке** `dagu/rosstat.yaml`: `type: chain` останавливает последующие шаги при падении предыдущего, и падение нового импортёра не должно лишать данных четыре существующих ряда (§12.1, §12.3).
10. **Каталог двусторонний** (§11.4): имена объявлены кодом, поэтому тест проверяет и «разобрано ⊆ описано», и «описано ⊆ разобрано».

## 5. Риски и митигации

| Риск | Митигация |
|---|---|
| Селектор опирается на опечатку источника (дефис вместо подчёркивания); Росстат может её исправить | Падение громкое и адресное (§4.4, §6.4) — правится один литерал; пока опечатка на месте, селектор `$="trud-1_15-s.xlsx"` соседних файлов не цепляет |
| Подписи месяцев со сносками и перевод строки в шапке | Сноски снимаются хвостовым правилом, шапка нормализуется по пробелам; оба случая закрыты тестами на реальной фикстуре (§11.1) |
| Разрыв покрытия 2022-10 прочитан как экономический сдвиг | Назван в `description` каждого из шести рядов |
| Страница 872 КБ не влезает в фикстуру | Урезается до карточки с сохранением классов; при поломке разметки берётся вариант `?print=1` (95 КБ, те же ссылки) |
| Новый шаг ломает цепочку остальных четырёх рядов | Шаг **последний**; предпосылки-зависимости у пакета нет |
| Глубина 2017+ короче контура (ставка с 2013) | Названо в §1.3 и в `description` («ряд с 2017»), чтобы модель не считала историю полной |

## 6. Приёмка

По стандарту §16.1:

1. `make all` — зелёный (gofmt, golangci-lint, `go vet ./...`, `go test -race ./...`, обе сборки); отдельно `go test -race -count=1 ./rosstat/`.
2. Живой прогон `make import STAT=rosstat_labour_force_mes` — число строк и крайние даты.
3. Повторный прогон — `no-op, версия … уже импортирована, … точек на месте`.
4. Spot-сверка с живым файлом: 2–3 значения (уровень безработицы и рабочая сила за последний отчётный месяц) — ячейка источника → значение витрины.
5. `make mcp-check` — ПРОВЕРКА ПРОЙДЕНА.
6. `dagu validate dagu/rosstat.yaml` — exit 0.
7. Документация и статус роадмапа обновлены тем же PR (§13.1, §13.2).
