## 1. Контекст

Пункт `key-rate/phase-2-urals` стоял `Blocked` с формулировкой «машиночитаемого ряда Urals нет ни у ЦБ, ни у Минфина, ни у Минэка, ни в ЕМИСС». Машиночитаемого файла действительно нет, но есть регулярная публикация Минэкономразвития: раздел «Конъюнктура мировых товарных рынков» — отдельная HTML-страница на каждый месяц с таблицей «Средняя цена» / «Уровень цены». Значение — средний за отчётный месяц уровень цен нефти сорта «Юралс», используемый для коэффициента Кц (п. 3 ст. 342 НК РФ).

Ряд нужен контуру ключевой ставки как ценовой канал (Urals — экспортный нетбэк и база НДПИ), поэтому владелец завёл задачу #509.

## 3. Решение

### 3.1. Схема и имена

Новой таблицы нет — ряд пишется в общую `macro_series` (выбор владельца 2026-11-02; так же устроены `fred`, `bls`, `bea`, `eia`, `wgc`, `bold`).

```text
пакет:        minec/              (Минэк; как minfin/ — по ведомству)
импортёр:     minec_urals_price   (Name(), CLICKHOUSE_IMPORT_STAT, id шага dagu)
таблица:      macro_series        (Name() != TableName — импортёр-владелец общей таблицы)
source:       'minec'
series:       'urals_avg_price'
витрина:      v_minec_macro       (long-форма: date, series, value)
env:          MINEC_URALS_FROM=YYYY-MM — ремонт/бэкфилл с месяца включительно
```

`macro_series`: `source LowCardinality(String)`, `series LowCardinality(String)`, `date Date32`, `value Float64`, `ReplacingMergeTree ORDER BY (source, series, date)` — канонический DDL `ARCHITECTURE.md` §6.2; импортёр несёт его копию (прецедент `fred`/`eia`).

`date` — **1-е число отчётного месяца** (месяц, за который посчитана средняя цена), а не дата публикации. `value` — долл. США за баррель, `Float64`.

### 3.2. Импортёр

- `minec/urals.go`: `minecUrals{util.ClickHouseImport}` с `TableName = "macro_series"`, `DataUrl` = URL листинга, `CrawFunc`, `AfterImport`; собственный `Name()` → `minec_urals_price` (метод на внешней структуре, как `cbr_mo_br`).
- Полный цикл — шаблонный: DDL → `CrawFunc` → `AfterImport`. `Import()` не переопределяется.
- `CrawFunc` (ctx шаблон не передаёт — `context.Background()` внутри): гейт → обход листинга и статей → один `PrepareBatch` → `Append` с проверкой → `Send`; на пути ошибки — `Abort`. Логирование — logrus.
- Точка контроля публикации **не объявляется**: артефакт — набор из 104 страниц, отпечаток одного URL не отвечает на вопрос «что уже разобрано» (стандарт §9.3; прецедент `cbr_mp_summary`). Винтажного архива нет: `CrawFunc`-транспорт в архив не попадает (стандарт §9.6) — отступление названо здесь.

### 3.3. Инкремент

Гейт по данным, а не HEAD:

1. `SELECT max(date) FROM macro_series FINAL WHERE source = 'minec'`.
2. `MINEC_URALS_FROM` задан → `start` = этот месяц (включительно; ошибка разбора env — ошибка прогона). Иначе пустая таблица → `start = 0001-01-01`, непустая → `max + 1 месяц`.
3. Листинг листается с `page=1`; обход прекращается, когда на странице минимальный месяц Urals < `start` (страницы упорядочены по дате публикации убыванию) либо страница пуста (`page > 1`). `page 1` без материалов — ошибка. Cap — 60 страниц.
4. Ссылки с месяцем < `start` пропускаются без GET статьи; дубль месяца с разными URL — ошибка.
5. Пауза 300 мс между запросами; загрузка — `util.GetFileBytesChecked` (статус не-2xx попадает в ошибку: WAF-заглушка не выглядит пустым разбором).

Первый прогон на пустой таблице — авто-бэкфилл: 22 страницы листинга + 104 статьи (~2 мин). Повтор — один GET листинга + один SQL, ноль GET статей, `Imported 0 rows`. Ревизия уже импортированного месяца автоматически не перечитывается; путь ремонта — `MINEC_URALS_FROM` (§6).

### 3.4. Разбор (`minec/urals_parse.go`, без сети)

- `minecParseListing(body []byte, first bool) (minecListingPage, error)`:
  - маркер `<title>` раздела требуется **только у первой страницы**: страницы 2+ сайт отдаёт AJAX-фрагментом карточек без `<title>`, а за последней — тело `\n\n` при статусе 200. Пустое тело — конец списка (вызывающий отличает его от ошибки), непустое тело без единой карточки — ошибка; первая страница без маркера или без карточек — ошибка (WAF/подмена);
  - анкоры `a[href*="/konyunktura_mirovyh_tovarnyh_rynkov/"][title]`; «Юралс» — по `title`, не по URL (слаг менялся);
  - месяц/год — из `за <месяц> <год>` в заголовке; карта русских месяцев в коде, `ё`→`е`; неразобранный заголовок — ошибка.
- `minecParseArticle(body []byte) (price float64, month time.Time, err error)`:
  - заголовок `header.e-title.e-title_main`, содержимое `section.e-material__content`;
  - regex `(\d{1,3}(?:[ \u00a0\u202f]\d{3})*,\d+)\s*долл\.\s*США\s+за\s+баррель`, десятичная запятая → точка; 0 совпадений — ошибка, > 1 — ошибка (неоднозначность);
  - месяц статьи обязан совпасть с месяцем из листинга — иначе ошибка (источник противоречит сам себе);
  - `price > 0`.
- Ошибки называют URL и заголовок страницы; `panic` нет, индексы проверяются (стандарт §6.4–6.5).

### 3.5. Производные

- `minec/series_meta.go`: одна запись — `source='minec'`, `series='urals_avg_price'`, `title` «Средняя цена нефти сорта «Юралс» (экспортный нетбэк)», `unit` «долл. США за баррель», `frequency='M'`, `origin` — раздел и шаблон заголовка страницы, `description` — что измеряет (средняя за отчётный месяц цена Urals для Кц), `date` = 1-е число отчётного месяца, это уровень, а не темп; пропуск 2018-06/07 — в источнике; ревизии не отслеживаются.
- `minec/views.go`: `v_minec_macro` — `SELECT date, series, value FROM macro_series FINAL WHERE source = 'minec'`; комментарии таблицы и каждой колонки через `util.View`.
- `AfterImport` — `util.UpsertSeriesCatalog` + `util.CreateView`.
- `sql/mcp_kimi_reader.sql`: `GRANT SELECT ON default.v_minec_macro TO kimi_reader;`; сырая `macro_series` агенту не выдаётся.
- `scripts/mcp_check.py`: витрина читается и непуста (`count()`, `max(date) >= 2026-10-01`), каталог `source='minec'` = 1 ряд, spot-значение 2026-10 = `101.46`.

### 3.6. Регистрация и расписание

- `minec/importers.go` — одна запись реестра, литералы таблицы `"macro_series"` и `countPoints: ""`, единственный `init()`; тест-энфорсер по стандарту §8.3.
- `main.go` — blank-import `minec`.
- `dagu/minec.yaml` — `type: chain`, `overlap_policy: skip`, `schedule: "43 20 * * *"` (ежедневно 20:43 МСК: день публикации плавает 1–5-го, время — 10:00…21:00), один шаг `minec_urals_price`, retry 3 × 300 с.

```bash

```

Ожидаемо: `Imported 104 rows`; `SELECT count(), min(date), max(date) FROM v_minec_macro` → `104 / 2018-01-01 / 2026-10-01`; spot `2026-10 = 101.46`, `2018-01 = 68.60`, `2020-04 = 16.26`; повтор — `Imported 0 rows`, без GET статей; ремонт `MINEC_URALS_FROM=2018-05` возвращает удалённую точку.

## 6. Ограничения и отступления

- В источнике нет 2018-06 и 2018-07 — ряд с разрывом; значения не фабрикуются.
- Ревизии опубликованных месяцев (`Обновлено …`) автоматически не отслеживаются: гейт `max(date)` не перечитывает прошлое. Ремонт — `MINEC_URALS_FROM` (включительно) вручную.
- PIT не заявляется: дата публикации страницы не хранится, `date` — отчётный месяц.
- Точки контроля публикации нет (§9.3), винтажного архива нет (§9.6, `CrawFunc`); no-op доказывается гейтом по `max(date)`, а не `source_publications`.
- Обход зависит от разметки `e-title`/`e-material__content` и маркера `<title>`: смена вёрстки — ошибка прогона, а не «0 строк»; три эры статьи закреплены фикстурами.

## 7. Вне объёма

- Другие материалы раздела («новое морское месторождение», обзоры товарных рынков) — не импортируются.
- История до 2018-01 (старый сайт Минэка, Wayback) — не заявляется.
- Изменение `#114` в коде: только комментарий и статус в роадмапе.
