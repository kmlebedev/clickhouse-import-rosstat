# CPI v3 h1/h3/h6 как model-based прокси ожидаемой инфляции

**Пункт:** `key-rate/phase-4-cbr-scenario-fan`, Task 4.1 — issue [#296](https://github.com/kmlebedev/clickhouse-import-rosstat/issues/296)
**Роль:** `role:ml`; **фаза:** 4
**Дата:** 2026-10-20
**Зависит от:** #289 (Task 4, merged)

## 1. Вопрос

Корректно ли использовать прогнозы ИПЦ модели `cpi_monthly_v3` как дополнительный вход канала «Инфляционные и ценовые ожидания» модели ставки?

**Короткий ответ до эксперимента.** Как **замену** survey-ожиданиям — нет: `cbr_infl_exp` и `price_expectations` измеряют ожидания агентов, а CPI-модель — ожидаемый фактический рост цен. Как **дополнительный model-based прокси** — да, гипотеза допустима, но должна быть проверена walk-forward: признаки коррелированы с survey-ожиданиями и с текущей инфляцией, поэтому выигрыш не гарантирован.

## 2. Проблема данных

`cpi_monthly_v3` сейчас прогнозирует **только h1** — m/m ИПЦ следующего месяца; в `v_ml_error_by_fold` у эксперимента только `window='h1'`. Горизонты h1/h3/h6 в репозитории есть у `cb_comp_live_compare`/`cb_comp_parity` на `TARGET_FULL`, но это не live-прогнозы CPI v3, покрытие 2019-01…2024-07 и фиксированный train — для модели ставки это неполный и несопоставимый ряд.

Поэтому эксперимент сначала строит **прямые h1/h3/h6 прогнозы** на тех же v3-признаках, с walk-forward и as-of по дате заседания.

## 3. CPI-прогнозы h1/h3/h6

### 3.1. Данные и признаки

- Строки — `cpi_monthly_v3.build_sample_v3("long")`: месяцы `2013-10 … 2026-08`, признаки `feature_names_v3()` (v2-база + 4 недельных diffusion-признака), `month` — категориальный.
- Таргет — `cm.TARGET_ALL` (`cpi_all`, m/m, %).
- Для origin-месяца `O` и горизонта `h` таргет:
  `y_h(O) = 100 · (Π_{k=1..h}(1 + y(O+k)/100) − 1)` — накопленный рост за `O+1 … O+h`.
- Модель — `CatBoostRegressor` с дефолтами `cpi_monthly_v3.fit_catboost` (RMSE, seed 20261018, `month` категориальным), **direct** на каждый горизонт. Гиперпараметры не подбираются.

### 3.2. As-of и walk-forward

- Cutoff origin `O` — `cm.cutoff_for(O)` = 8-е число `O+1`.
- На cutoff `O` наблюдены месяцы ИПЦ до `O−1` включительно (месяц `O` публикуется в конце `O+1`).
- Обучение для прогноза в `O`: только origin'ы `M`, у которых таргетные месяцы `M+1 … M+h` уже наблюдены: `M+h ≤ O−1`; минимум 24 train-строки.
- Прогноз — строка `O` (её признаки сняты на `cutoff_for(O)`).
- Origin'ы считаются для всех месяцев выборки; для заседания `d` берётся **последний** `O` с `cutoff_for(O) ≤ d`. Если train ещё нет — `None`, `cpi_v3_available=0`.
- Запрещено: использовать строку `O+k` как признак, брать `O` с cutoff позже `d`, обучаться на таргете, который на cutoff не наблюдён.

### 3.3. Артефакт прогнозов

Для каждого заседания — `cpi_v3_h1`, `cpi_v3_h3`, `cpi_v3_h6` (п.п. накопленного роста), `cpi_v3_available` (0/1), `cpi_v3_origin` (дата origin, только в diagnostics, не в ядро).

## 4. Интеграция в модель ставки

- Базовая модель — `channel_fan_vol` из `key_rate_scenario_fan_v3.py` (41 признак, primary).
- Дополнительные признаки: `cpi_v3_h1`, `cpi_v3_h3`, `cpi_v3_h6`, `cpi_v3_available`.
- `build_channel_rows(..., extra_by_date=...)` добавляет их к `PanelRow.features`; `run_v3_walk_forward` принимает `extra_by_date` и передаёт в построение строк.
- Ablations:
  1. **baseline** — без CPI v3;
  2. **+h1** — только `cpi_v3_h1`;
  3. **+h1/h3/h6** — primary-гипотеза;
  4. **замена survey** — `infl_exp_*`, `price_expectations` и их дельты = `None`, вместо них CPI v3 (проверка, что CPI-прогноз не подменяет ожидания).
- Ядро, дисперсия, веера и метрики — без изменений: `ElasticNetCV`, `disp_vol`, 35 точек, expanding/rolling40.

## 5. Метрики и критерий

- Primary: CRPS `channel_fan_vol` expanding, paired comparison augmented vs baseline.
- Полный набор: coverage 50/80/90, ширина 80, RMSE, MAE, эпизоды 2022–2023/2024–2026.
- DM-HLN и блочный бутстрап (блок 3, n=2000) по разнице CRPS.
- **Приёмка:** coverage 80 % в [0.70; 0.90] и Wilson CI включает 0.8; ΔCRPS augmented − baseline ≤ 0, 95 % CI верх ≤ 0; RMSE не хуже baseline ×1.05; ablations опубликованы.
- Вердикт: `promote` — значимое улучшение; `iterate` — направление есть/нейтрально; `reject` — хуже baseline.

## 6. Вне объёма

- Замена primary-веера в продакшне; `forecast_log`; Go/DDL/витрины/гранты.
- Переобучение `cpi_monthly_v3` или изменение его h1-результатов.
- Полный QPM/многозаседаний путь; CPI-веер #285.

## 7. Ограничения

- PIT/винтажей ИПЦ нет: as-of консервативный (cutoff 8-е M+1), ревизии не учтены.
- CPI v3 long-выборка 2013-10+; для заседаний 2014–2015 признаки missing (индикатор), оценка — на общих фолдах отдельно.
- h3/h6 — прямые модели на 24+ train-месяцах; early folds могут быть нестабильны.
- Накопленный рост — compounded m/m, не SA; CPI v3 h1 — m/m, а не уровень.
- 108 решений, 45 признаков после добавления: ElasticNet-регуляризация; CatBoost только внутри CPI-прогноза.
- Множественные сравнения: primary один, ablations — robustness; p-value без поправки.
