## 1. Контекст

Сигнал «доходность ОФЗ выше ключевой ставки» — первый пункт сюжета о долговом рынке, но посчитать и забэктестить его нечем: `v_ofz_curve` (MOEX G-curve) содержит по одной точке на тенор (2026-10-09), а история RGBI начинается с 2010 и доходностью не является. ЦБ публикует кривую бескупонной доходности (КБД) с 2003 года — это готовый дневной ряд по 12 тенорам.

Два пункта роадмапа решаются вместе, потому что #169 зависит от общего разбора HTML-таблиц ЦБ (#117): КБД — первая из трёх таблиц (`КБД`, MIACR/MIACR-IG, ликвидность банковского сектора), которым нужен один и тот же транспорт и форма `UniDbQuery`. Решение владельца (2026-10-19): сначала инфраструктурный хелпер, затем импортёр, одной веткой и одним PR.

## 2. Источник: что проверено живыми запросами

- Страница: `https://www.cbr.ru/hd_base/zcyc_params/`; форма — GET с параметрами
  `UniDbQuery.Posted=True`, `UniDbQuery.From=DD.MM.YYYY`, `UniDbQuery.To=DD.MM.YYYY`.
- Ответ — одна таблица `.table-wrapper table.data`:
  - две строки заголовка: `Дата` + `Срок до погашения, лет` (`colspan=12`), затем 12 теноров;
  - строки данных: дата `DD.MM.YYYY` (ячейка со ссылкой `zcyc/?DateTo=…`) и 12 значений с десятичной запятой (`12,30`).
- Теноры источника — **12**: `0,25 / 0,5 / 0,75 / 1 / 2 / 3 / 5 / 7 / 10 / 15 / 20 / 30`. Issue #169 перечисляет 11 (без 0,75); импортёр берёт все 12 — это надмножество, приёмка «10+ теноров» выполняется.
- История: **04.01.2003 … сегодня**, строки от свежей к старой; в проверенных выпусках 2003 и 2026 пустых ячеек нет.
- **Предел одного запроса — около 5 лет.** `04.01.2003…31.12.2007` отдаёт 1 238 строк (485 КБ), а `04.01.2003…31.12.2012` и `01.01.2015…31.12.2024` — пустую страницу без таблицы (26 КБ). Поэтому бэкфилл режется на окна по **4 года** (6 окон на 2003–2026) с паузой 500 мс.
- **Пустая выборка и поломка различаются маркером формы.** Валидная страница без данных (например, выходные) не содержит таблицы, но содержит форму (`UniDbQuery.Posted`); заглушка WAF маркера не содержит. Парсер обязан различать эти случаи, иначе «нет новых данных» и «источник сломан» неотличимы.
- Спот-значения для тестов: `30.12.2003` (10y = 8,51), `04.01.2003` (10y = 13,45), `16.10.2026` (10y = 16,51), `09.10.2026` (10y = 16,85; MOEX G-curve 10y = 16,8486 — источники сходятся).

## 3. Решение

### 3.1 `util`: общий разбор HTML-таблиц и форма `UniDbQuery` (#117)

Новый файл `util/html.go`:

```go
type HTMLTable struct {
    Headers [][]string // все строки <th> до строк данных
    Rows    [][]string // строки <td>; значения TrimSpace, пустые ячейки — ""
}

var ErrHTMLTableNotFound = errors.New("HTML table not found")

func ParseHTMLTable(body []byte, selector string) (HTMLTable, error)
```

- Разбор отделён от сети (стандарт §6.1), `goquery` уже в зависимостях.
- Селектор задаёт вызывающий; `colspan`/`rowspan` не разворачиваются — заголовки отдаются как есть (КБД: две строки, вторая — 12 теноров).
- Нет таблицы — ошибка, обёрнутая `ErrHTMLTableNotFound`, с селектором в тексте.

Новый файл `util/unidbquery.go`:

```go
func UniDbQueryURL(base string, from, to time.Time) (string, error)
func IsUniDbQueryPage(body []byte) bool
```

- `UniDbQueryURL` собирает `Posted=True&From=DD.MM.YYYY&To=DD.MM.YYYY`, сохраняя существующие query-параметры базы.
- `IsUniDbQueryPage` — маркер `UniDbQuery.Posted`: отличает валидную пустую выборку от заглушки WAF.
- Хелперы покрыты офлайн-тестами на реальной урезанной странице ЦБ; в `util` ошибок сети нет.

### 3.2 Импортёр `cbr_zcyc` (#169)

Схема (канон — `ARCHITECTURE.md` §6.2):

```sql
CREATE TABLE IF NOT EXISTS cbr_zcyc (
    tenor LowCardinality(String),  -- 0.25, 0.5, 0.75, 1, 2, 3, 5, 7, 10, 15, 20, 30
    date Date,                     -- торговый день публикации КБД
    yield Float64                  -- доходность, % годовых
) ENGINE = ReplacingMergeTree ORDER BY (date, tenor);
```

- Импортёр — на `util.ClickHouseImport` с `CrawFunc`; `Name()` = `cbr_zcyc` = имя таблицы.
- **Без точки контроля публикации**: URL содержит сегодняшнюю дату и скользящее окно, отпечаток меняется каждый прогон, no-op по HEAD недостижим — та же причина, что у `cbr_key_rate`/`cbr_ruania`/`cbr_currency_usd`/`cbr_gold`.
- Инкремент: `SELECT max(date) FROM cbr_zcyc FINAL`; пусто → `2003-01-04`, иначе `max + 1 день`. Диапазон режется на последовательные непересекающиеся окна по 4 года; последнее обрезается по сегодняшней дате. На каждый прогон — один `PrepareBatch` → `Append` → `Send` (точки собираются после успешного разбора всех окон, чтобы частичный бэкфилл не записывался).
- Пустое историческое окно — ошибка (с окном и URL в тексте); пустое последнее окно — штатное «новых данных нет» (выходные/праздник).
- Первый прогон с нулём точек — ошибка; инкрементальный с нулём — успешный no-op без батча.
- Повторный прогон при `max(date) = сегодня` не делает ни одного сетевого запроса; `AfterImport` всё равно перепубликовывает каталог и витрины (самолечение).
- Регистрация: `cbr/importers.go` (22-я запись), шаг `cbr_zcyc` — **последним** в `dagu/cbr.yaml` (22-й), чтобы падение нового шага не останавливало цепочку из 21 проверенного.

### 3.3 Каталог рядов

12 записей `series_catalog` (`source='cbr'`, `series` = канонический тенор `0.25`…`30`): `title`, `unit = "% годовых"`, `frequency = "D"`, `origin` — таблица и колонка источника, `description` — уровень, а не темп; история с 04.01.2003; пропуск дня — нет публикации; пустая ячейка — не ноль; ссылки на витрины. Имена рядов объявлены кодом, а не из заголовка (стандарт §6.8).

### 3.4 Витрины

`v_ofz_curve_compare` (`cbr_zcyc` + `ofz_curve`) — сравнение КБД ЦБ и G-curve МосБиржи по `(date, tenor)`:

- `tenor` — канонические `0.25`…`30` (MOEX `1y/3y/5y/10y` нормализуются срезом `y`);
- `cbr_yield`, `moex_yield`, `spread_pp = moex_yield − cbr_yield`;
- `NULL` — у источника нет точки (MOEX даёт только 1/3/5/10 и только с 2026-10-09), а не ноль.

`v_ofz_signal` (`cbr_zcyc` + `cbr_key_rate` + `rosstat_ipc_mes`) — одна строка на дату КБД:

- `ofz_1y`, `ofz_2y`, `ofz_10y`;
- `key_rate` — последняя действующая ставка на дату (шаговая функция, `ASOF JOIN`; до 2013-09-17 — `NULL`, не ноль);
- `ofz_10y_minus_key_rate_pp`, `ofz_2y_minus_key_rate_pp` — спреды `ofz − key_rate`, п.п.;
- `slope_10y_1y_pp` — наклон `10y − 1y`;
- `inflation_yoy` — официальный ИПЦ Росстата г/г: произведение 12 месячных индексов `rosstat_ipc_mes` (на 2026-09-30 — 6,35 %);
- `real_yield_10y_pp = ofz_10y − inflation_yoy`.

Оговорки в комментариях витрины: ИПЦ привязан к концу отчётного месяца, лаг публикации ~2 недели не моделируется (для point-in-time бэктеста сдвигать отдельно); `NULL` — нет точки/ставки, не ноль. Обе витрины — dedicated, а не long-форма (отступление от §10.3, прецеденты — `v_keyrate_expectations`, `v_cbr_dip_bulletin`, `v_cbr_mt_forecast`): `v_ofz_signal` — производные колонки одной строкой, `v_ofz_curve_compare` — сравнение двух источников.

`AfterImport: afterCbrZcyc(meta)` — `UpsertSeriesCatalog` → `CreateView(compare)` → `CreateView(signal)`; витрина пропускается, пока нет исходных таблиц (`ofz_curve`, `rosstat_ipc_mes`), и самолечится следующим прогоном.

### 3.5 MCP

- `sql/mcp_kimi_reader.sql` — `GRANT SELECT` на обе витрины.
- `scripts/mcp_check.py` — витрины читаются и непусты; каталог `source='cbr' AND origin LIKE '%zcyc\_params%'` = 12; сырая `cbr_zcyc` → отказ 497.

## 4. Тесты

- `util`: разбор реальной фикстуры (заголовки, строки, spot-ячейка), `ErrHTMLTableNotFound`, `IsUniDbQueryPage` true/false, `UniDbQueryURL` (формат дат, параметры, сохранение query).
- `cbr`: разбор реальных фикстур 2003 и 2026 (точное число строк, spot-значения), пустая выборка → 0 точек без ошибки, заглушка без маркера → ошибка, битое значение → ошибка; двусторонний контракт каталога через `checkCbrSeriesMeta`; чанкер (6 окон, смежные границы, ≤4 года, `from > to` → 0).
- Реестр: `cbr_zcyc` в `cbrImporters`, в `chimport.Stats`, шаг `dagu/cbr.yaml`; префлайта нет.
- Все тесты офлайн, на реальных урезанных артефактах источника.

## 5. Приёмка

- `make all` зелёный; `go test -race -count=1 ./util/ ./cbr/`.
- `make import STAT=cbr_zcyc`: первый прогон — 6 окон, 2003-01-04 … сегодня, 12 теноров, ≥20 лет дневных данных (ориентир ≈70 тыс. строк); повтор — идемпотентный no-op.
- `make mcp-check` — ПРОВЕРКА ПРОЙДЕНА; `dagu validate dagu/cbr.yaml`.
- Витрины читаются через MCP; `v_ofz_curve_compare` на 2026-10-09/10: КБД 16,85 против MOEX 16,8486; `v_ofz_signal` на 2026-10-16: 16,51 − 14,00 = 2,51 п.п., наклон 2,74 п.п., реальная ≈10,16 %.
- Статусы `phase-2-html-cb-tables` и `phase-2-cbr-zcyc` — ✅ с протоколом в PR.

## 6. Риски

| Риск | Митигация |
|---|---|
| ЦБ ужесточит лимит окна | Пустое историческое окно — ошибка; уменьшить `cbrZcycChunkYears` и повторить (идемпотентно) |
| Throttling/WAF на 6 запросов бэкфилла | Пауза 500 мс, retry 3×300 c в dagu, маркер формы отличает пустую выборку от заглушки |
| Смена разметки/набора теноров | Неизвестный тенор — warn и пропуск; ни одного известного — ошибка; тесты на фикстурах 2003/2026 |
| Витрина зависит от `rosstat_ipc_mes` | `CreateView` пропускает до появления таблицы; самолечение; MCP-проверка ловит пустоту |
| Лаг ИПЦ | Оговорка в комментарии; основной сигнал `ofz − key_rate` от ИПЦ не зависит |
