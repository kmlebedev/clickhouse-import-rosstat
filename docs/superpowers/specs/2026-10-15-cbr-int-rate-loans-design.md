## 1. Зачем

Канал «жёсткость ДКУ» в контуре прогноза ключевой ставки сейчас закрыт только со стороны
пассивов: `cbr_bank_int_rate` собирает ставки по **вкладам** физлиц. Без кредитных ставок
трансмиссия видна наполовину — ЦБ в резюме обсуждений регулярно ссылается на динамику
кредитования и денежно-кредитные условия. Пункт закрывает ставки по кредитам **юридическим
лицам** (нефинансовым организациям) в рублях.

## 2. Источник (проверен живьём 2026-10-15)

| Свойство | Значение |
|---|---|
| URL | `https://www.cbr.ru/vfs/statistics/pdko/int_rat/loans_nonfin.xlsx` — HTTP 200, 124 КБ, **прямая стабильная ссылка** (подтверждает разведку §4.3 роадмапа) |

| Глубина | помесячно, 2014-01 … 2026-08 (152 месяца на снимке) |
| Пустые/нулевые ячейки | нет (проверено скриптом по живому файлу) |

### Разметка листа `ставки_руб`

- Строки 1–3: заголовок «Средневзвешенные процентные ставки…», «(в целом по Российской
  Федерации)», «% годовых».
- Строка 4: два group header'а (объединённые ячейки): колонки B–I — «Всего», колонки J–Q —
  «в том числе субъектам малого и среднего предпринимательства». Значение объединённой
  ячейки живёт только в её первой колонке.
- Строка 5: 16 названий колонок — 8 сроков × 2 группы; наборы сроков внутри групп
  **идентичны**, поэтому заголовок колонки сам по себе имя ряда не даёт.
- Строки 6+: данные «Январь 2014» … «Август 2026».
- После данных: сноска, начинающаяся с «*».

## 3. Решения по дизайну

### 3.1 Таблица и имя импортёра

- Таблица: `cbr_int_rate_loans`; импортёр `Name() == TableName` (стандарт §7.2), префикс
  `cbr_` (стандарт §7.1). Имя ставит импортёр рядом с `cbr_bank_int_rate` и читается как
  «int_rate: loans» против «int_rate: bank (deposits)».
- DDL (канонический, правило 5 AGENTS.md — ценовые значения Float64; legacy `Float32` у
  `cbr_bank_int_rate` не копируем):

```sql
CREATE TABLE IF NOT EXISTS %s (
      name LowCardinality(String)
    , date Date
    , rate Float64
) ENGINE = ReplacingMergeTree ORDER BY (name, date);
```

### 3.2 Имена рядов — из кода (стандарт §6.8)

16 рядов: префикс группы + срок. Группы: `Всего: ` (все нефинансовые организации) и
`СМП: ` (субъекты малого и среднего предпринимательства). Базовые сроки: `до 30 дней,
включая «до востребования»`; `от 31 до 90 дней`; `от 91 до 180 дней`; `от 181 дня до 1 года`;
`до 1 года, включая «до востребования»`; `от 1 года до 3 лет`; `свыше 3 лет`; `свыше 1 года`.

Текст заголовка колонки источника сверяется с ожидаемым (нормализация переноса
«до востребова-ния» и типографики): расхождение — fail-fast (стандарт §6.4), потому что оно
означает «источник изменил структуру», а не «появился новый ряд». В данные идёт имя из кода.

### 3.3 Привязка даты

Предпоследний день месяца отчётного периода: `time.Date(year, month+1, -1, …)` — та же
конвенция, что у `cbr_bank_int_rate`, поэтому ставки по вкладам и по кредитам сопоставимы
на одной временной оси во витрине. Привязка фиксируется в `description` каталога:
«сопоставлять по toStartOfMonth(date)».

### 3.4 Парсер (стандарт §6)

- Значения — сырые (`GetRows(sheet, excelize.Options{RawCellValue: true})`, стандарт §6.2).
- Якоря, а не магические индексы (§6.3): строка «% годовых» — ориентир шапки; строка групп
  ищется по подписям «Всего» / «в том числе субъектам малого»; строка заголовков колонок —
  следующая за ней. Колонки привязываются к группе позиционно (между первой колонкой группы
  и первой колонкой следующей группы), merged-диапазоны не читаются.
- Метки периодов — через `util.MonthsToNum`; строка, чья метка не парсится как месяц и
  начинается с «*» — сноска, разбор данных закончен; любая иная непарсящаяся непустая метка —
  ошибка (§6.4).
- Пустая ячейка — пропуск точки (§6.7; в текущем файле пустых нет, решение зафиксировано
  про запас и описано в `description` рядов).
- Fail-fast с именем таблицы в ошибке: лист отсутствует, лист короче шапки, ноль точек
  (§6.4); без `panic`, индексация слайсов с проверкой (§6.5).

### 3.5 Точка контроля публикации (стандарт §9)

Объявлена: файл помесячный, шаг ежедневный (§9.1).
`PublicationCountPoints: SELECT count() FROM cbr_int_rate_loans FINAL` (FINAL — §9.2).
Артефакт качается шаблонным путём (`DataUrl` + `ImportFunc`) → версии попадают в винтажный
архив общим механизмом шаблона (§9.6), кода импортёра архивация не требует.

### 3.6 Производные (стандарт §10)

- Каталог: `cbrIntRateLoansSeriesMeta` в `cbr/series_meta.go` — 16 записей,
  `unit = «% годовых»`, `frequency = M`, `origin` — файл/лист/группа/срок,
  `description` — что измеряет (средневзвешенная ставка по новым кредитам за месяц,
  взвешенная объёмом размещений), как читать (уровень, не темп; темп — разница в п.п.) и
  привязка даты. Контракт каталога — **двусторонний** (имена из кода, §11.4).
- Витрина: общая `v_cbr_macro` (`cbr/views.go`): таблица добавляется в `Tables` и в SELECT
  строкой `UNION ALL SELECT 'cbr', toString(name), date, toFloat64(rate) FROM cbr_int_rate_loans FINAL`;
  комментарии витрины дополняются («ставки по вкладам и кредитам»). Отдельная витрина
  не заводится — ряды того же контура и единиц, что `cbr_bank_int_rate`.
- Грант: отдельный не нужен (`v_cbr_macro` уже выдана `kimi_reader`,
  `sql/mcp_kimi_reader.sql`); сырые таблицы по-прежнему закрыты (§10.4).
- Публикует `AfterImport: afterCbrMacro(cbrIntRateLoansSeriesMeta)` (стандарт §10.2).

### 3.7 Транспорт

`util.GetXlsx` по статичному `DataUrl` (стандарт §4.1, таблица «XLSX (ссылка стабильная)»).
Сетевых вызовов в `init()` нет (§4.3). HTTP-статус `GetFile` не проверяет (§4.2) — fail-fast
парсера (§3.4) закрывает этот случай.
