## 1. Контекст и границы

T1 даёт сырой ИЦП Росстата по видам экономической деятельности — совокупный ряд «Промышленность» / «Российская Федерация» с кодом `1323500.029.31`. Это вход для T2 (товары/ОКПД2 и веса), T3 (mapping ОКПД2→КИПЦ), T4 (SA-слой `ppi_sa`) и T5 (витрина `v_rosstat_ppi`, каталог, грант MCP).

В T1 **не входят**:

- `rosstat_ppi_product` и `rosstat_ppi_weights` (T2, #277);
- mapping и паритет (T3, #278);
- SA-слой `ppi_sa` (T4, #279);
- витрина `v_rosstat_ppi`, `GRANT SELECT` и MCP-проверка ИЦП (T5, #280);
- окончательное расписание «после 16-го рабочего дня» и проверка свежести (T6, #281).

243 кода ОКВЭД2 и все разделы B/C/D/E в T1 не импортируются: issue #276 ограничивает объём совокупным рядом. Поле `code` остаётся в схеме как измерение и точка расширения.

## 3. Покрытие

Винтаж 08-2026:

| Тип | Листы | Период | Точек (ориентир) |
|---|---|---|---|
| `m/m` | `1.1` (1998–2016), `2.1` (2013–2025), `3.1`–`8.1` (2021–2026) | 1998-01 … 2026-08 | 344 |
| `ytd` | `1.1`/`2.1` — декабрьская строка; `3.2`–`8.2` — помесячно | дек-1998 … дек-2020, 2021-01 … 2026-08 | 91 |

Итого ~571 точка. Точное число зависит от `…`/пустых ячеек; приёмка фиксирует фактическое.

Ограничения покрытия — свойство источника, а не дефект разбора:

- `ytd` до 2021 г. источник даёт только декабрьской строкой «Декабрь в % к декабрю предыдущего года»; помесячный `ytd` начинается с листов `3.2` (2021).
- `y/y` и `period` появляются только с 2021 г. (листы `3.3`/`3.4`); за 1998–2020 их в файле нет.
- `8.x` в винтаже 08-2026 содержит январь–август; сентябрь–декабрь появятся в следующих выпусках.

## 4. Схема

Канонический DDL — в `ARCHITECTURE.md` §6.2, в коде — `%s`-форма шаблона `util.ClickHouseImport`:

```sql
CREATE TABLE IF NOT EXISTS rosstat_ppi_ved (
      date Date
    , code LowCardinality(String)
    , name LowCardinality(String)
    , index_type LowCardinality(String)
    , value Float64
) ENGINE = ReplacingMergeTree
ORDER BY (date, code, index_type);
```

- `date` — последний день отчётного месяца (UTC): значение относится к месяцу и лежит внутри него.
- `code` — код ОКВЭД2; в T1 всегда `1323500.029.31`.
- `name` — стабильное имя ряда, объявленное кодом: `ИЦП по ВЭД, РФ, m/m`, `... ytd`, `... y/y`, `... period`. Это не подпись строки источника: подпись содержит редакцию и может меняться, а имя ряда — контракт каталога и будущей витрины.
- `index_type` — `m/m` | `ytd` | `y/y` | `period`.
- `value` — индекс, `%`; `100` = без изменения. `Float64`, не `Float32`.
- Ключ `(date, code, index_type)` перезаписывает ревизию месяца; `ReplacingMergeTree` без версии — как у соседних рядов пакета.

## 5. Разбор

### 5.1. Общие правила

- Значения читаются только в сыром виде: `GetRows(sheet, excelize.Options{RawCellValue: true})`. Форматированные строки теряют точность и превращают числа в текст.
- Разметка ищется по признаку, а не по номеру строки/колонки: годы — по четырёхзначным подписям, шапка годового листа — по ячейке `ОКВЭД2`, месяцы — по названиям, итоговая строка — по коду `1323500.029.31` и/или подписи `Российская Федерация`.
- Сноски источника снимаются с подписей месяцев (`январь1)`), годов (`20221)`, `20241)`) и заголовков; сравнение — после сжатия пробелов и приведения регистра.
- Пустая ячейка и маркеры `…`, `...`, `-`, `—`, `х`, `X` — **не точка**; это пропуск, а не ноль. Нечисловой текст — ошибка с номером листа/строки/колонки.
- `NaN`/`Inf` отбрасываются как ошибка.
- `panic` в разборе запрещён; выход за границы среза проверяется.
- Даты — `time.Date(year, month+1, 0, 0, 0, 0, 0, time.UTC)`.

### 5.2. Legacy-листы `1.1` и `2.1`

- Строка 3 — годы в колонках 1..N (подписи со сносками).
- Маркер `К предыдущему месяцу` открывает блок `m/m`; ниже идут строки месяцев (`Январь`…`Декабрь`).
- После декабря — строка `Декабрь в % к декабрю предыдущего года` — это `ytd` только за декабрь.
- `1.1` — ОКВЭД-2007, 1998–2016; `2.1` — ОКВЭД2, 2013–2025.
- `1.1` и `2.1` — только совокупный ряд; остальные листы групп 1/2 (разделы B/C/D/E) в T1 не читаются.

### 5.3. Годовые листы `3.x`–`8.x`

- Год берётся из заголовка листа `в YYYY г.` (регулярка с допуском на сноску и перенос строки), а не из номера листа. Новый `9.x` в 2027 г. подхватится без правки кода.
- Шапка — строка, где ячейка после нормализации равна `ОКВЭД2`; месяцы — колонки с распознанными названиями.
- `3.x`–`6.x` — только РФ: строка с кодом `1323500.029.31` содержит значения.
- `7.x`/`8.x` — РФ + регионы: у блока кода `1323500.029.31` значения лежат в следующей строке `Российская Федерация`. Если строка РФ не найдена — ошибка (не молчаливый пропуск).
- Суффикс листа задаёт тип: `.1` — `m/m`, `.2` — `ytd`, `.3` — `y/y`, `.4` — `period`.

### 5.4. Приоритет и непрерывность

Листы перекрываются: `1.1` и `2.1` — 2013–2016; `2.1` и годовые — 2021–2025. Приоритет: **годовые > `2.1` > `1.1`**. Это даёт:

- `m/m` — непрерывный ряд 1998-01…2026-08 без дублей;
- `ytd` — декабрь 1998–2020 + помесячно 2021+;
- `y/y`/`period` — 2021+.

Дополнительные проверки:

- для `m/m` каждый месяц между min и max обязан иметь точку; первый пропуск — ошибка с именем месяца;
- дубль ключа `(date, index_type)` с разным значением — ошибка (одинаковое значение допустимо, но в T1 дублей быть не должно);
- 0 точек — ошибка.

## 6. Импортёр

- Пакет `rosstat/`, файлы `ppi_ved.go` и `ppi_ved_parse.go`; `Name()` = `TableName` = `rosstat_ppi_ved`.
- `PPIVedStat` встраивает `util.ClickHouseImport`, override `Import()` вычисляет `DataUrl` со страницы и вызывает шаблон (как `LabourForceStat`).
- `ImportFunc` разбирает книгу и пишет одним батчем `PrepareBatch` → `Append` (с проверкой) → `Send`; на ошибке разбора — `Abort`.
- Точка контроля публикации объявлена: `PublicationCountPoints = SELECT count() FROM rosstat_ppi_ved FINAL`. Файл обновляется раз в месяц, шаг — недельный, поэтому повтор — HEAD-префлайт и no-op без скачивания. Версия файла (`source_publications`) и винтажный архив — общим механизмом шаблона.
- `AfterImport` в T1 публикует **только** `series_catalog` (`util.UpsertSeriesCatalog`). Витрину T5 заменит на `afterRosstatPPI`, который добавит `v_rosstat_ppi`.

### 6.1. Отступление от стандарта §10.2

`IMPORTER_PACKAGE_STANDARD.md` §10.2 требует публиковать каталог и витрину одним `AfterImport`. T1 сознательно публикует только каталог: общая витрина `v_rosstat_ppi` по определению T5 (#280) строится над `rosstat_ppi_ved`, `rosstat_ppi_product`, `rosstat_ppi_weights` и `ppi_sa`, а три последние таблицы появляются в T2/T4. Витрина в T1 была бы либо узкой и одноразовой, либо неполной. Отступление фиксируется здесь и в PR; T5 закрывает его.

### 6.2. Шаг dagu

Тест-энфорсер `rosstat/importers_test.go` требует, чтобы каждый импортёр реестра был шагом `dagu/rosstat.yaml` (проверка в обе стороны). Поэтому в T1 добавляется восьмой шаг в хвост цепочки (`retry_policy: 3 × 300 s`). Расписание пока наследует четверг 12:17; окно «после 16-го рабочего дня» и проверка свежести — T6 (#281).

## 7. Каталог рядов

`rosstat/series_meta.go`, `ppiVedSeriesMeta` — четыре записи, `source='rosstat'`, `frequency='M'`, `unit='индекс, % (100 = без изменения)'`:

| `series` | `title` | Описание |
|---|---|---|
| `ИЦП по ВЭД, РФ, m/m` | ИЦП по ВЭД, РФ, м/м | 1998-01…текущий; 100 = без изменения |
| `ИЦП по ВЭД, РФ, ytd` | ИЦП по ВЭД, РФ, с начала года | декабрь 1998–2020, помесячно 2021+ |
| `ИЦП по ВЭД, РФ, y/y` | ИЦП по ВЭД, РФ, г/г | 2021-01+ |
| `ИЦП по ВЭД, РФ, period` | ИЦП по ВЭД, РФ, период с начала года к прошлому году | 2021-01+ |

`origin` называет файл, листы, код `1323500.029.31` и строку РФ; `description` — единицу, дату точки, покрытие и правило «пропуск ≠ ноль».
