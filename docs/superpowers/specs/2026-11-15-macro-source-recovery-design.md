# Восстановление источников рабочей силы и зарплат (#604)

Пункт key-rate/phase-4-macro-source-recovery, role:research, Depends on #603
(merged #605, 647fda67). Только чтение источников и MCP-витрин, без импорта/DDL/кода.

## Вопрос и границы

Можно ли восстановить те же ряды после 404 текущих официальных XLSX?
Рабочая сила: шесть национальных месячных рядов текущего импортёра, тот же
возрастной охват, обследование и единицы. Зарплата: номинальная начисленная,
полный круг организаций, РФ, месяцы; не реальная и не бюджетный/региональный срез.
Ключи/семантика дат действующего кода сохраняются при проектировании handoff.
Переход на иной показатель или новый ряд не считается восстановлением.

## Метод и критерий

1. Зафиксировать MCP baseline, каталог и код разбора/дат/единиц; проверить
   текущие ссылки повторно (HTTP/контент, наблюдаемое время, размер и SHA-256).
2. Независимый поиск официальных альтернатив для двух источников: разделы
   Росстата, его территориальные публикации только при общероссийском показателе,
   официальные бюллетени/ЕМИСС. Кандидат из поиска не считается проверенным.
3. Для найденного файла установить определение, охват, период, формат, доступ,
   ревизии, terms/ссылку на правила использования; сохранить минимальные доказательства.
4. Сверить все доступные месяцы перекрытия с MCP. Float32 учитывать явно;
   несовпадения классифицировать как округление/ревизию/иной показатель, не скрывать.
5. Go только при доказанной идентичности и воспроизводимом доступе/разборе;
   иначе iterate/no-go с конкретным блокером. Нет гарантии найти замену.
6. Никаких записей в БД/смены производственного URL. Результат — research,
   bounded Go-handoff и новые пункты только если обоснованы доказательствами.
7. docs-check, независимое финальное ревью, один PR с протоколом. Нет PIT без
   исторических винтажей; пробы +1/+3 дня в этой сессии не заявляются.
