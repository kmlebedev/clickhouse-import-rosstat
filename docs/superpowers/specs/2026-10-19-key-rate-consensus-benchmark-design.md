## 1. Зачем

`cbr_mo_br` (фаза 1.5) собирает медианы, интервалы и число ответов макроэкономического опроса ЦБ, но в модели они не используются. [KEY_RATE_MODEL.md](../../KEY_RATE_MODEL.md) §6.4 требует **бенчмарк №4** — «медиана макроэкономического опроса ЦБ, побить профессионалов»; сравнение допускается **только по опросам, опубликованным строго до события**, и **на горизонте, который опрос реально покрывает** (опрос даёт среднегодовую траекторию, а не исход заседания).

Issue #129 — P1 к первой публикации: без измерения консенсуса статья неполна, хотя публикацию не блокирует.

## 2. Источник и семантика

- Источник — витрина `v_cbr_mo_br` (`macro_series FINAL WHERE source = 'cbr_mo_br'`); используются ряды `key_rate_avg_<год>_median|p10|p90|answers`.
- `date` — дата волны (1-е число месяца). Публикация наступает через 2–6 дней после полевого периода ([спека импортёра](2026-10-13-cbr-mo-br-design.md) §2). Консервативное правило доступности: `available_from = wave_date + 6 дней`.
- Для исторических волн `source_publications.first_seen` не пригоден: механизм заведён 2026-10-13 и хранит одну строку на версию файла, а не на волну. Это ограничение называется в отчёте.
- Значения — прогнозы аналитиков, а не факты; `answers` — число ответов, не прогноз. Для бенчмарка используются только медианы; p10/p90/answers печатаются для текущей волны.

## 3. Два измерения

### 3.1. Годовой горизонт — основной результат

Медиана `key_rate_avg_<Y>_median` сравнивается с **фактической среднегодовой** ставкой года `Y`.

**Факт.** `cbr_key_rate` — дневные точки (рабочие дни). Для каждой календарной даты берётся последняя точка с `date <= d` (fill-forward). `annual_average_rate(points, Y) = (1/N) Σ rate(d)` по всем календарным дням года; это соответствует формулировке опроса «с учётом выходных дней». Год завершён, если ряд покрывает его начало и конец: `points[0] <= 1 января` и `points[-1] >= 31 декабря`.

**Выборка** (завершённые годы 2021–2025):

- **экс-анте** — последняя волна с медианой на `Y`, у которой `available_from < 1 января Y` (декабрьская волна `Y−1`); для 2021 экс-анте нет — опрос начинается с 2021-05;
- **внутригодовые** — все волны с медианой на `Y`, у которых `1 января Y <= available_from < 1 января Y+1`; бакет по числу месяцев до конца года: `10–12`, `7–9`, `4–6`, `1–3`.

Ожидаемый состав: 41 пара — экс-анте 4 (2022–2025), внутригодовых 37 (8 + 9 + 10 + 10).

**Ошибки.** `err_cons = (median − actual) × 100` б.п.; положительная — консенсус завысил. Наивный бенчмарк «ставка не меняется»:

- если `available_from < 1 января Y`: `hold = rate(available_from)` (на весь год);
- иначе: `hold = (Σ_{1 янв..A} rate(d) + rate(A) × N_rem) / N_Y`, где `A = available_from`, `N_rem` — дни с `A+1` до 31 декабря.

**Метрики.** По каждому бакету: `n`, RMSE, MAE, bias отдельно для консенсуса и hold; Diebold–Mariano с поправкой HLN (`h=1`) на парных ошибках. При `n < 2` или нулевой дисперсии разницы — «—». p-value на малой выборке индикативный; превосходство не заявляется без значимости. Дополнительно — режимный срез 2024–2025 (завершённые годы текущего режима).

### 3.2. B4 — проекция годовой медианы на шаг заседания

Для заседания `M`, последней волны `W` с `A = W + 6 дней` и `A < M`, и медианы на год `Y = year(M)`:

```
N_Y       = число дней в году Y
R_known   = Σ_{d=1 января Y .. A} rate(d)
N_rem     = число дней с A+1 до 31 декабря Y
r_implied = (median_Y × N_Y − R_known) / N_rem
step_B4   = (r_implied − rate_before) × 100      # rate_before — ставка на M−1
```

Если `A < 1 января Y` (январское заседание, последняя волна — декабрьская), `R_known = 0`, `N_rem = N_Y`, `r_implied = median_Y`.

**Ограничения.** B4 — механическая проекция (постоянная ставка на остаток года), а не прогноз заседания. Guard: `N_rem >= 30`; есть медиана на `Y`; ряд ставки покрывает `A`; `-100 < r_implied < 100`. B4 **не входит** в `METHODS`, `FORECAST_METHODS`, `key_rate_model_forecast.json`, `forecast_log` и writer. Он живёт отдельным разделом отчёта и отдельной таблицей метрик. DM против B1–B3 и методов считается на общих заседаниях; положительная статистика значит, что B4 хуже.

### 3.3. Сценарий удержания — мост к годовой средней

Берётся формальный прогноз `ordered_logit` из текущего прогноза: `model_level = rate_before + expected_step_bp/100`. Вменённая среднегодовая:

```
implied_avg = (Σ_{1 янв..today} rate(d) + rate_before × дни(today+1..M−1)
               + model_level × дни(M..31 дек)) / N_Y
```

Это **сценарий удержания после ближайшего заседания**, не траектория и не тест значимости; в журнал не пишется. Если `ordered_logit` отсутствует — блок не печатается с пометкой.

## 4. Текущий консенсус

Последняя волна с `available_from <= today` (для бэктеста — строго `<`). Печатаются медианы, p10/p90 и `answers` по годам волны; для текущего года — средняя с начала года (calendar-day fill-forward) и B4-проекция остатка. Устаревшая волна не подменяется: если последняя волна старше естественного цикла (8 волн/год ≈ 6–7 недель), это называется.

## 5. Отчёт и интеграция

В `key_rate_model_report.md` добавляется раздел «Консенсус-бенчмарк №4»:

1. вводные и правило доступности;
2. текущий консенсус (медианы/p10/p90/answers, B4-проекция остатка, сценарий удержания);
3. годовой бенчмарк: таблица по бакетам (consensus vs hold, DM);
4. построчный аудит волн;
5. режимный срез 2024–2025;
6. B4: DM против B1–B3/методов на общих заседаниях, перечень пропусков;
7. «что не проверено».

Основной CSV `key_rate_model_predictions.csv` не меняется: B4 в него не пишется, аудит — в отчёте. Если `v_cbr_mo_br` пуста — раздел «данных нет», прогон не падает; ошибка запроса — fail-fast.

Статья `docs/publications/2026-10-18-key-rate.md` §4.1 дополняется абзацем о точности консенсуса и сценарием удержания; чек-лист публикации — строкой «Консенсус-бенчмарк #129 — измерен».

## 7. Риски

| Риск | Митигация |
|---|---|
| Годовая медиана — не шаг заседания | Основной результат — годовой горизонт; B4 подписан «механическая проекция», не трек |
| B4 чувствителен к округлению медианы и остатку года | Guard `N_rem >= 30`; формула и ограничение названы; DM на общих заседаниях |
| Малая выборка (экс-анте n=4), смены режима 2022/2024–2025 | Бакеты по горизонту + режимный срез 2024–2025; p-value индикативный; «не значимо» — допустимый результат |
| Дата волны ≠ дата публикации | Консервативные +6 дней; ограничение названо |
| `v_cbr_mo_br` пуста/недоступна | Пустая — раздел «данных нет»; ошибка запроса — fail-fast |
| Основной CSV/JSON/журнал меняются | B4 не входит в `METHODS`/`FORECAST_METHODS`/JSON; CSV не меняется |
