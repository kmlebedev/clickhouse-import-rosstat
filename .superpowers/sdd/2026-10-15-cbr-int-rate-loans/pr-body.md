# Пункт 4.2 №8 «Ставки по кредитам» — импортёр `cbr_int_rate_loans`

Пункт фазы 2 контура прогноза ключевой ставки ([docs/ROADMAP_KEY_RATE.md](docs/ROADMAP_KEY_RATE.md) §4.2 №8).
Спека: [docs/superpowers/specs/2026-10-15-cbr-int-rate-loans-design.md](docs/superpowers/specs/2026-10-15-cbr-int-rate-loans-design.md),
план: [docs/superpowers/plans/2026-10-15-cbr-int-rate-loans.md](docs/superpowers/plans/2026-10-15-cbr-int-rate-loans.md).

## Зачем

Канал «жёсткость ДКУ» был закрыт только со стороны пассивов: `cbr_bank_int_rate` собирает ставки по
**вкладам** физлиц. Без кредитных ставок трансмиссия ДКП видна наполовину — ЦБ в резюме обсуждений
регулярно ссылается на динамику кредитования и денежно-кредитные условия.

## Источник данных

| | |
|---|---|
| URL | `https://www.cbr.ru/vfs/statistics/pdko/int_rat/loans_nonfin.xlsx` — прямая стабильная ссылка (HTTP 200, 124 288 байт) |
| Лист | `ставки_руб` (в книге 8 листов; читается один) |
| Содержание | Средневзвешенные процентные ставки по кредитам, предоставленным кредитными организациями **нефинансовым организациям** в рублях, % годовых |
| Глубина | помесячно, 2014-01 … 2026-08 (152 месяца) |
| Ряды | 16 = 8 сроков (до 30 дней, включая «до востребования»; 31–90; 91–180; 181 дня–1 года; до 1 года; 1–3 года; свыше 3 лет; свыше 1 года) × 2 группы заёмщиков («Всего» и «СМП») |

Имена рядов объявляет код (стандарт §6.8: в источнике наборы сроков в двух группах идентичны и как
имена не годятся); текст заголовков сверяется, расхождение — fail-fast. Дата точки — предпоследний
день месяца отчётного периода, конвенция та же, что у `cbr_bank_int_rate`, поэтому ставки по вкладам
и по кредитам сопоставимы на одной оси (в `description` каталога: сопоставлять по `toStartOfMonth(date)`).

## Схема таблицы

```sql
CREATE TABLE IF NOT EXISTS cbr_int_rate_loans (
      name LowCardinality(String)   -- группа + срок, например «Всего: от 1 года до 3 лет»
    , date Date                     -- предпоследний день месяца отчётного периода
    , rate Float64                  -- % годовых (новые ценовые значения — Float64, правило 5 AGENTS.md)
) ENGINE = ReplacingMergeTree ORDER BY (name, date);
```

Ряды читаются витриной `v_cbr_macro` (общая long-форма `source, series, date, value`) и описаны в
`series_catalog` (16 записей); сырая таблица агенту MCP не выдана. Точка контроля публикации
объявлена (`SELECT count() FROM cbr_int_rate_loans FINAL`) — файл помесячный, шаг ежедневный.

## Как запускать

```bash
make import STAT=cbr_int_rate_loans
```

Шаг добавлен в `dagu/cbr.yaml` (10-й из 16, цепочка ежедневно 09:17 МСК) сразу после
`cbr_bank_int_rate`; версии файла попадают в винтажный архив общим механизмом шаблона.

## Пример проверки

```sql
SELECT series, date, value FROM v_cbr_macro FINAL
WHERE series LIKE 'Всего:%' ORDER BY series, date DESC LIMIT 5;
```
